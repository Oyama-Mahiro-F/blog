计算机系统概述与性能指标

2026-08-29
  • 计算机组成原理

计算机系统 = 硬件 + 软件，本章是计算机组成原理的开篇，回答三个问题：计算机由什么组成、如何自动工作、用什么指标衡量快慢。408 的考查重心在：冯·诺依曼结构与存储程序思想、五大部件职责与取指→分析→执行的工作流程、软硬件逻辑等价，以及性能指标计算（时钟周期、CPI、CPU 执行时间、MIPS、FLOPS）——性能计算几乎每年必考，务必把公式练到能直接代入。

计算机系统的基本组成

计算机系统由硬件和软件两大部分组成，缺一不可：

组成 内容 举例
硬件 看得见摸得着的物理装置 CPU、主存、硬盘、键盘、显示器
软件 运行在硬件之上的程序、数据与文档 操作系统、编译器、办公软件

软件又分为两类：

类别 定义 举例
系统软件 管理整个计算机系统、为应用软件提供运行平台 操作系统、数据库管理系统（DBMS）、编译程序、汇编程序
应用软件 解决具体应用领域实际问题的程序 Word、浏览器、游戏

考点：数据库管理系统（DBMS）属于系统软件，这是选择题高频陷阱；语言处理程序（编译、解释、汇编程序）也都是系统软件。

计算机系统的层次结构

从底层硬件到上层软件，计算机系统可划分为六个层次：

层次 名称 使用者 说明
第 1 层 逻辑电路层 硬件工程师 逻辑门、寄存器等底层电路
第 2 层 微程序层 硬件工程师 一条机器指令由一段微程序解释执行
第 3 层 指令集体系结构层（ISA） 软硬件分界面 机器指令的集合，软件与硬件的接口/契约
第 4 层 操作系统层 系统程序员 管理硬件资源、向上提供系统调用
第 5 层 汇编语言层 汇编程序员 助记符编程，虚拟机器
第 6 层 高级语言层 高级语言程序员 C、Java 等，虚拟机器
  • 下层为上层服务，上层对下层透明：上层程序员无需关心下层实现细节。
  • 除第 1~2 层是”实际机器”外，其余各层均由软件实现，称为虚拟机器。
  • ISA（指令集体系结构）规定指令格式、操作类型、寻址方式、寄存器组织等：同一 ISA 可用不同硬件实现（微架构），实现软硬件解耦。
  • 从程序员视角看三层机器：高级语言程序员（第 6 层）→ 汇编语言程序员（第 5 层）→ 机器级程序员（第 3 层及以下）；层次越低，越需要了解底层细节。

考点：ISA 是软件与硬件的分界面；一条机器语言指令的落地路径是”高级语言 →（编译）→ 汇编语言 →（汇编）→ 机器语言 →（微程序解释执行）→ 硬件”。

三级语言与三种翻译程序

语言 特点 翻译方式
机器语言 二进制代码，唯一能被硬件直接识别执行 无需翻译
汇编语言 用助记符（ADD、MOV）表示机器指令 由汇编程序翻译成机器语言
高级语言 接近自然语言与数学表达（C、Java） 由编译程序或解释程序处理

三种翻译程序的对比（重点）：

对比项 汇编程序 编译程序 解释程序
翻译对象 汇编语言 → 机器语言 高级语言 → 机器语言（或先译为汇编） 高级语言逐句翻译执行
工作方式 整体翻译 整体翻译一次，生成目标程序 逐句翻译、逐句执行
是否生成目标代码 是 是（可脱离翻译程序独立反复运行） 否（每次执行都要解释程序在场）
执行速度 快 快 慢
典型场景 汇编源程序 C/C++、Fortran Python、JavaScript

软件和硬件的关系：逻辑等价

  • 任何操作既可以由硬件实现，也可以由软件实现——即软硬件逻辑等价。如乘法可用硬件乘法器（快、成本高），也可用”加法 + 移位”的软件子程序（慢、省钱）实现。
  • 固件（Firmware）：具有软件特性的硬件（如固化在 ROM 中的微程序、引导程序），兼具硬件的快速性与软件的灵活性。
  • 设计权衡：性能关键、使用频繁的操作用硬件实现（硬化），灵活多变、较少使用的用软件实现（软化），按价格、速度、变更频率取舍。

易错点：编译程序生成目标代码、解释程序不生成目标代码——解释是”翻译一句、执行一句”，不产生可独立运行的目标程序。

冯·诺依曼计算机的结构

存储程序思想

1945 年冯·诺依曼提出**存储程序（Stored Program）**概念，奠定了现代计算机体系结构的基础：

  • 指令和数据以同等地位、用二进制形式，事先存入存储器；
  • 机器按地址访问，逐条自动取出指令并顺序执行（遇转移指令才改变顺序）；
  • 程序启动前必须先装入主存；运行就是不断循环”取指令 → 分析指令 → 执行指令“，无需人工干预。

五大部件及其功能

部件 功能 典型内部结构
运算器 完成算术运算与逻辑运算 ALU、ACC（累加器）、MQ（乘商）、X（操作数）
控制器 指挥中心：取指令、分析指令、发出控制信号协调各部件 PC、IR、ID、CU
存储器 存放指令和数据（两者同等地位） 存储体、MAR、MDR
输入设备 将程序和数据转换成机器能识别的形式 键盘、鼠标
输出设备 将处理结果转换成人能识别的形式 显示器、打印机

图中实线为数据流、虚线为控制流（反馈）：输入设备把程序和数据送入存储器，运算器与存储器交换数据，控制器发控制信号指挥全局，结果经输出设备送出。

以运算器为中心到以存储器为中心

早期冯·诺依曼机以运算器为中心：I/O 设备与存储器之间的数据传送都要经过运算器，运算器忙于搬运数据、效率低。现代计算机改进为以存储器为中心，I/O 设备可与主存直接交换数据（如 DMA 方式），并进行功能集成：

  • CPU = 运算器 + 控制器（集成在同一芯片）
  • 主机 = CPU + 主存储器
  • 外设（I/O 设备）= 输入设备 + 输出设备 + 辅助存储器

考点：冯·诺依曼机以运算器为中心，现代计算机以存储器为中心；主机 = CPU + 主存，辅存（外存）从主机组成角度归入外设。

计算机的工作过程

关键寄存器一览

寄存器 全称 所属 作用
PC 程序计数器 控制器 存放下一条指令的地址，具有自动 +1 功能
IR 指令寄存器 控制器 存放当前正在执行的指令
ID 指令译码器 控制器 对操作码译码，识别指令类型
CU 控制单元 控制器 产生微操作控制信号，指挥各部件
MAR 存储器地址寄存器 主存 存放要访问单元的地址；n 位 → 可寻址 2n 个单元
MDR 存储器数据寄存器 主存 存放与主存交换的数据；位数 = 存储字长
ACC 累加器 运算器 存放操作数或运算结果
ALU 算术逻辑单元 运算器 执行算术/逻辑运算
PSW 程序状态字寄存器 运算器 记录标志位（CF、ZF、SF、OF）

一条指令的完整执行流程

以指令 ADD M（将主存 M 单元的内容与 ACC 相加）为例，一条指令的执行分三步：

① 取指令——把指令从主存取到 IR：

② 分析指令——译码并产生控制信号：

③ 执行指令——取操作数并运算：

执行完毕后回到①取下一条指令，整个程序就是”取指→分析→执行”的循环，直到停机指令。完整的指令周期可包含：取指周期 → 间址周期（间接寻址时再访存一次取有效地址）→ 执行周期 → 中断周期（有中断请求时响应）。

考点：取指数据通路一步不差地记牢——PC → MAR → 主存 → MDR → IR；PC 存”下一条”指令地址、IR 存”当前”指令；PC 自动加 1 发生在取指阶段。
易错点：MAR、MDR、IR、PSW 对程序员透明（不可见），PC 可编程访问（可见）；间址周期是”再访存取地址”，不是”取操作数”。

以 c = a + b 为例，编译后大致生成四条指令：LOAD R1,[a]、LOAD R2,[b]、ADD R3,R1,R2、STORE [c],R3，每条都走一遍上述取指→分析→执行的循环。

计算机的性能指标

机器字长、数据通路带宽与主存容量

指标 定义 说明
机器字长 CPU 一次能处理的二进制位数（内部寄存器/ALU 宽度） 字长越长精度越高、寻址范围越大
指令字长 一条指令的二进制位数 可等于或数倍于机器字长
存储字长 一个存储单元存放的二进制位数 通常等于 MDR 位数
数据通路带宽 数据总线一次能并行传送的位数 又称总线宽度，影响传输效率
主存容量 存储单元个数 × 存储字长 MAR 16 位、MDR 32 位 → 216×32 bit = 256 KB
主存带宽 每秒可从主存读/写的最大数据量 = 数据总线宽度 × 工作频率（DDR 再 ×每周期传输次数）

易错点：主存容量由 MAR 位数决定单元个数（2n）、MDR 位数决定存储字长；容量单位用 2 的幂（1 KB = 210 B、1 GB = 230 B），速率单位（带宽、FLOPS）用 10 的幂。

主频与 CPU 时钟周期

  • CPU 时钟周期 T：CPU 工作的最小时间单位，每个动作至少占一个时钟周期。
  • 主频 f：CPU 内数字脉冲信号的振荡频率，单位 Hz（如 2 GHz）。
T=f1​

例：主频 2 GHz → T=2×1091​s=0.5ns。

CPI 与 CPU 执行时间（核心公式）

CPI（Clock cycles Per Instruction）：执行一条指令所需的平均时钟周期数。不同指令 CPI 不同（如加法 CPI=1、乘法可达 3~5），混合程序要按占比加权平均：

CPI=总指令条数总时钟周期数​=i∑​wi​×CPIi​(wi​ 为第 i 类指令占比) CPU 执行时间=指令条数×CPI×T=f指令条数×CPI​

例题 1：某 CPU 主频 2 GHz、平均 CPI 为 4，程序共含 5×108 条指令，求 CPU 执行时间与 MIPS。

  • 时钟周期 T=2×1091​=0.5 ns
  • 总时钟周期数 = 5×108×4=2×109
  • CPU 执行时间 = 5×108×4×0.5×10−9=1 s
  • MIPS = CPI×106f​=4×1062×109​=500 MIPS

验算：MIPS = 执行时间×106指令条数​=1×1065×108​=500 ✓

考点：决定 CPU 执行时间的三个因素——指令条数（算法与编译器决定）、CPI（ISA 与微架构决定）、时钟周期 T（硬件工艺决定）。

例题 2（综合例题）：某程序含三类指令：A 类 120 条（CPI=1）、B 类 60 条（CPI=2）、C 类 20 条（CPI=4），机器主频 400 MHz。求平均 CPI、总时钟周期数、CPU 执行时间与 MIPS。

  • 总指令数 = 120 + 60 + 20 = 200 条
  • 总时钟周期数 = 120×1+60×2+20×4=120+120+80=320
  • 平均 CPI = 200320​=1.6
  • 时钟周期 T=400×1061​=2.5 ns
  • CPU 执行时间 = 320×2.5ns=800 ns
  • MIPS = 1.6×106400×106​=250 MIPS

验算：MIPS = 800×10−9×106200​=0.8200​=250 ✓

易错点：平均 CPI 不是各类指令 CPI 的简单算术平均，必须按条数（占比）加权；代入 MIPS 公式时注意主频与 106 的换算。

例题 3（两机对比）：执行同一程序（指令条数均为 N），机器 A 主频 2 GHz、CPI=1.5；机器 B 主频 2.5 GHz、CPI=2，问哪台更快？

  • A 的执行时间 = N×1.5/(2×109) = 0.75N ns
  • B 的执行时间 = N×2/(2.5×109) = 0.8N ns
  • 0.75N<0.8N，A 更快；B 时间是 A 的 0.750.8​≈1.07 倍（A 性能约为 B 的 1.07 倍）。

考点：主频高不一定快——性能还取决于 CPI 与指令条数，比较性能只能用同一程序的总执行时间。

例题 4（优化前后对比）：某程序中访存指令占 40%（CPI=3），其余指令 CPI=1。优化后访存指令的 CPI 减半，求平均 CPI 变化与加速比（主频不变）。

  • 优化前平均 CPI = 0.4×3+0.6×1=1.8
  • 优化后平均 CPI = 0.4×1.5+0.6×1=1.2
  • 指令条数与主频不变，执行时间与 CPI 成正比：总时间变为原来的 1.81.2​=32​
  • 加速比 = 1.21.8​=1.5

MIPS 与 FLOPS

MIPS=执行时间×106指令条数​=CPI×106f​(每秒执行多少百万条指令)

FLOPS（Floating-point Operations Per Second）：每秒浮点运算次数，衡量科学计算与超算性能；各量级每级 ×10³ 递进：

单位 数量级 含义
MFLOPS 106 每秒百万次浮点运算
GFLOPS 109 每秒十亿次
TFLOPS 1012 每秒万亿次
PFLOPS 1015 每秒千万亿次（超算常用）
EFLOPS 1018 每秒百亿亿次
ZFLOPS 1021 每秒十万亿亿次

易错点：MIPS 以指令为单位、FLOPS 以浮点运算为单位，二者不能直接换算；FLOPS 记住递推 M → G → T → P → E → Z，每级 ×10³。

吞吐量、响应时间与基准程序

指标 定义 说明
吞吐量 系统单位时间内完成的作业/请求数 作业数/s、TPS、QPS，衡量系统整体处理能力
响应时间 从提交请求到获得首个结果的总时间 = CPU 时间 + I/O 与等待时间
利用率 资源实际使用时间占总时间的比例 百分比（%）

基准程序（Benchmark）：用一组专门设计的真实程序（如 SPEC 套件）综合测量机器性能，比单一指标（如主频）更客观；但要警惕厂商针对基准程序做针对性优化导致结果失真。吞吐量与响应时间往往相互制约：提高吞吐量（多道并发）可能拉长单个任务的响应时间。

性能指标关系表

指标 公式 / 关系 决定因素
时钟周期 T=1/f 硬件工艺
主频 f=1/T 硬件工艺
CPI 总周期数 / 总指令数（加权平均） ISA + 微架构
CPU 执行时间 指令条数 × CPI × T = 指令条数 × CPI / f 三者共同决定
MIPS f/(CPI×106) 主频 + CPI
FLOPS 每秒浮点运算次数（M/G/T/P/E/Z） 浮点部件吞吐能力
吞吐量 / 响应时间 系统级指标 软硬件整体 + 负载情况

考点：提升性能的三条路——减少指令条数（改进算法/编译器）、降低 CPI（流水线、超标量）、缩短时钟周期（提升工艺）。

高频考点速记

考点 记忆
冯·诺依曼核心 存储程序：指令和数据同等地位、二进制存放、按地址顺序执行
五大部件与主机 输入、输出、存储器、运算器、控制器；CPU = 运算器 + 控制器；主机 = CPU + 主存
中心转移 冯·诺依曼机以运算器为中心 → 现代以存储器为中心（DMA 直连主存）
MAR / MDR MAR n 位 → 寻址 2n 个单元；MDR 位数 = 存储字长
取指流程 PC → MAR → 主存 → MDR → IR（同时 PC+1）；PC 存下条地址、IR 存当前指令
指令周期 取指 → 间址 → 执行 → 中断；程序运行 = “取指→分析→执行”循环
逻辑等价与固件 任何操作软/硬件皆可实现；固件 = 具有软件特性的硬件（快 + 活）

系统软件 DBMS、编译/解释/汇编程序、操作系统都是系统软件
主频与时钟周期 f=1/T；主频 2 GHz → T = 0.5 ns
CPI 与执行时间 CPI = 总周期数/总指令数（加权平均）；CPU 时间 = 指令条数 × CPI × T
MIPS = f/(CPI×106) = 指令条数/(执行时间×106)
FLOPS 量级 M(106)→G(109)→T(1012)→P(1015)→E(1018)→Z(1021)，每级 ×10³
主频高 ≠ 快 还要看 CPI 与指令数；比较性能用同一程序的总执行时间
