浮点数与IEEE754

2026-08-29
  • 计算机组成原理

浮点数（Floating Point）是小数点位置可以浮动的数，用”阶码 + 尾数”把数表示成二进制科学计数法，在有限字长内同时兼顾表示范围与精度。现代计算机普遍采用 IEEE 754 标准存储浮点数。408 对本部分的考查集中在：浮点数一般格式、规格化、IEEE 754（隐藏位、偏置阶码、特殊值）、表示范围与上溢下溢、浮点加减五步运算。

浮点数的一般格式

任意一个二进制数都可以写成类似十进制科学计数法的统一形式：

N=M×RE
符号 名称 含义
M 尾数（Mantissa） 定点小数，决定精度（有效数字位数）
E 阶码（Exponent） 定点整数，决定表示范围（小数点实际位置）
R 基数（Radix） 隐含约定，通常 R=2，不占存储位

机器中存储一个浮点数只需三段信息：

  • 阶码位数决定小数点能浮动多远 → 决定表示范围；
  • 尾数位数决定有效数字个数 → 决定精度；
  • “小数点位置随阶码浮动”正是浮点数得名的由来。

考点：阶码决定范围、尾数决定精度。同一个数有多种浮点表示（1.0×23=0.5×24），因此需要规格化统一形式、保证表示唯一。

规格化

为什么要规格化

尾数小数点后紧跟 0 时（如 0.0011×25），前面的 0 白白占位、浪费有效位。规格化就是调整阶码并移动尾数，使尾数最高数值位成为有效位，从而保留最多有效位、表示唯一。

左规与右规

以双符号位补码尾数为例（单符号位同理，看符号位与最高数值位的关系）：

操作 触发条件 操作 阶码变化
左规 尾数最高数值位与符号位相同（形如 00.0xx…、11.1xx…） 尾数左移 k 位，低位补 0 阶码 减 k（可能连续多次）
右规 双符号位为 01 / 10（尾数加减有进位，假溢出） 尾数右移 1 位 阶码 加 1（最多 1 次）

右规最多只需 1 次：两个规格化尾数相加减，结果绝对值不会超过 2 倍，最多产生一次进位。

规格化形式的判断

码制 规格化尾数形式 尾数范围
原码 0.1xx…（正）、1.1xx…（负）——最高数值位恒为 1 绝对值 ∣M∣∈[1/2, 1)
补码 0.1xx…（正）、1.0xx…（负）——符号位与最高数值位相反 正数 [1/2,1)，负数 (−1,−1/2]

易错点：原码看”最高数值位是否为 1”；补码看”符号位与最高数值位是否相反”。补码负数规格化形如 1.0xx…（如 −0.75 的补码 1.010…），不要套用原码口诀；IEEE 754 的规格化则是”尾数呈 1.M 形式”。

IEEE 754 标准

格式与隐藏位

格式 总位数 符号 S 阶码 E 尾数 M 偏置 Bias
单精度（float） 32 位（4B） 1 位 8 位 23 位 127（27−1）
双精度（double） 64 位（8B） 1 位 11 位 52 位 1023（210−1）

三条关键约定：

  • 阶码用偏置阶码（移码）：E=e+Bias（e 为真阶），如单精度 8 位存的是 e+127；
  • 尾数用原码且规格化，最高位的 1 隐藏不存（隐藏位）：23 位尾数实际表示 1.M，白赚 1 位精度；
  • 真值公式：
N=(−1)S×1.M×2E−Bias

考点：隐藏位 1——规格化数尾数首位必为 1，不必存储。float 有效位数 24 位（23+1，约 6~7 位十进制），double 53 位（52+1，约 15~16 位十进制）。

为什么用偏置而不用补码

偏置阶码把真阶统一加上 Bias 后，阶码域成为无符号整数且保持单调（真阶越大，无符号码越大）。于是任意两个浮点数可按”符号位 → 阶码 → 尾数”直接做无符号整数逐位比较判断大小，硬件只需一套无符号比较器。若用补码，负阶码的最高位为 1，无符号比较会得出”负数大于正数”的错误结论，需额外判号逻辑。

易错点：单精度偏置是 127 不是 128；规格化阶码域取值 1~254（全 0、全 1 留给特殊值），对应真阶 −126∼127。双精度同理：1~2046，真阶 −1022∼1023。

单精度 vs 双精度（重点对比）

对比项 单精度 float（32 位） 双精度 double（64 位）
位分配 1 + 8 + 23 1 + 11 + 52
偏置常数 127 1023
有效位数（含隐藏位） 24 位（约 6~7 位十进制有效数字） 53 位（约 15~16 位十进制有效数字）
规格化真阶范围 −126∼127 −1022∼1023
最大正数 (2−2−23)×2127≈3.4×1038 (2−2−52)×21023≈1.8×10308
最小规格化正数 2−126≈1.18×10−38 2−1022≈2.23×10−308

特殊值四类（考纲新宠）

阶码全 0、全 1 的编码不按普通偏置解释，专门表示特殊值（以单精度为例）：

类型 阶码 E 尾数 M 含义 真值
零 全 0（0） 全 0 真值 0 +0 与 −0 两种编码
非规格化数 全 0（0） 非 0 极小数，隐藏位变 0 (−1)S×0.M×2−126
规格化数 1~254 任意 正常浮点数 (−1)S×1.M×2E−127
无穷大 ∞ 全 1（255） 全 0 溢出、除零的结果 (−1)S×∞
NaN 全 1（255） 非 0 非数（0/0、−1​ 等无效操作） 不与任何数相等
  • 非规格化数把隐藏位从 1 换成 0（0.M），指数固定为 −126，填补 0 与最小规格化数之间的空隙，实现逐渐下溢（Gradual Underflow）——越靠近 0 分得越细、过渡平滑；
  • ∞ 可正常参与运算（如 ∞x​=0）而不报错；NaN 由无效操作产生，任何比较均返回假。

考点：记”全 0 或全 1 有特殊含义“——阶码全 0：零 / 非规格化数（看尾数是否为 0）；阶码全 1：∞ / NaN（看尾数是否为 0）。
易错点：非规格化数的隐藏位是 0 不是 1，公式为 0.M×2−126；+0 和 −0 编码不同但数值相等。

例题：十进制与 IEEE 754 的互转

十进制 → 单精度：178.125

① 整数部分：178=128+32+16+2=101100102​；

② 小数部分：0.125=0.0012​；

③ 合并：178.125=10110010.0012​；

④ 规格化：10110010.0012​=1.01100100012​×27（小数点左移 7 位）；

⑤ 符号位：正数，S=0；

⑥ 阶码：E=e+127=7+127=134=100001102​；

⑦ 尾数：隐藏整数位 1，只存小数部分 0110010001，后补 13 个 0 凑满 23 位；

⑧ 拼装：

单精度 → 十进制：1 01111101 10000000000000000000000

① 符号：S=1 → 负数；

② 阶码：E=011111012​=125，真阶 e=125−127=−2；

③ 尾数：1.M=1.100…02​=1.5（隐藏位 1 要补回去）；

④ 真值：N=(−1)1×1.5×2−2=−0.375。

验证：−0.375=−0.0112​=−1.12​×2−2，与位串一致 ✓

浮点数的表示范围

数轴两端为上溢区，0 附近为下溢区（由非规格化数填补）：

极值 单精度 双精度
最大正数 (2−2−23)×2127≈3.4×1038 (2−2−52)×21023≈1.8×10308
最小正规格化数 1.0×2−126≈1.18×10−38 1.0×2−1022≈2.23×10−308
最小正非规格化数 2−149≈1.4×10−45 2−1074≈4.9×10−324
  • 上溢（阶码上溢）：结果绝对值超过最大正数 → 按 ±∞ 处理并置溢出标志（可中断）；
  • 下溢（阶码下溢）：结果绝对值小于最小非规格化数 → 按机器零处理，不算错误。

考点：浮点溢出只发生在阶码上——上溢触发异常，下溢按机器零继续运算。

例题：float 的最大正数与最小规格化正数

最大正数——阶码取规格化最大值 E=254（全 1 被特殊值占用），尾数全 1：

  • 真阶：e=254−127=127；
  • 尾数：1.2311…1​​=2−2−23；
  • 最大正数 =(2−2−23)×2127≈2128≈3.4×1038。

最小规格化正数——阶码取规格化最小值 E=1，尾数全 0：

  • 真阶：e=1−127=−126；
  • 尾数：1.00…0=1；
  • 最小规格化正数 =1.0×2−126≈1.18×10−38。

再往下就是非规格化区：最小正非规格化数 =2−23×2−126=2−149≈1.4×10−45。

易错点：阶码全 0、全 1 不能取（留给特殊值），所以规格化真阶范围是 −126∼127 而非 −127∼128；最大正数尾数是 (2−2−23) 不是 2。

浮点数的加减运算

阶码不同的两个数尾数”对不齐”（相当于一个”千”级、一个”十”级），不能直接相加，必须先统一指数。设 x=Mx​×2Ex​，y=My​×2Ey​（Ex​≤Ey​），则：

x±y=(Mx​×2Ex​−Ey​±My​)×2Ey​

五步法：对阶 → 尾数加减 → 规格化 → 舍入 → 溢出判断。

第一步：对阶（小阶向大阶）

  • 求阶差 ΔE=∣Ex​−Ey​∣；
  • 阶小的数尾数右移 ΔE 位（原码尾数高位补 0），阶码加 ΔE。

考点：为什么小阶向大阶？若让大阶变小，其尾数要左移，丢的是高位（直接出错）；小阶尾数右移只丢低位（仅损精度）。两害相权取其轻。

第二步：尾数加减

对阶后两数阶码相同，直接做定点补码加减。尾数用双符号位（00 正、11 负）暂存，以便发现溢出形态：结果双符号位为 01 或 10 说明尾数”溢出”——这只是假溢出，下一步右规即可修复。

第三步：规格化

结果形式（双符号位） 判断 操作
00.1xx… 或 11.0xx… 符号位与最高数值位相反，已规格化 不动
00.0xx… 或 11.1xx… 符号位与最高数值位相同 左规：尾数左移 k 位、阶码减 k
01.xx… 或 10.xx… 双符号位相异（假溢出） 右规：尾数右移 1 位、阶码加 1

第四步：舍入

对阶右移和规格化时被移出的低位需要舍入。IEEE 754 规定四种舍入模式：

模式 规则 特点
就近舍入（默认） 舍弃部分 < 一半则舍去、> 一半则进 1、恰为一半向偶数（最低位为 0）舍入 无累积偏差，最常用
朝 +∞ 舍入 结果向 +∞ 方向取，多余位非 0 则增大 相当于向上取整
朝 −∞ 舍入 结果向 −∞ 方向取，多余位非 0 则减小 相当于向下取整
朝 0 舍入（截断） 直接丢弃多余位 最简单，误差最大

硬件上用保护位 G、舍入位 R、粘着位 S（S 记录移出位中是否出现过 1）三位判断”舍弃部分”与一半的关系，再按模式舍入。

第五步：溢出判断

考点：浮点溢出只看阶码——尾数加减出现 01.xx/10.xx 是假溢出（右规一次即可修复）；阶码上溢才是真溢出。

情况 判断（单精度） 处理
阶码上溢 真阶 >127 置溢出标志，结果 ±∞
阶码下溢 真阶 <−126 转非规格化数或按机器零处理
阶码正常 −126≤e≤127 正常结果

例题：浮点加法完整演算

求 x+y，其中 x=23×0.1101，y=25×(−0.1010)（尾数取 6 位，双符号位补码运算）。

准备：[x]补​=00.110100；−0.101000 取反加 1 得 [y]补​=11.011000；阶码 Ex​=3、Ey​=5。

① 对阶：ΔE=∣3−5∣=2，x 阶小 → x 的尾数右移 2 位、阶码加 2：

对阶后 x′=25×00.001101，移出的两位都是 0，无精度损失。

② 尾数相加（双符号位补码竖式）：

③ 规格化：结果 11.100101 的符号位（11）与最高数值位（1）相同 → 左规 1 位：尾数变 11.001010，阶码 5−1=4。此时符号 11 与最高数值位 0 相反，已规格化。

④ 舍入：对阶移出的全是 0，本次无舍入。

⑤ 溢出判断：阶码 4 在正常范围内 → 不溢出。

结果：[x+y]补​=11.001010×24，还原成原码为 −0.110110×24，即：

x+y=24×(−0.1101102​)=−0.84375×16=−13.5

验算：x=8×0.8125=6.5，y=32×(−0.625)=−20，6.5+(−20)=−13.5 ✓

易错点：对阶移动的是小阶数的尾数（不是大阶数）；左规阶码减、右规阶码加；补码负数结果要”取反加 1”还原成原码再读真值。

浮点 vs 定点与运算精度

对比项 定点数 浮点数
小数点位置 固定 浮动（由阶码决定）
表示范围 窄 宽（同字长下远大于定点）
精度 全程恒定 动态（数越大，数轴间隔越大）
加减运算 直接相加 需对阶、规格化、舍入
溢出判断 结果超范围即溢出 只看阶码
硬件成本 低 高（需浮点运算器 FPU）

浮点运算不精确的根源：尾数位数有限，对阶右移、规格化、存储每一步都要舍入，误差逐步累积。因此浮点加法不满足结合律（(a+b)+c 与 a+(b+c) 可能不等，如 (1020+1)−1020=1）。经典现象：0.1 + 0.2 ≠ 0.3——0.1 和 0.2 的二进制是无限循环小数，存储时已舍入，相加后再舍入便得到 0.30000000000000004。

考点：浮点 = 近似运算：交换律成立、结合律不成立；误差根源是”有限尾数 + 舍入“。

高频考点速记

考点 记忆
浮点一般格式 N=M×RE；阶码定范围、尾数定精度，小数点位置随阶码浮动
规格化目的 保留最多有效位、表示唯一；原码尾数绝对值 ∣M∣∈[1/2,1)
左规 / 右规 符号与最高数值位同 → 左规（阶码减 k）；双符号位 01/10 → 右规（阶码加 1，最多 1 次）
补码规格化判据 符号位与最高数值位相反（正 0.1xx、负 1.0xx）
IEEE 754 位数 单精度 1+8+23、双精度 1+11+52；尾数隐藏 1，实际为 1.M
偏置阶码 阶码 E=e+127（float）/ e+1023（double）；移码单调 → 可无符号比较
特殊值（阶码全 0） 尾数全 0 = ±0；尾数非 0 = 非规格化数（0.M，隐藏位变 0，逐渐下溢）
特殊值（阶码全 1） 尾数全 0 = ±∞；尾数非 0 = NaN
float 表示范围 最大 (2−2−23)×2127≈3.4×1038；最小规格化正数 2−126
加减五步法 对阶 → 尾数加减 → 规格化 → 舍入 → 判溢出
对阶原则 小阶向大阶：小阶尾数右移 ΔE 位（丢低位损失小，左移丢高位会出错）
舍入模式 默认就近舍入（恰为一半向偶数舍入）；另有朝 0、朝 +∞、朝 −∞
溢出判断 只看阶码：上溢 → ±∞（异常）；下溢 → 机器零；尾数 01/10 是假溢出
运算精度 有限尾数 + 舍入 → 交换律成立、结合律不成立；0.1+0.2=0.3
