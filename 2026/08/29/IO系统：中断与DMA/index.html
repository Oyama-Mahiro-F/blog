IO系统：中断与DMA

2026-08-29
  • 计算机组成原理

输入输出（I/O）系统是计算机主机与外界进行信息交换的桥梁，由 I/O 设备（外设）、I/O 接口、I/O 总线与 I/O 软件共同构成。它的核心矛盾是：CPU 快、外设慢，且外设种类繁多、信号形式各异，因此必须解决数据缓冲、信号转换、设备选择与控制方式等问题。408 对本章的考查集中在：外设参数与磁盘计算、I/O 端口编址、程序查询 / 程序中断 / DMA 三种 I/O 方式——尤其是中断屏蔽字与多重中断、DMA 控制器组成与传送过程、中断与 DMA 的对比。

I/O 系统的组成与控制方式

I/O 系统由四部分组成，软硬件协同完成一次输入输出：

组成部分 说明 示例
I/O 设备（外设） 输入 / 输出 / 外存储设备 键盘、显示器、磁盘
I/O 接口 主机与外设之间的交接电路，内含可访问的寄存器 串口控制器、磁盘控制器
I/O 总线 连接 CPU、主存与各 I/O 接口的传输线路 PCIe、USB、SATA
I/O 软件 驱动程序、中断服务程序等 设备驱动、BIOS 例程

注意：I/O 接口是整块接口电路，I/O 端口只是接口内部可被 CPU 访问的寄存器（数据 / 状态 / 控制端口），每个端口有一个地址。接口功能（缓冲、译码、中断控制等）与端口编址详见下文” I/O 接口”一节；I/O 软件、驱动与中断处理程序的分层管理属于操作系统的 I/O 子系统，考纲只要求一句” I/O 接口与端口”的概念，详细机制与 OS 课程呼应。

I/O 控制方式的演进主线是：CPU 介入越来越少，CPU 与外设并行程度越来越高：

方式 CPU 介入程度 数据传送单位 速度 适用设备
程序查询方式 全程参与（循环查询忙等） 字 / 字节 慢 低速简单设备
程序中断方式 每传送一个数据响应一次中断 字 / 字节 中 键盘、鼠标
DMA 方式 仅预处理、后处理介入 数据块 快 磁盘、网卡
通道 / I/O 处理机 几乎不介入 块 / 文件 最快 大型机（408 仅要求概念）

考点：四种方式的演进趋势——查询 → 中断 → DMA → 通道，CPU 介入逐级减少；408 重点考中断与 DMA 的细节。

外部设备

输入设备：键盘与鼠标

设备 功能 工作原理
键盘 字符 / 命令输入 按键 → 扫描电路得扫描码 → 转换为 ASCII 码 → 以中断方式通知 CPU 取走
鼠标 位置 / 点击输入 光电传感器检测位移 → 输出坐标增量与按键事件，同样经接口上报

键盘、鼠标都是低速设备，天然适合用程序中断方式与 CPU 交换数据。

输出设备：显示器与打印机

显示器主要参数：

参数 含义
屏幕大小 以对角线长度度量，常见 12~29 英寸
分辨率 屏幕能显示的像素个数，用”水平 × 垂直”表示（如 1024×768），分辨率越高图像越细
灰度级 黑白显示器中像素的亮暗等级；彩色显示器中表现为颜色种类数，灰度级越多层次越逼真
刷新频率 单位时间内整屏刷新的次数，大于 30 Hz 人眼才不感到闪烁，常见 60~120 Hz

**显示存储器（VRAM，刷新存储器）**用于存放一帧图像以供反复刷新，其容量由分辨率与灰度级共同决定：

V显存​=8分辨率×log2​(灰度级)​ B

显存容量例题：分辨率 1024×768、灰度级 256 色，求所需显存容量与刷新带宽。

  • 每个像素位数 = log2​256=8 位 = 1 B
  • 显存容量 = 1024×768×8 位 =6291456 位 =786432 B = 768 KB（即 0.75 MB）
  • 若刷新频率为 60 Hz，刷新带宽 = 768 KB×60/s≈45 MB/s——显存要按帧频被反复读出

易错点：显存存的是一帧画面，”灰度级 256”意味着每像素 8 位而不是 256 位；分辨率与灰度级任何一个增大都会使显存加大。

打印机三种典型机型的对比：

类型 成像方式 特点
针式打印机 打印针击打色带（击打式） 噪声大、速度慢，但可复写多联票据
喷墨打印机 喷头喷射微小墨滴（非击打式） 可彩色打印，耗材为墨水
激光打印机 静电成像 + 碳粉转印定影（非击打式） 速度快、质量高、噪声低，办公主流

外存储器：硬盘存储器

磁记录原理：硬盘属于磁表面存储器，利用磁性材料的两种不同磁化方向表示 0 和 1。写入时，写线圈中通以不同方向的电流，通过磁头把盘片表面的磁层磁化成相应方向；读出时，磁化单元随盘片旋转掠过磁头，磁通变化在 read 线圈中感应出电动势，还原出 0/1。记录方式（归零制、不归零制、调相制、调频制、改进调频制 MFM 等）影响自同步能力与密度，408 只需了解。

磁盘的组成与关键术语：硬盘由磁盘驱动器（磁头组件 + 盘片组件）、磁盘控制器（IDE、SCSI、SATA 等接口标准）和盘片组成。一块硬盘含若干记录面，每个面划分若干磁道，每条磁道划分若干扇区——扇区（块）是磁盘读写的最小单位。

术语 含义
磁头数 = 记录面数 每个记录面一个磁头
柱面 所有记录面上相同编号的磁道的集合（磁头不动、盘旋转即可同柱面连续存取）
扇区数 每条磁道划分的扇区个数

磁盘性能指标：

指标 说明
道密度 沿半径方向单位长度上的磁道数（道/mm）
位密度 沿磁道方向单位长度上记录的二进制位数；各道容量相同，最内圈磁道周长最短，故内圈位密度最大
转速 盘片每分钟转数（r/min），决定旋转延迟
数据传输率 单位时间内读出 / 写入的数据量 C=n×r（n 为每道字节数，r 为每秒转数）
平均存取时间 = 寻道时间（磁头移到目标磁道）+ 平均旋转延迟（转到目标扇区，取半圈时间）+ 传输时间（读 / 写数据）(+ 控制器开销)

磁盘性能例题 1（数据传输率）：转速 7200 r/min，每磁道 160 扇区，每扇区 512 B，求数据传输率。

  • 转速 r=7200/60=120 r/s；每道容量 n=160×512B=80KB
  • 数据传输率 C=n×r=120×80KB/s=9600 KB/s（≈ 9.375 MB/s）

磁盘性能例题 2（平均存取时间）：转速 10000 r/min，平均寻道时间 6 ms，传输率 20 MB/s，控制器延迟 0.2 ms，读一个 4 KB 块的平均时间。

  • 平均旋转延迟 = 转半圈 = (60/10000)/2=3 ms
  • 传输时间 = 4KB/20MB/s=0.2 ms
  • 平均存取时间 = 3+6+0.2+0.2=9.4 ms

格式化容量例题：某盘组 6 个记录面，每面 1000 磁道，每道 160 扇区，每扇区 512 B。

格式化容量=6×1000×160×512B=491520000B≈468.75 MB

易错点：格式化容量（按扇区数计算，用户可用）小于非格式化容量（按磁化单元总数计算）；磁道容量相同 → 位密度内圈最大、外圈最小。

磁盘地址由四字段构成，访问时按字段逐级定位：

磁盘地址=驱动器号+柱面（磁道）号+盘面号+扇区号

磁盘工作过程：寻址（译码驱动器号 → 磁头移动到目标柱面（寻道）→ 选中盘面 → 旋转等待目标扇区到达磁头下）→ 读写操作（写：数据经磁头磁化盘面；读：磁头感应磁化状态还原数据）。可见一次访盘的大头开销是寻道与旋转等待，因此磁盘按块成批存取，也正因如此适合用 DMA 方式传送。

磁盘阵列 RAID

RAID（独立 / 廉价冗余磁盘阵列）把多个物理盘组织成一个逻辑盘，数据交叉并行存储，同时用冗余信息提高可靠性。408 重点掌握四级：

级别 名称 冗余方式 容量利用率 容错能力
RAID 0 条带阵列 无冗余，数据按条带分布在各盘 100%（最高） 无，坏一块全失效
RAID 1 镜像阵列 数据完全镜像到另一盘 50% 可坏一块，读快
RAID 4 块交叉奇偶校验 数据按块交叉 + 专用奇偶校验盘 (N−1)/N 可坏一块；校验盘成瓶颈
RAID 5 分布式奇偶校验 奇偶信息分散在所有盘，无专用校验盘 (N−1)/N 可坏一块，兼顾性能

考点：RAID 0速度最快但无容错；RAID 1利用率 50% 但可靠性最高；RAID 5 把校验分散存放，解决了 RAID 4 专用校验盘的写瓶颈——三者是”容量利用率 ↔ 可靠性”的权衡。N 块盘的 RAID 5 等效容量为 N−1 块盘。

I/O 接口（I/O 控制器）

I/O 接口的功能与基本结构

I/O 接口（I/O 控制器）处于系统总线与外设之间，功能包括：数据缓冲（匹配速度差）、信号与格式转换（电平、串并转换）、地址译码与设备选择、命令译码、记录并提供设备状态、差错检测、以及中断控制（需要时向 CPU 发中断请求）。

接口内部的核心是三类可编程寄存器（端口）：

端口（寄存器） 作用 传送方向
数据缓冲寄存器 DBR 暂存 CPU 与外设间交换的数据 双向（输入 / 输出）
状态寄存器 记录设备状态：忙（Busy）、就绪（Ready）、错误（Error） CPU 只读
控制寄存器 存放 CPU 发出的命令（启动、读 / 写、方式选择） CPU 只写

此外还有地址译码器（识别端口地址选中本接口）与控制逻辑。状态、控制寄存器在传送方向上正好相反，占用不同端口地址。

I/O 端口及其编址

I/O 端口就是接口中上述可被 CPU 访问的寄存器，要给每个端口编一个地址，编址方式有两种：

对比项 统一编址（存储器映射 I/O） 独立编址（端口映射 I/O）
地址空间 端口与主存单元共用一个地址空间 端口有独立的 I/O 地址空间
访问指令 直接用访存指令（LOAD/STORE/MOV） 需专用 I/O 指令（IN / OUT）
是否占内存空间 占用主存地址空间，使内存可用空间减少 不占内存空间
译码与速度 地址位数长，译码电路复杂、速度较慢 端口地址短，译码快
区分 I/O 与访存 靠地址范围区分，无需专门控制信号 靠专门的控制线（如 M/IO 信号）区分
优点 指令丰富、寻址方式多，无需专用 I/O 指令 I/O 指令短、一目了然，不挤占内存
代表体系 ARM、MIPS x86

考点：统一编址下对端口的操作就是对存储单元的操作，无需专用 I/O 指令，但占内存空间、译码复杂；独立编址必须用 IN/OUT 专用指令，且需控制线指明当前地址属于内存还是 I/O——“是否需要专用指令、是否占内存空间”是选择题最常见判断点。

程序查询方式

程序查询方式完全由 CPU 执行程序控制传送：CPU 先向接口发出启动命令，然后循环读取状态寄存器，检测到”就绪”标志后才与数据端口交换一个数据；未就绪则继续查询——CPU 与外设完全串行工作。

流程 操作
① CPU 执行启动指令，启动外设
② 循环读状态端口，判断 Busy / Ready（忙等）
③ 就绪后读 / 写数据端口，传送一个字
④ 判断是否全部传完，未完转 ②

易错点：查询方式中 CPU 绝大部分时间浪费在”查询忙等”上，设备越多 CPU 负担越重；它优点只有接口硬件简单。数据通路单位是字 / 字节，且传送过程不允许被打断（查询-传送紧密耦合）。

程序中断方式

中断的基本概念

中断指 CPU 暂停现行程序，转去处理随机出现的紧急事件，处理完后返回断点继续执行。按来源分：

类型 来源 示例 特点
内中断（异常） CPU 内部、与指令相关 除 0、溢出、非法操作码、缺页、陷入指令 通常不可屏蔽
外中断 CPU 外部设备 / 事件 I/O 设备请求（INTR）、时钟、掉电 分可屏蔽与不可屏蔽（NMI）

本节只讨论外中断驱动的 I/O：外设准备就绪后，通过接口中的中断请求触发器向 CPU 发出中断请求信号 INTR，CPU 在适当时机响应。

中断响应过程的三个条件：

  1. 中断源有请求（INTR 触发器置 1，且未被屏蔽字屏蔽）；
  2. CPU 允许中断（处于开中断状态，EINT / IF=1；不可屏蔽中断 NMI 不受此限制）；
  3. 一条指令执行完毕之后（CPU 只在指令周期结束时检查中断请求）。

中断隐指令：硬件自动完成的三件事

CPU 响应中断后、转去服务程序之前，由中断隐指令（不是真实指令，完全由硬件自动完成）做三件事：

步骤 操作
① 关中断 置 EINT=0，防止响应过程被新中断打断
② 保存断点 把 PC（及程序状态字等）压栈或存入指定单元，供返回使用
③ 引出中断服务程序 取出中断服务程序的入口地址——硬件向量法（由排队器输出产生向量地址，查中断向量表得入口，速度快）或软件查询法（逐个查询中断源，慢）

易错点：”保存断点”和”关中断”属于中断隐指令（硬件完成）；而”保护现场（通用寄存器）”是中断服务程序里的指令（软件完成）——两者经常放在一起做辨析。

中断处理过程：中断服务程序流程

响应之后，中断服务程序按固定流程执行：

  1. 保护现场：保存通用寄存器等内容（压栈）；
  2. （多重中断：设置中断屏蔽字，然后开中断）
  3. 设备服务：与接口交换数据（输入 / 输出一个字）；
  4. 恢复现场：恢复被保护的内容；
  5. 开中断并中断返回（IRET），回到断点继续执行。

其中数据传送期间接口与 CPU 的配合：外设准备数据（并行） → 就绪后发 INTR → CPU 执行服务程序取走数据 → 返回主程序继续执行——CPU 与外设并行工作，这正是中断方式优于查询方式的根源。

单重中断与多重中断

对比项 单重中断 多重中断（中断嵌套）
定义 服务程序执行期间不再响应新的中断请求 暂停现行服务程序，转去处理**更紧急（优先级更高）**的新请求
开中断时机 服务程序末尾才开中断（全程关中断） 保护现场、设置屏蔽字后提前开中断
嵌套 不允许 允许”高级打断低级”
屏蔽字 屏蔽一切其他可屏蔽请求 按优先级屏蔽，留给更高级的通路

实现多重中断的两个必备条件：① 服务程序中提前设置开中断指令；② 优先级高的中断源有权打断优先级低的中断源。

中断屏蔽字与优先级设置

优先级有两套，务必区分：

概念 决定者 可否动态改变 作用
响应优先级 硬件排队电路（排队器） 不可改变 多个请求同时到达时，先响应谁
处理优先级 中断屏蔽字（各服务程序中设置） 可动态修改 决定执行某服务程序时谁能打断谁（嵌套次序）

每个中断源对应一个屏蔽触发器，全体组成屏蔽字寄存器：某位为 1 表示屏蔽对应中断源，为 0 表示开放。构造规则：屏蔽字中，对本中断源自身以及处理优先级不高于自己的中断源置 1（屏蔽），对处理优先级高于自己的置 0（开放）——这样只留出”更高者可打断我”的通路。

中断屏蔽字例题（核心）：某机 4 个中断源 A、B、C、D，硬件排队（响应）优先级 A>B>C>D；现要求把处理优先级改为 D>A>C>B，写出各源的屏蔽字（每位按 A、B、C、D 顺序），并推演中断嵌套。

  • D（处理第 1，最高）：屏蔽自己 + 所有更低者 A、B、C → 1 1 1 1
  • A（处理第 2）：屏蔽 A、B、C，开放 D → 1 1 1 0
  • C（处理第 3）：屏蔽 C、B，开放 D、A → 0 1 1 0
  • B（处理第 4，最低）：只屏蔽 B，开放 D、A、C → 0 1 0 0
中断源 处理次序 屏蔽字（A B C D） 说明
D 1（最高） 1 1 1 1 全 1，谁都打不断 D
A 2 1 1 1 0 仅 D 位为 0（允许 D 打断 A）
C 3 0 1 1 0 D、A 位为 0（允许 D、A 打断 C）
B 4（最低） 0 1 0 0 D、A、C 位为 0（都可打断 B）

嵌套情形推演 1：CPU 正执行 B 的服务程序（屏蔽字 0100），此时 C 的请求到来——C 位为 0（开放），且 C 处理优先级高 → C 打断 B；C 执行中 D 又到来——D 位为 0 → D 打断 C。完整嵌套序列：

嵌套情形推演 2：CPU 正执行 D 的服务程序（屏蔽字 1111），B 的请求到来——B 被屏蔽，只能挂起等待；D 执行完毕返回后，若挂起的请求有多个（如 A、B、C 同时在等），则按硬件响应优先级 A>B>C>D 依次逐个响应（A、C、B）。

考点：屏蔽字例题的固定套路——先写处理次序，再按”屏蔽自己及更低、开放更高”逐行填 1/0；判断嵌套时只看现行程序的屏蔽字中该请求对应位是 0 还是 1。别忘了同一时刻多个挂起请求按响应优先级排队。
易错点：修改屏蔽字改变的只是处理优先级，响应优先级由硬件排队固定，不会因屏蔽字而变。

DMA 方式

DMA 方式的特点

DMA（Direct Memory Access，直接存储器访问）在主存与外设之间开辟直接数据通路，成块数据的传送完全由硬件（DMA 控制器）控制，传送期间不需要 CPU 执行程序来搬运数据。特点归纳：

  • 主存既可被 CPU 访问，也可被外设（经 DMAC）访问，主存中需开辟数据缓冲区；
  • 主存地址修改、传送计数等全由硬件直接实现；
  • CPU 与外设高度并行，传送速度快，适合磁盘等高速批量设备；
  • 在 DMA 方式中中断的作用仅为：数据传送结束（或出错）时通知 CPU——不像中断方式每个数据都中断一次。

DMA 控制器的组成

部件 功能
主存地址计数器（MAR） 存放交换数据在主存中的首地址，由 CPU 预置；每传一个数据自动 +1
传输长度计数器（WC） 存放要传送的字数（补码形式由 CPU 预置），每传一个自动 −1，减到 0 表示本块传送结束
数据缓冲寄存器（BR） 暂存设备与主存间传送的数据
命令 / 状态寄存器（CR） 接收 CPU 发来的 I/O 命令（读 / 写方向、启动）并存放 DMAC、设备的状态
DMA 请求触发器 设备准备好一个数据后置位，向 DMAC 提出 DMA 请求
中断机构（中断逻辑） 一块数据传送完毕（WC=0）时向 CPU 发出中断请求，请求做后处理

DMA 传送过程：三个阶段

阶段 由谁控制 操作
① 预处理（初始化） CPU 执行指令 向 DMAC 写入主存起始地址、传送字数、传送方向（读 / 写），启动设备；随后 CPU 继续执行原程序
② 数据传送 DMAC 硬件控制 设备每准备好一个数据就向 DMAC 发 DMA 请求 → DMAC 向 CPU 申请总线使用权（HOLD/HLDA 握手）→ 接管总线，完成”设备 ↔ 主存”一个数据的传送；循环直至 WC=0
③ 后处理 CPU 响应中断 DMAC 发中断 → CPU 执行中断服务程序：校验数据、决定是否继续传送、释放缓冲区等

考点：DMA 传送以块为单位，但每次挪用总线只传一个字（字节），传完即还总线；“预处理和后处理要 CPU 参与，中间传送不用”——这正是与中断方式的本质区别。DMA 结束时的中断叫**”DMA 结束中断”**，一句话常考：DMA 方式仍需要中断机构，但中断只在整块数据传送结束时发生一次。

DMA 与 CPU 的三种访存方式

DMA 与 CPU 都要访存，可能冲突，常用三种方式协调：

方式 原理 优缺点
停止 CPU 访存 DMA 传送期间 CPU 完全停止访存，整块让出总线 控制最简单，但 CPU 利用率低（成组传送）
周期挪用（周期窃取） DMA 趁 CPU 不访存的周期“偷”一个存储周期传一个数据 折中最常用；既有并行度又不至于长时间霸占总线
DMA 与 CPU 交替访问 把一个（存储）周期一分为二：C1​ 专供 DMA、C2​ 专供 CPU CPU、DMA 分时访存互不等待，无需总线申请归还，但硬件逻辑复杂

周期挪用时 DMA 请求与 CPU 访存的三种冲突情形：

情形 处理
CPU 此刻不访存 不冲突，DMA 直接挪用该周期
CPU 正在访存 DMA 等该存取周期结束后再挪用（不中断 CPU 的访存）
CPU 与 DMA 同时请求访存 I/O（DMA）优先，CPU 暂让总线（否则数据会丢失）

DMA 与中断方式的对比

对比项 程序中断方式 DMA 方式
数据传送单位 字 / 字节 数据块（成批）
数据通路 外设 → 接口 → CPU 寄存器 → 主存（CPU 执行程序搬运） 外设 ↔ 主存直接传送，不经 CPU
CPU 是否执行程序传送 是，每传一个数据执行一次中断服务程序 否，传送由 DMAC 硬件完成
CPU 介入程度 每个数据一次（响应 + 服务 + 返回） 仅预处理、后处理介入
响应时机 每条指令执行周期结束后才可响应 每个（存储/机器）周期结束后即可响应总线请求
现场保护 中断要保护 / 恢复现场（程序切换） DMA 不执行程序，不占用 CPU 寄存器等资源，无需保护现场
请求优先级 低 DMA 请求高于中断请求（数据实时性更强，晚了会丢失）
硬件开销 中断控制器、向量表 专用 DMAC（硬件复杂）
适用设备 中低速设备（键盘、鼠标） 高速块设备（磁盘、网卡）

DMA 每秒中断次数例题：主机经 DMA 从磁盘读 1 MB 文件，DMA 每次传送一块 4 KB 后向 CPU 发一次中断；若改用程序中断方式按每字节中断一次，比较两者的 CPU 介入次数。

  • DMA 方式：中断次数 = 220B/212B=256 次
  • 中断方式：中断次数 = 220=1048576 次
  • 相差 4096 倍——DMA 把”每个字节打断 CPU 一次”降为”每块打断一次”，这就是高速块设备必须用 DMA 的原因。

三种 I/O 方式综合对比

对比项 程序查询 程序中断 DMA
CPU 参与程度 全程忙等（100% 参与） 每个数据响应一次中断 仅预处理 / 后处理
数据传送单位 字 / 字节 字 / 字节 块
数据通路 接口 ↔ CPU 寄存器 接口 ↔ CPU 寄存器 设备 ↔ 主存直达
是否打断现行程序 不打断（但 CPU 也干不了别的，忙等） 打断，需保护 / 恢复现场 打断，但仅启动与结束各一次，不保护现场
CPU 与外设 串行工作 并行工作 高度并行
响应时机 —（CPU 主动查询） 指令执行周期结束 存取周期结束即可
传送控制方式 程序 程序（中断服务程序） 硬件（DMAC）
适用场景 低速、任务单一的系统 中低速设备（键盘、鼠标） 高速块设备（磁盘、网卡）

高频考点速记

考点 记忆
I/O 控制方式演进 查询 → 中断 → DMA → 通道，CPU 介入逐级减少
显存容量 分辨率 × log2​灰度级 / 8 B；1024×768、256 色 = 768 KB；刷新 >30 Hz 不闪烁
磁盘最小读写单位 扇区（块）；磁盘地址 = 驱动器号+柱面号+盘面号+扇区号
平均存取时间 寻道 + 平均旋转延迟（半圈）+ 传输时间；旋转延迟 = (60/转速)/2
数据传输率 C=n×r = 每道字节数 × 每秒转数；内圈磁道位密度最大
RAID 0 条带无冗余（100% 无容错）、1 镜像（50%）、4 专用校验盘、5 分布式校验（少一块容量）
统一 vs 独立编址 统一：访存指令、占内存空间、译码复杂；独立：IN/OUT 专用指令、不占内存、需控制线区分
中断隐指令 关中断、保存断点、引出服务程序入口——硬件自动；保护现场才是软件；响应需开中断 + 一条指令执行完
响应 vs 处理优先级 响应：硬件排队不可改；处理：屏蔽字可动态改
屏蔽字规则 1 屏蔽 0 开放；屏蔽自己及处理优先级更低的，开放更高的
多重中断条件 服务程序提前开中断 + 高优先级可打断低优先级
DMAC 组成 主存地址计数器（自动 +1）、传输长度计数器（−1 至 0 结束）、CR、BR、中断机构
DMA 三阶段 预处理（CPU 置参）→ 数据传送（DMAC 接管总线）→ 后处理（中断通知 CPU）
DMA 三种访存方式 停止 CPU / 周期挪用（最常用） / 交替访问；同时请求时 CPU 让给 DMA
中断 vs DMA 字节 vs 块；程序 vs 硬件；指令周期末 vs 存取周期末；DMA 请求优先级更高
