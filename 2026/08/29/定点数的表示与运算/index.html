定点数的表示与运算

2026-08-29
  • 计算机组成原理

定点数是小数点位置固定不变的数，是计算机表示数值数据最基本的方式。围绕它，408 考查一条完整的链路：进位计数制的相互转换 → 真值与机器数（原码/反码/补码/移码）→ 定点数的移位、加减、乘除运算 → 溢出判断 → 加法器与 ALU 的硬件实现。其中补码加减的溢出判断、原码/补码一位乘、原码除法（加减交替法）的逐步演算是大题重灾区，务必动手把每张演算表推一遍。

进位计数制及其相互转换

进位计数制：用有限数码、按”逢 r 进一”的规则计数。三个关键词：

概念 含义
基数 r 每个数码位可能出现 r 种字符（二进制 0/1，十六进制 0~F）
位权 第 i 位的权重为 ri（小数点左侧为正幂、右侧为负幂）
按权展开 (Kn​...K0​.K−1​...K−m​)r​=∑Ki​×ri

计算机采用二进制的原因：两个稳定状态的物理器件成本低、可靠；0/1 恰好对应逻辑假/真；逻辑门电路易于实现算术运算。

二进制与八进制、十六进制的相互转换

二进制 3 位一组对应 1 位八进制、4 位一组对应 1 位十六进制；分组以小数点为中心，整数部分向左、小数部分向右，两端不足补 0。

考点：分组方向记牢——整数向左、小数向右，补 0 只补在两端；八进制一位展开成 3 位、十六进制一位展开成 4 位。

十进制转换为 r 进制

  • 整数部分：除基取余——先取得的余数是低位，除到商 0 为止；
  • 小数部分：乘基取整——先取得的整数是高位，乘到小数部分为 0（或按精度取够位数）。

例题：把 (11.6875)10​ 转换为二进制。

易错点：十进制小数大多不能精确转换成二进制，如 (0.3)10​=0.0100110011...（0011 无限循环），此时按精度要求截取位数；”先余为低、先整为高”的方向不要写反。

真值与机器数

概念 含义
真值 带正负号的实际数值，符合人类书写习惯（如 +5、−0.75）
机器数 数值在机器内的存储形式，符号被数字化（通常 0 表正、1 表负）

无符号数：全部二进制位都是数值位、没有符号位，n+1 位无符号整数范围为 0∼2n+1−1。有符号数的机器码有四种：原码、反码、补码、移码。

原码、反码、补码、移码

四种机器码的定义

  • 原码：符号位 + 真值的绝对值。直观，但加减要单独处理符号、比较绝对值大小，硬件复杂。
  • 反码：正数同原码；负数符号位不变、数值位按位取反。主要作原码转补码的中间状态。
  • 补码：正数同原码；负数 = 反码末位 + 1。且 [[x]补​]补​=[x]补​。
  • 移码：在补码基础上只把符号位取反（相当于真值加偏置 2n），常用于表示浮点数的阶码。

负数原码转补码的快捷法：从右往左找到第一个 1，这个 1 及其右边各位不变、左边各位按位取反（符号位不变）。由 [x]补​ 求 [−x]补​ 则是连同符号位一起取反、末位加 1。

四种机器码大对比

码制 表示方式（n+1 位，n 位数值） 0 的表示 整数表示范围 加减运算便利性
原码 符号位 + 绝对值 2 个：+0 = 全 0，−0 = 10…0 −(2n−1)∼2n−1 符号单独处理、需比大小，最麻烦
反码 负数数值位取反 2 个：全 0、全 1 −(2n−1)∼2n−1 需处理循环进位，基本不单独使用
补码 负数取反加 1 唯一：全 0 −2n∼2n−1 符号位参与运算、减法变加法，最方便
移码 补码符号位取反 唯一：10…0 −2n∼2n−1 不直接做加减；保持大小顺序，便于比较

考点：补码比原码、反码多表示一个最小负数 −2n（8 位即 −128），它没有对应的原码和反码；定点小数补码范围为 −1∼1−2−n，同样多出一个 −1。
易错点：移码全 0 时真值最小、全 1 时真值最大，大小顺序与真值一致——这正是浮点数阶码采用移码、可按无符号数方式直接比较两个浮点数大小的原因。

字符与字符串

ASCII 码

ASCII 用 7 位二进制表示 128 个字符，计算机中用 1 字节存储、最高位为 0；00H~1FH 为控制字符（换行 LF = 0AH、回车 CR = 0DH），20H~7EH 为可打印字符。

字符 ASCII（十进制） 记忆点
‘0’ ~ ‘9’ 48 ~ 57（30H ~ 39H） 数字字符 = 30H + 数值
‘A’ ~ ‘Z’ 65 ~ 90（41H ~ 5AH） 大写从 65 开始
‘a’ ~ ‘z’ 97 ~ 122（61H ~ 7AH） 小写 = 大写 + 32（差 bit5）
空格 32（20H） 最小的可打印字符

汉字编码与 UTF-8

  • GB2312：双字节编码，收录 6763 个汉字；国标码 = 区位码 + 2020H，汉字内码 = 国标码 + 8080H（最高两位置 1，避免与 ASCII 混淆）。
  • UTF-8：Unicode 的变长编码，占 1~4 字节，与 ASCII 完全兼容——英文字符 1 字节（’A’ 与 ASCII 相同），常用汉字 3 字节（’中’ = 11100100 10111000 10101101）。

字符串的存储与大小端

C 语言字符串以空字符 '\0' 结尾（strlen 不计入结尾的 \0）；也可用长度字段（Pascal 风格）或定长补空格存储。多字节数据在内存中的字节顺序分两种：

方式 规则 典型场景
大端（Big-Endian） 最高有效字节（MSB）存最低地址 网络字节序、Java 虚拟机
小端（Little-Endian） 最低有效字节（LSB）存最低地址 x86/x64

考点：给一段内存字节序列判断大小端——最低地址放高字节是大端，放低字节是小端；网络程序跨主机传输需统一按网络字节序（大端）转换。

定点数的表示

定点数的小数点位置固定且隐含、不占存储位：定点整数小数点隐含在最低位之后，定点小数小数点隐含在符号位之后、数值位之前。

设字长 n+1 位（1 位符号 + n 位数值），表示范围：

码制 定点整数 定点小数
原码 −(2n−1)∼2n−1 −(1−2−n)∼1−2−n
补码 −2n∼2n−1 −1∼1−2−n
无符号数 0∼2n+1−1 0∼1−2−(n+1)

考点：定点数运算简单、硬件成本低，但范围有限、精度固定；浮点数靠阶码浮动小数点位置来扩大范围（IEEE 754 另文整理）。

定点数的移位运算

算术移位针对带符号数，移位后符号位保持不变；逻辑移位把整个字长当作无符号位串整体移动。添补代码规则：

码制 / 类型 算术左移（高位丢） 算术右移（低位丢）
原码（正数、负数） 数值位补 0，符号不变 数值位补 0，符号不变
补码正数 补 0 补 0
补码负数 低位补 0 高位补 1
反码负数 补 1 补 1
逻辑移位（无符号） 低位补 0 高位补 0

规律：正数一律补 0；负数——原码补 0、反码补 1、补码”左 0 右 1“。

  • 移位与乘除：算术左移一位 = ×2（可能溢出）；右移一位 = ÷2（补码负数右移向下取整，−1≫1=−1）。
  • 循环移位：不带进位位 CF 时数值位自身首尾相接循环；带 CF 时 CF 一起进入循环（大循环），常用于字节交换、检测移位中丢失的位。

定点数的加减运算

补码加减法

[A+B]补​=[A]补​+[B]补​ (mod 2n+1)[A−B]补​=[A]补​+[−B]补​
  • 符号位与数值位一起参与运算，符号位产生的进位直接丢弃；
  • 求 [−B]补​：把 [B]补​ 连同符号位一起取反、末位加 1。硬件上减法 = “B 取反 + 最低位进位置 1” 的加法，与加法共用同一套加法器；
  • 原码加减则须符号单独处理：同号相加绝对值相加、符号不变；异号相加绝对值大减小、符号随大数。

例题（机器字长 8 位 = 双符号位 + 6 位数值，x=+50，y=−39，求 [x+y]补​、[x−y]补​ 并判断溢出）：

溢出概念与判断方法

溢出（Overflow）：运算结果超出该字长能表示的范围。只有同号相加（或异号相减）才可能溢出，一正一负相加绝不可能溢出。三种判断方法：

方法 判断规则 逻辑表达式
单符号位法 同号相加，结果符号与操作数相反则溢出 V=AS​BS​SS​​+AS​​BS​​SS​
进位判断法 符号位进位 Cs​ 与最高数值位进位 C1​ 不同则溢出 V=Cs​⊕C1​
双符号位法 结果两符号位不同则溢出：01 正溢出、10 负溢出 V=SS1​⊕SS2​
  • 双符号位（变形补码/模 4 补码）：00 表正、11 表负，最高一位才是真正的符号位；存储时可只存一个符号位，运算时复制成两位；
  • 无符号数越界看 CF：加法最高位有进位即溢出；减法 CF=Cout​⊕Sub（Cout​=0 表示不够减、有借位）。

考点：上例 (2) 改用单符号位验证：0 110010 + 0 100111 = 1 011001，正 + 正 = 负，溢出；此时 Cs​=0、C1​=1，0⊕1=1——三种方法结论一致，真符号以双符号位的最高位为准。

定点数的乘法运算

原码一位乘法

  • 符号位不参与数值运算：积的符号 Ps​=Xs​⊕Ys​（同号正、异号负）；
  • 数值部分取绝对值相乘：部分积 A 初值 0（用双符号位暂存进位），每轮看乘数末位——为 1 加被乘数绝对值、为 0 加 0，随后 A 与乘数寄存器 C 联合逻辑右移一位（高位补 0），A 移出的低位进入 C；
  • n 位数值共 n 次加法、n 次右移，乘积 = A 的数值部分（高位）拼接 C 中移入的低位。

例题：x=0.1101，y=−0.1011，用原码一位乘求 x×y。

补码一位乘法（Booth 算法）

补码乘法符号位直接参与运算。乘数取补码（连同符号位），末位附加一位辅助位 Yn+1​=0；每步根据乘数寄存器最低位 Yn​ 与辅助位 Yn+1​ 决定操作：

Yn​ Yn+1​ 操作
0 0 部分积 + 0，算术右移一位
0 1 部分积 +[X]补​，算术右移一位
1 0 部分积 +[−X]补​，算术右移一位
1 1 部分积 + 0，算术右移一位

口诀：看相邻两位的差——“01 加 [X]补​，10 加 [−X]补​，00/11 不加”。n 位数值共 n+1 次加法、n 次移位，最后一步加法后不再移位；部分积与被乘数均用双符号位补码，移位是算术右移（符号位不变，负数补 1）。

例题：x=0.1101，y=−0.1011，用 Booth 算法求 [x×y]补​。

易错点：Booth 乘数寄存器的位会逐步被部分积低位替换，判断对象始终是当前的最低两位（含辅助位）；与原码一位乘的”逻辑右移补 0”不同，Booth 是算术右移，负数部分积高位补 1。

定点数的除法运算

原码除法同样符号位单独处理（商符 = 两数符号异或），数值部分取绝对值做无符号除法，核心是”左移 — 试减 — 上商“：余数 R 减去除数，够减（R ≥ 0）商 1，不够减（R < 0）商 0。

方法 不够减时 每步加法次数 速度
恢复余数法 加回除数恢复原余数，再左移试减 1~2 次（不固定） 慢
加减交替法（不恢复余数法） 不恢复，下一步左移后改加除数 固定 1 次 快约一倍

加减交替法的依据：某步余数 Ri​<0 时，”恢复后左移再减” = 2(Ri​+∣Y∣)−∣Y∣=2Ri​+∣Y∣，故直接左移加除数完全等价且省一次加法。

例题：x=1101（13），y=0011（3），用加减交替法求商与余数（减法用补码实现）。

若用恢复余数法：上例第 1、3、4 步不够减时都要先”加回除数恢复”，再左移、下一步重新试减，步骤相同但每步多一次加法，最终结果一致。

易错点：”够减看余数正负”只对原码除法成立；补码除法（加减交替）符号位参与运算、够减看余数与除数是否同号，且末位商恒置 1——两套规则不要混用。

串行加法器与并行加法器

一位全加器与串行进位加法器

全加器有三个输入（本位加数 Ai​、Bi​，低位进位 Ci−1​）、两个输出：

Si​=Ai​⊕Bi​⊕Ci−1​Ci​=Ai​Bi​+(Ai​⊕Bi​)Ci−1​

把 n 个全加器级联、低位进位输出接高位进位输入，就是 n 位串行进位加法器（行波进位加法器，Ripple-Carry Adder）：

  • 优点：结构简单、硬件成本最低；缺点：高位必须等低位进位逐级传上来，延迟与字长 n 成正比，速度慢；
  • 它天然提供 Cn​（符号位进位）与 Cn−1​（最高数值位进位），一个异或门即可检测带符号数溢出：OF=Cn​⊕Cn−1​。

并行进位加法器（先行进位 CLA）

CLA（Carry Look-ahead Adder）的核心思想：把进位表达式逐位展开，使每位进位只依赖本位输入 Ai​、Bi​ 和最低位进位 C−1​，从而所有进位并行产生、一级门延迟形成。定义两个辅助函数：

  • 进位生成函数：Gi​=Ai​Bi​——本位两数都为 1，必定产生进位；
  • 进位传递函数：Pi​=Ai​⊕Bi​——本位有 1，低位进位可以穿过本位传向高位。

C0​=G0​+P0​C−1​
C1​=G1​+P1​G0​+P1​P0​C−1​
C2​=G2​+P2​G1​+P2​P1​G0​+P2​P1​P0​C−1​
C3​=G3​+P3​G2​+P3​P2​G1​+P3​P2​P1​G0​+P3​P2​P1​P0​C−1​

例：A=1011（11），B=0111（7），C−1​=0。

考点：位数增大时 Ci​ 展开式过长，受门电路扇入限制，实际采用分组实现——单级先行进位（组内并行、组间串行）与多级先行进位（组间也并行，引入组生成 G∗、组传递 P∗，公式与位级完全同构）。16 位加法器常分 4 组、每组 4 位。

对比 串行进位（行波） 并行进位（CLA）
进位产生 逐级等待，Ci​ 依赖 Ci−1​ 展开并行、同时产生
延迟 O(n) 级门延迟 O(1) 级门延迟
硬件成本 低（n 个全加器级联） 高（额外的进位生成逻辑）

算术逻辑单元 ALU

ALU（算术逻辑单元）是运算器的核心，属于组合逻辑电路（无记忆，输出仅由当前输入决定）：既做加减等算术运算，也做与/或/非/异或等逻辑运算（逻辑运算按位独立、不产生进位）。

  • MUX 选择运算：内部算术单元（加法器）与逻辑单元的结果由**多路选择器（MUX）**按 ALUop 选择输出；Sub 就是 ALUop 之一——Sub=1 时 B 取反、最低位进位置 1，同一套加法器即可做减法；
  • 经典芯片 74181：4 位 ALU，M=0 做 16 种算术运算、M=1 做 16 种逻辑运算；多片 74181 配合先行进位芯片 74182 可级联成任意位宽的 ALU；
  • 四个标志位的生成（详细在 CPU 章）：
标志 生成逻辑 含义
ZF 结果全部位或非 结果为 0（可用于比较相等）
SF 取结果最高位 Fn−1​ 结果符号（带符号数才有意义）
OF Cn​⊕Cn−1​ 带符号数溢出
CF Cout​⊕Sub 无符号数进位/借位

考点：带符号数溢出看 OF、无符号数越界看 CF——同一套加法器硬件，仅按标志位区别解释；条件转移指令正是读取这些标志位实现分支。

高频考点速记

考点 记忆
