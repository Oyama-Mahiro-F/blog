归并排序、基数排序与外部排序

2026-08-09
  • 数据结构&算法

这三种排序的共同点是都采用”分治/归并”或”分配/收集”的思路，而非逐个插入或交换：

算法 核心操作 时间复杂度 空间 稳定性
归并排序 合并两个有序子序列 O(nlogn) O(n) 稳定
基数排序 按位”分配 → 收集”，不比较 O(d(n+r)) O(n+r) 稳定
外部排序 多路归并 + 败者树 取决于 I/O 趟数 内存工作区 w 取决于内排序

归并排序

归并排序是分治算法：将两个有序子序列合并为一个有序序列。初始时每个元素看作一个长度为 1 的有序子序列，然后两两合并，直到整个序列有序。

非递归实现避免了递归调用栈的 O(logn) 空间开销。每趟 Merge_pass 将子序列长度 d 翻倍，经 ⌈log2​n⌉ 趟后，整个序列有序。

算法分析

具有 n 个待排序记录的归并次数是 ⌈log2​n⌉，一趟归并的时间复杂度为 O(n)，则整个归并排序的时间复杂度无论最好还是最坏情况均为 O(nlog2​n)。

排序过程中使用了辅助向量 DR[]，大小与待排序记录空间相同，则空间复杂度为 O(n)。

归并排序是稳定的（R[i].key < R[j].key 保证左半优先）。

项目 说明
时间复杂度 O(nlogn)（最好/最坏/平均均如此）
空间复杂度 O(n)（辅助数组 DR[]）
稳定性 稳定

归并排序是稳定排序中时间复杂度最优的 O(nlogn) 算法。

基数排序

基数排序（Radix Sorting，又称桶排序或数字排序）：按待排序记录的关键字组成成分（或”位”）进行排序。它和前面各种内部排序方法完全不同——不需要进行关键字的比较和记录的移动，借助多关键字排序思想实现单逻辑关键字的排序。

多关键字排序思想

最高位优先（MSD, Most Significant Digit first）：先按第一个关键字 K1 排序分组，再对每个子序列按 K2 排序……最后将所有子序列依次联接成有序序列。

最低位优先（LSD, Least Significant Digit first）：与 MSD 相反，排序顺序从最低位开始——先按 Kd 排序，再按 Kd−1，直到 K1。

LSD 基数排序过程

从最低位开始，依次对每一位进行”分配 → 收集”，高位在后保证高位权重更大。

链式基数排序实现（LSD）

① 首先以静态链表存储 n 个待排序记录；

② 一趟排序过程：

  • 分配：按当前位 Kd 的值，改变记录指针，将链表中的记录分配到 r 个链表（桶）中，用 f[i]、e[i] 作为第 i 个链表的头结点和尾结点；
  • 收集：改变所有非空链表的尾结点指针，使其指向下一个非空链表的第一个结点，将 r 个链表重新链接成一个链表；

③ 依次按 Kd−1,Kd−2,…,K1 进行，共 d 趟排序后完成。

一趟分配：遍历链表，按当前位的值分入 r 个桶；一趟收集：将 r 个桶首尾相连，重新形成链表。

性能分析

项目 说明
时间复杂度 O(d(n+r))，d 为位数，r 为基数
空间 O(r+n)（需要 r 个队列）
稳定性 稳定

基数排序适用于 n 大但 d 小的场景，且关键字能拆分为多个独立的”位”。

外部排序

当数据量大到无法全部放入内存时，需要进行外部排序。外排序的基本方法是归并排序法，分为两个步骤：

(1) 生成若干初始归并段（顺串）——文件预处理：

① 把含有 n 个记录的文件，按内存大小 w 分成若干长度为 w 的子文件（归并段）

② 分别将各子文件调入内存，采用有效的内排序方法排序后送回外存。产生 m=⌈n/w⌉ 个初始归并段。

(2) 多路归并：对这些初始归并段反复进行归并，直到得到整个有序文件。

多路平衡归并与败者树

增加归并路数 k 可以减少归并趟数，从而减少磁盘 I/O 次数。

概念 说明
归并趟数 s=⌈logk​m⌉（m 为初始归并段数）
最佳归并树 用哈夫曼树思想构造 I/O 次数最少的归并顺序

在 k 路归并中，每次需从 k 个归并段的当前第一个记录中选出最小值。若每次简单比较，需 k−1 次比较。败者树将 k 个归并段组织为一棵完全二叉树，每次选最小仅需 ⌈log2​k⌉ 次比较。

(1) 初始化：每个叶子结点代表一个归并段，其值为该归并段的当前最小关键字。非叶结点存储”败者“（比较中较大值对应的段号），根结点之上再设一个结点存储”冠军“。

(2) 比较过程：从叶子开始两两比较，败者（较大值）存入父结点，胜者继续向上。

(3) 重构：输出最小值后，读入该段下一个记录，沿路径向上更新败者。

每选一个最小记录仅 ⌈log2​k⌉ 次比较（vs k−1 次），总比较 n⌈log2​k⌉。

置换-选择排序

常规方法生成的初始归并段长度受限于内存大小 w，产生 m=⌈n/w⌉ 个段。置换-选择排序可以在内存大小不变的前提下，生成更长的初始归并段，从而减少段数 m 和归并趟数。

算法思想：

  • 利用一个大小为 w 的内存工作区（败者树 / 小顶堆）
  • 每次选出当前工作区中 ≥ 上一个输出值的最小关键字输出
  • 若所有剩余关键字都 < 上一个输出值，则该归并段结束，开始新的一段

算法步骤：

  1. 从输入文件读入 w 个记录到内存工作区
  2. 从工作区选出最小关键字的记录输出，作为当前归并段的第一个记录
  3. 从输入文件再读入一个记录替换输出者
  4. 从工作区选出 ≥ 上一个输出值的最小关键字输出；若找不到（所有都 < 上一个输出），则该归并段结束，重新选最小开始新的一段
  5. 重复 ③④，直到输入文件读完且工作区为空

常规方法（w=3）产生 ⌈9/3⌉=3 个段；置换-选择排序仅产生 2 个段，且 Run1 长度达 8。

最佳归并树

置换-选择排序产生的各初始归并段长度可能不相等。在 k 路归并时，若简单按顺序归并，总 I/O 次数不一定最少。最佳归并树利用哈夫曼树思想：将权值（段长）越小的归并段放在越靠近根的位置进行归并，使总 I/O 量最小。

构造方法（以 k=3 路归并为例，5 个归并段长 [2,3,6,9,12]）：

虚段处理：当初始归并段数 m 不满足 (m−1)mod(k−1)=0 时，需补充虚段（长度为 0）。虚段数 =(k−1)−(m−1)mod(k−1)（除余为 0 时不补）。

三者对比

项目 归并排序 基数排序 外部排序
适用 内部排序 内部排序（关键字可拆位） 外部（数据放不进内存）
核心 合并有序段 按位分配收集 生成归并段 + 多路归并
时间 O(nlogn) O(d(n+r)) 取决于 I/O 趟数 s=⌈logk​m⌉
空间 O(n) O(n+r) 内存工作区 w
稳定性 稳定 稳定 取决于所用内排序
是否比较 比较 不比较不移动 比较

记忆锚点：归并是”稳定且 O(nlogn) 的唯一选择”；基数是”唯一不比较的排序”；外部排序的本质是”用败者树减少比较、用置换-选择减少段数、用最佳归并树减少 I/O”。

考点 记忆
归并排序 共 ⌈log2​n⌉ 趟，每趟 O(n)，总 O(nlogn)；辅助数组空间 O(n)；稳定且为稳定中最优
基数排序 不比较不移动，LSD 从低位”分配→收集” d 趟；时间 O(d(n+r))、空间 O(n+r)；稳定
基数排序适用场景 n 大 d 小
外部排序流程 ①生成初始归并段 m=⌈n/w⌉ ②多路归并；归并趟数 s=⌈logk​m⌉
败者树 完全二叉树，非叶存败者、根上结点存冠军；每选最小仅 ⌈log2​k⌉ 次比较
置换-选择排序 工作区选 ≥ 上一输出的最小关键字输出，生成更长初始归并段、减少趟数
最佳归并树 哈夫曼思想：段长小的靠根归并，总 I/O 最小；虚段数 =(k−1)−(m−1)mod(k−1)
比较次数与初始状态无关 基数、简单选择（+ 堆排序）
