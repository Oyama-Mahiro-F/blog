图的存储结构：邻接矩阵与邻接表

2026-08-09
  • 数据结构&算法

图的存储要兼顾”判边快慢”与”空间开销”两件事。两种方式各有侧重：邻接矩阵用二维数组、$O(n^2)$ 空间换 $O(1)$ 判边，适合稠密图；邻接表用 $n$ 条单链表、$O(n+e)$ 空间换遍历邻接点的便利，适合稀疏图。

存储结构 空间 判边 适合
邻接矩阵 $O(n^2)$ $O(1)$ 稠密图
邻接表 $O(n+e)$ $O(\deg)$（遍历链表） 稀疏图

邻接矩阵

用二维数组 adj[][] 存储顶点间的边/弧关系，物理上是一张 $n\times n$ 的表。

结构定义

关键性质

图类型 元素值 特殊性质
无向图 1 有边 / 0 无边 对称矩阵；第 $i$ 行非零数 = 度；1 的总数 = $2e$
无向带权图 $w_{ij}$ / $\infty$ 对称矩阵；第 $i$ 行非 $\infty$ 数 = 度；非 $\infty$ 总数 = $2e$
有向带权图 $w_{ij}$ / $\infty$ 一般不对称；第 $i$ 行非 $\infty$ 数 = 出度；第 $j$ 列非 $\infty$ 数 = 入度

复杂度

操作 时间复杂度
插入顶点 $O(n)$（初始化新行列）
插入/删除边 $O(n)$（LocateVex 遍历）/ $O(1)$（已知下标）
求第一个/下一个邻接点 $O(n)$（遍历一行）
删除顶点 $O(n^2)$（双重循环压缩行列）

易错点：邻接矩阵的”第 $i$ 行非零数 = 度”只对无向图成立；有向图的行统计的是出度、列统计的是入度，两者不等，审题时务必分清。

邻接表

对图中每个顶点建立一个单链表，链表中结点存放该顶点的所有邻接点。$n$ 个顶点就有 $n$ 个链表。

结点结构

  • adjvex：邻接点在顶点表中的下标（关键字段）
  • weight：边的权值（无权图可省略或置 1）
  • next：指向下一个边表结点（同一顶点的下一条出边）

考点：邻接表插入边用头插法，新结点始终插在链表头部，复杂度严格 $O(1)$，与链表长度无关。

邻接矩阵 vs 邻接表

维度 邻接矩阵 邻接表
空间 $O(n^2)$ $O(n+e)$
判边 $O(1)$ $O(\deg)$（需遍历链表）
遍历邻接点 $O(n)$ $O(\deg_i)$
入度（有向图） 遍历列 $O(n)$ 需逆邻接表
适合 稠密图 稀疏图

易错点：遍历结果唯一性不同——邻接矩阵（基于顶点下标顺序）的遍历结果唯一；邻接表依赖链表的内存/插入顺序，遍历结果不唯一。

引子：十字链表与邻接多重表

当两种基础结构各自有短板时，另有两种”升级版”链式存储专门补齐：

  • 十字链表（有向图）：每个弧结点同时挂出弧链（tlink）与入弧链（hlink），可同时高效求得出度与入度。
  • 邻接多重表（无向图）：每条边只存一次，删除边/弧、判断两顶点是否邻接都更方便，避免了邻接表每条无向边存两次的冗余。

高频考点速记

考点 记忆
邻接矩阵 空间 $O(n^2)$、判边 `O(1)，适合稠密图
无向图矩阵 对称；第 $i$ 行非零数 = 度；1 总数 = $2e$
有向图矩阵 第 $i$ 行非零数 = 出度、第 $j$ 列非零数 = 入度
邻接表 空间 $O(n+e)$、判边 `O(deg)，适合稀疏图
边表结点数 无向图边表结点 $2e$ 个、有向图 $e$ 个
头插法 新结点始终插入链表头部 $O(1)，不依赖链表长度
遍历唯一性 邻接矩阵结果唯一；邻接表不唯一（依赖链表顺序）
升级结构 有向图求入度用十字链表、无向图删边用邻接多重表
