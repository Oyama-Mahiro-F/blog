队列：循环队列、链式队列与双端队列

2026-08-09
  • 数据结构&算法

队列（Queue）是只允许在一端插入、另一端删除的线性表，遵循 FIFO（先进先出）。插入端叫队尾（rear），删除端叫队头（front）。

三种实现方式各有分工：

实现 存储 核心问题 判满
循环队列 顺序（数组） 假溢出 → 取模绕回解决 (rear+1) % MAXSIZE == front
链式队列 链式（链表） 无假溢出，天然动态 不存在（除非内存耗尽）
双端队列 两端都可入可出 合法输出序列判断 视受限类型而定

循环队列（顺序实现）

顺序队列用数组存储，rear 只会单调递增，导致 front 之前腾出的空间无法被利用——这就是假溢出 (False Overflow) 问题。解决办法：循环队列——将数组逻辑上视为环形，当指针到达数组末尾时通过取模运算绕回头部：

rear=(rear+1)modMAXSIZE
front=(front+1)modMAXSIZE

核心难点：判空 vs 判满

循环队列中 front == rear 既是空队条件也是满队条件，必须区分！三种经典方案：

方案 判空条件 判满条件 元素个数 特点
牺牲一个单元 Q.front == Q.rear (Q.rear + 1) % MAXSIZE == Q.front (Q.rear - Q.front + MAXSIZE) % MAXSIZE 408 最常考，默认方案
增设 size 变量 Q.size == 0 Q.size == MAXSIZE Q.size 直观，需增加 size 字段
增设 tag 标记 front==rear && tag==0 front==rear && tag==1 取决于 tag tag=0 上次出队，tag=1 上次入队

考研默认采用牺牲一个单元方案。最大容纳元素数 = MAXSIZE - 1。

核心操作（牺牲一个单元方案，408 默认）

front = rear = 0 为初始值，rear 指向下一个空位。

操作 核心步骤
入队 Q.data[Q.rear] = x; Q.rear = (Q.rear + 1) % MAXSIZE（先存再移），O(1)
出队 x = Q.data[Q.front]; Q.front = (Q.front + 1) % MAXSIZE（先取再移），O(1)
读队头 x = Q.data[Q.front]，不修改 front，O(1)

front 和 rear 的初始化方式（考研必背）

特性 方式一 f=r=0 方式二 f=0,r=-1
rear 含义 下一个空位 当前队尾元素
初始值 front = 0, rear = 0 front = 0, rear = -1
判空 Q.front == Q.rear Q.front > Q.rear
判满（牺牲单元） (Q.rear + 1) % MAXSIZE == Q.front 不适用于循环队列
入队 先存再移 rear 先移 rear 再存
出队 先取再移 front 先取再移 front
元素个数 (Q.rear - Q.front + MAXSIZE) % MAXSIZE Q.rear - Q.front + 1

考研提醒：408 默认采用方式一（front = rear = 0，rear 指向队尾下一位置，牺牲一个单元判满）。审题时先看清初始化值，再推导对应代码！

链式队列

链式队列（Linked Queue）用链表实现队列，front 指向队头、rear 指向队尾。链式队列不会满、不需要循环——天然没有假溢出问题。

核心设计原则：入队在 rear 端（尾插法）、出队在 front 端（头删法），均为 O(1)。队头必须设在链表头部（否则出队找前驱退化为 O(n)）。

结构定义

带头结点链式队列（408 最常考，逻辑统一）

头结点不存数据，front 永远指向头结点，第一个数据结点由 front->next 访问。

项目 内容
初始状态 front 和 rear 都指向新创建的头结点
判空 Q.front == Q.rear（头尾指针重合）
入队核心 Q.rear->next = s; Q.rear = s（尾插法），空队插入无需特殊处理
出队核心 p = front->next; front->next = p->next; free(p)
关键边界 出队最后一个元素后 Q.rear = Q.front 恢复空队

不带头结点链式队列

front 直接指向第一个数据结点。空队列时 front = rear = NULL。入队第一个元素需要特殊处理。

项目 内容
判空 Q.front == NULL
空队入队 Q.front = Q.rear = s（两指针都指向新结点）
出队最后元素 额外判断 Q.rear == p → Q.rear = NULL

带头 vs 不带头对比

维度 带头结点 不带头结点
初始值 front = rear = malloc(…); front->next = NULL front = rear = NULL
判空 Q.front == Q.rear Q.front == NULL
入队（空队） 无需特殊处理 Q.front = Q.rear = s（特殊处理）
出队（最后） Q.rear = Q.front Q.rear = NULL
考研倾向 ★ 408 最常考，逻辑统一 需要多种边界判断

双端队列 (Deque)

定义

允许在两端都进行插入和删除操作。是栈和队列的泛化形式。

图：双端队列示意——左端与右端均可进行入队与出队操作。

分类

类型 左端入 左端出 右端入 右端出 说明
双端队列 ✓ ✓ ✓ ✓ 全功能，两端均可入可出
输入受限双端队列 ✗ ✓ ✓ ✓ 只能从一端插入，两端均可删除
输出受限双端队列 ✓ ✓ ✓ ✗ 两端均可插入，只能从一端删除

考研核心考点：合法序列判断

给定输入序列 1, 2, 3, 4，判断某个输出序列能否由特定类型的双端队列生成。

  • 解题关键：模拟过程，逐个检查目标序列中的元素是否可以从左端或右端合法进入/离开。
  • 常见结论：
    • 普通队列（一端入一端出）：输出序列唯一（即输入序列本身）。
    • 双端队列：合法序列数量远超普通队列，但少于栈（卡特兰数）。
    • 具体题目中需画图模拟，不可记结论。

三种队列实现对比

维度 循环队列（顺序） 链式队列 双端队列
核心问题 假溢出 → 循环队列解决 无（天然动态） 合法输出序列判断
容量 有限（MAXSIZE - 1） 无限（仅受物理内存） 视实现而定
判满 (rear+1) % MAXSIZE == front 不存在 视实现而定
入队/出队 O(1)（偶尔扩容 O(n)） 严格 O(1) 两端均 O(1)
适用场景 元素个数可预估 元素个数未知、波动极大 需要两端操作（如滑动窗口）

栈 vs 队列 对比总结

维度 栈 (Stack) 队列 (Queue)
原则 LIFO 后进先出 FIFO 先进先出
插入端 栈顶 (top) 队尾 (rear)
删除端 栈顶 (top) 队头 (front)
顺序实现核心问题 上溢出 (overflow) 假溢出 (false overflow)
顺序实现解决方案 动态扩容 / 共享栈 循环队列（取模运算）
链式实现判空 S.top->next == NULL Q.front == Q.rear
双端版本 — 双端队列 (Deque)
经典应用 括号匹配、表达式求值、DFS、函数调用 层次遍历、BFS、进程调度
