单链表：建立、查找、插入删除与去重

2026-08-09
  • 数据结构&算法

单链表通过”指针”将一个个零散的内存块（节点）串联起来。每个节点包含数据域 (data) 和指针域 (next)。

头结点机制：头指针指向头结点；头结点不存放数据。

  • 有头结点：判空条件 p->next == NULL
  • 无头结点：判空条件 p == NULL

贯穿全文的两条铁律：
① 钩链顺序永远是「先连后面大部队，再让前驱牵自己」——顺序反了会断链 + 内存泄漏。
② 删除时前驱指针原地不动，只让探路指针接手 p->next，否则连续重复项会漏网。

建立：头插法与尾插法

头插法（逆序建表）

“后来居上”——每次新来的节点都抢占”第一名”的位置，紧紧贴在头结点后面。核心两步钩链：先连后面大部队，再让前驱牵自己（防止断链）。

特点：输入顺序与链表顺序相反（逆序建表），时间复杂度 O(n)。

尾插法（顺序建表）

“先来后到，排队上车”——核心在于维护一个尾指针 r (rear)，每来一个节点挂在最后面，然后尾指针后移。

特点：输入顺序与链表顺序一致（顺序建表），时间复杂度 O(n)。

查找：按序号与按值

与顺序表（数组）O(1) 的随机访问不同，单链表的物理内存是分散的。要想找到第 i 个元素，唯一办法就是”顺藤摸瓜”：从头结点开始，顺着 next 指针一节一节往后数。因此单链表只能顺序存取，查找复杂度 O(n)。

遍历时指针移动的三种基本操作：

  • q = p（共享同一节点）：没有产生新的物理节点，只是让 q 和 p 指向内存中的同一个实体：
  • q = p->next（探路）：q 越过 p，直接获取后继节点的地址，常用于遍历或删除前的”锁定”目标：
  • p = p->next（指针后移）：p 放弃当前节点，更新指向为下一个节点，是遍历链表的”履带行进”：

插入与删除

单链表插入/删除的核心都是”寻找前驱“。已知位置时插入/删除仅需改指针，O(1)；按位操作需先遍历找前驱，O(n)。

按位插入（在第 i 个位置插入元素 e）

黄金法则：先连后面大部队，再让前驱牵自己——指针赋值顺序绝对不能反！

如果先执行 p->next = s;，那么 p 原本后面的节点地址就彻底丢失了——内存泄漏 + 链表断裂！

按序号删除（删除第 i 个节点）

删除解剖三步曲：长途跋涉找前驱 → 派驻哨兵防泄漏 → 逻辑跨越与物理超度。

按值删除：删除第一个值为 key 的节点

短路求值拦截崩溃：while (q != NULL && q->data != key) 中，若链表中没有 key，q 最终变成 NULL，短路求值会直接跳出循环；顺序写反会因访问 NULL->data 崩溃！

按值删除：删除所有值为 key 的节点

核心灵魂：删除发生时 p 绝对不能动！删除一个 key 后，q 接手 p->next 继续探测，防止连续相同 key 漏网。

经典例题：删除重复节点

在无序链表中，重复的元素可能隔得很远（如 10 -> 20 -> 30 -> 10）。彻底去重需要三个指针各司其职：”双层嵌套循环 + 三指针暴力扫荡”。

核心战术：为什么要用三个指针？

  1. 锚点 p（基准）：站在原地的指挥官。如果 p 站在 10 上，它就向后下达命令：”后面所有人，谁也是 10，格杀勿论。”
  2. 巡视员 ptr（探路）：顺着链表往下挨个查身份证，看是否跟指挥官 p 的值一样。
  3. 行刑者 q（前驱）：ptr 的影子。删除操作永远离不开前驱节点，所以 q 必须死死跟在 ptr 后面，一旦 ptr 被核实为重复项，q 立即执行绕过和断链。

算法实现

关键细节

  • 删除后 q 不动、ptr 接替：与”删所有 key”同理，ptr = q->next 保证连续重复也能被连续切除
  • 保留首次出现：外层 p 逐个做基准，内层只删 p 之后的重复项，首次出现的节点天然保留
  • 时间复杂度：O(n2)（双层嵌套循环），空间 O(1)
