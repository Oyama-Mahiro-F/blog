并查集算法（Disjoint Set Union）

2026-08-09
  • 数据结构&算法

并查集用双亲表示法（树结构）管理不相交集合。支持两种操作：查（Find，找根）和并（Union，合并）。

核心思想：每个集合用一棵树表示，树的根代表整个集合。parent[i] 存结点 i 的双亲，根结点的 parent = -1。

查找 Find（朴素版）

沿着 parent 链一直向上，直到找到根（parent = -1）。

合并 Union（朴素版）

将一棵树的根挂到另一棵树的根下面。

路径压缩优化（Find 优化）

查找时把沿途所有结点直接挂到根下面，摊还后接近 O(1)。

按秩合并优化（Union 优化）

将矮树挂到高树下面，避免退化成链。需要额外 rank[] 数组。

完整实现（路径压缩 + 按秩合并）

双优化后 Find 和 Union 的摊还时间复杂度接近 O(α(n))，其中 α 是反阿克曼函数，实际中可视为常数。

考点 记忆
并查集查/并 Find 找根（parent==-1），Union 将一树根挂另一树根下

按秩合并 矮树挂高树下，避免退化为链（O(log n)）
