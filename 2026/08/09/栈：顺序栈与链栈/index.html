栈：顺序栈与链栈

2026-08-09
  • 数据结构&算法

栈（Stack）是只允许在一端（栈顶）进行插入和删除的线性表，遵循 LIFO（后进先出）。两种存储实现各有讲究：

实现 存储 判满 入栈/出栈
顺序栈 连续数组 top == MAXSIZE（静态）/ 自动扩容（动态） O(1)，扩容瞬间 O(n)
链栈 单链表 不存在（malloc 失败才满） 严格 O(1)（头插/头删）

贯穿两种实现的铁律：栈顶必须锚定在数组末端 / 链表头部——否则入栈找尾、出栈找前驱都会退化成 O(n)。

顺序栈（静态与动态）

顺序栈利用一段物理地址连续的存储空间（数组）存储栈内元素，分静态和动态两种，核心区别在于底层数组容量是否可以在运行期间改变。

静态顺序栈

容量在编译时就固定，通常用宏定义指定数组大小，是考试中最常见、最基础的形式。

top 通常初始化为 -1（指向栈顶元素），也可初始化为 0（指向栈顶元素的下一个空闲位置）。

核心操作（以 top = 0 方案为例，top 指向下一个空位）：

项目 内容
初始值 S.top = 0
判空 S.top == 0
判满 S.top == MAXSIZE
入栈核心 S.data[S.top] = x; S.top++（先存再移）
出栈核心 S.top--; x = S.data[S.top]（先移再取）

致命缺点：MAXSIZE 太小易上溢（Stack Overflow），太大浪费空间。

栈顶 top 的四种初始化方式对比（考研必背）

特性 从下往上 top=0 从下往上 top=-1 从上往下 top=n 从上往下 top=n-1
top 含义 下一空位 当前栈顶 当前栈顶 下一空位
初始值 0 -1 n n-1
判空 top == 0 top == -1 top == n top == n-1
判满 top == MAXSIZE top == MAXSIZE-1 top == 0 top == -1
入栈 S[top++] = x S[++top] = x S[--top] = x S[top--] = x
出栈 x = S[--top] x = S[top--] x = S[top++] x = S[++top]
读栈顶 S[top - 1] S[top] S[top] S[top + 1]
元素个数 top top + 1 n - top n - 1 - top

考研提醒：严蔚敏教材默认 top = 0，但很多习题用 top = -1。审题时先确认题目给的 top 初始值，再推导对应代码！

静态 vs 动态对比

维度 静态顺序栈 动态顺序栈
内存位置 系统栈区或全局/静态数据区 系统堆区 (Heap)
容量限制 编译时固定，不可变 运行时可动态扩容 (realloc)
上溢风险 高 极低（仅受物理内存限制）
时间复杂度 所有操作严格 O(1) 绝大部分 O(1)，扩容瞬间 O(n)

链栈

链栈（Linked Stack）是用链表实现的栈，本质上是一个只允许在表头进行插入和删除的单链表。只要内存够就一直能入栈，彻底告别”栈满溢出”。

核心设计原则：栈顶指针必须锚定在链表头部——入栈用头插法、出栈用头删法，均为 O(1)。若栈顶在链表尾部，每次入栈找尾结点 + 出栈找前驱都会退化为 O(n)。

不带头结点链栈（严蔚敏教材默认，408 最常考）

S（即 top）直接指向第一个数据结点。

关键理解：链栈是倒过来的链表——next 指向栈中下方的元素。入栈 = 头插法，出栈 = 头删法。

项目 内容
判空 S == NULL
判满 不存在（链栈不会满，malloc 失败才返回 false）
入栈核心 p->next = S; S = p（头插法），严格 O(1)
出栈核心 p = S; S = S->next; free(p)（头删法），严格 O(1)
出栈最后元素 S = p->next 自然置 NULL，无需特殊处理

带头结点链栈

S（top）永远指向头结点，真正的栈顶数据在 S->next。入栈/出栈逻辑完全统一，无需区分空栈边界。

项目 内容
判空 S->next == NULL
入栈核心 p->next = S->next; S->next = p（操作对象是 S->next 而不是 S 本身）
出栈核心 p = S->next; S->next = p->next; free(p)
代价 多一个头结点的 malloc/free 开销

带头 vs 不带头对比

维度 不带头结点 带头结点
初始值 S = NULL S = malloc(…); S->next = NULL
判空 S == NULL S->next == NULL
入栈 p->next = S; S = p p->next = S->next; S->next = p
出栈 p = S; S = S->next; free(p) p = S->next; S->next = p->next; free(p)
内存 省一个头结点 多一个头结点
考研倾向 ★ 严蔚敏教材默认，最常考 考试较少出现

顺序栈 vs 链栈对比

维度 顺序栈 链栈
存储方式 连续数组 离散结点（单链表）
容量 有限（静态）/ 可扩（动态） 无限（仅受物理内存限制）
判满 top == MAXSIZE 等 不存在（malloc 失败才满）
入栈 O(1)，偶尔 O(n)（扩容时） 严格 O(1)（头插法）
出栈 O(1) 严格 O(1)（头删法）
适用场景 元素个数可预估 元素个数未知、波动极大

高频考点速记

考点 记忆
栈的特性 LIFO 后进先出，只在栈顶 top 一端插入删除
静态顺序栈 top=0：判空 top==0、判满 top==MAXSIZE、先存再移
动态顺序栈 用 realloc 扩容，必须更新 S.data 指针
top 四种初始化 从下往上 top=0/-1、从上往下 top=n/n-1；审题先看初始值
入/出栈口诀 top=0：S[top++]=x / x=S[--top]；top=-1：S[++top]=x / x=S[top--]
链栈设计原则 栈顶必须设在链表头部，入栈头插法、出栈头删法，均 O(1)
不带头结点链栈 判空 S==NULL；★ 严蔚敏教材默认，最常考
带头结点链栈 判空 S->next==NULL；操作对象始终是 S->next
链栈优势 不会满；出栈最后元素 S=p->next 自然置 NULL，无需特殊处理
