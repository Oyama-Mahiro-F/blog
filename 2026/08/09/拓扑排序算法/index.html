拓扑排序算法

2026-08-09
  • 数据结构&算法

拓扑排序：由某个集合上的一个偏序得到该集合上的一个全序的操作。即有向图的拓扑排序——构造 AOV 网中顶点的一个拓扑线性序列，使得该线性序列满足两点：

  1. 保持原来有向图中顶点之间的优先关系
  2. 对原图中没有优先关系的顶点之间，也建立一种（人为的）优先关系

基本概念

概念 说明
偏序 集合中仅有部分元素之间可以比较先后
全序 集合中任意两个元素之间都可以比较先后（拓扑排序后的线性序列）
AOV 网 顶点表示活动，弧表示活动间的优先关系
前驱/后继 存在弧 ⟨i,j⟩，则 i 是 j 的直接前驱

核心条件：

条件 说明
图必须为 DAG 有向无环图——若存在环，无法确定环上顶点的先后顺序
存在性 DAG 的拓扑序列一定存在（至少一个）
唯一性 拓扑序列通常不唯一（多入度为 0 时有多种选择）

AOV 网不能有环：若存在环，则某项活动能否进行是以自身的完成作为前提条件，逻辑上不可能。检查方法——拓扑排序，若所有顶点都在拓扑有序序列中，则无环（否则存在环，拓扑排序失败）。

算法思想

① 在 AOV 网中选择一个没有前驱的顶点（入度为 0）并输出；

② 在 AOV 网中删除该顶点以及从该顶点出发的所有有向弧（即邻接点入度 −1）；

③ 重复 ①②，直到：

  • 图中全部顶点都已输出 → 图中无环，拓扑排序成功
  • 图中不存在无前驱的顶点（但仍有顶点未输出）→ 图中必有环，拓扑排序失败

算法分析

设 AOV 网有 n 个顶点、e 条边：

步骤 操作 时间复杂度
统计各顶点入度 遍历所有顶点和边 O(n+e)
入度为 0 的顶点入栈 遍历所有顶点 O(n)
排序过程 顶点入栈/出栈 n 次 + 入度减 1 共 e 次 O(n+e)
总计 O(n+e)

空间复杂度：O(n)（栈 + 入度数组）。

高频考点速记

考点 记忆
拓扑排序 反复输出入度 0 顶点并删弧（入度 −1），时间 O(n+e)
拓扑环检测 全部顶点输出→DAG 无环；仍有入度均 >0 的顶点→有环
拓扑唯一性 DAG 一定有拓扑序列；通常不唯一（多入度 0 时）
应用场景 课程先修关系排课、工程任务调度、编译依赖分析
