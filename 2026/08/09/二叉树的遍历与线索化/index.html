二叉树的遍历与线索化

2026-08-09
  • 数据结构&算法

二叉树的遍历是整棵树所有操作的基础——查找、插入、删除、线索化，本质上都是遍历的变体。本篇覆盖四种遍历（递归三序 + 层序）、非递归实现，以及建立在遍历之上的线索二叉树。

遍历 辅助结构 核心口诀
先序 / 中序 / 后序（递归） 递归栈 按”根”的访问时机区分：根左右 / 左根右 / 左右根
中序（非递归） 栈 一路向左压栈，左到头弹栈访问转右
层序 队列 根入队，出队访问，孩子依次入队
线索化 遍历 + pre 指针 左空指前驱、前驱右空指当前

结构定义与空指针域

n 个结点的二叉链表共有 n+1 个空指针域——每个结点 2 个指针共 2n 个，其中 n−1 个指向孩子，剩余 n+1 个为空。这 n+1 个空指针正是线索二叉树的用武之地。

递归遍历

三种遍历方式按”根”的访问时机区分：

  • 先序（根左右）：根 → 左子树 → 右子树
  • 中序（左根右）：左子树 → 根 → 右子树
  • 后序（左右根）：左子树 → 右子树 → 根

核心规则：必须有中序才能唯一确定一棵二叉树。

序列组合 能否唯一确定 原因
先序 + 中序 ✅ 先序定根，中序分左右
后序 + 中序 ✅ 后序定根，中序分左右
层序 + 中序 ✅ 层序定根，中序分左右
先序 + 后序 ❌ 能定根但无法区分左右子树边界

通用方法：① 从先序/后序/层序中确定根 → ② 在中序中找到根，划分左右子树 → ③ 递归处理左右子树。

关键结论：已知中序 + 先序 或 中序 + 后序可唯一确定二叉树。仅先序+后序不能唯一确定。
