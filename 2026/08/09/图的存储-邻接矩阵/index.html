图的存储：邻接矩阵及基本操作

2026-08-09
  • 数据结构&算法

邻接矩阵用二维数组存储顶点间的边/弧关系，判边 O(1)、空间 O(n2)，适合稠密图。

结构定义

关键性质

图类型 元素值 特殊性质
无向图 1 有边 / 0 无边 对称矩阵；第 i 行非零数 = 度；1 的总数 = 2e
无向带权图 wij​ / ∞ 对称矩阵；第 i 行非 ∞ 数 = 度；非 ∞ 总数 = 2e
有向带权图 wij​ / ∞ 一般不对称；第 i 行非 ∞ 数 = 出度；第 j 列非 ∞ 数 = 入度

复杂度总结

操作 时间复杂度
插入顶点 O(n)（初始化新行列）
插入/删除边 O(n)（LocateVex 遍历）/ O(1)（已知下标）
求第一个/下一个邻接点 O(n)（遍历一行）
删除顶点 O(n2)（双重循环压缩行列）
