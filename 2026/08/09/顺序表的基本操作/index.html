顺序表的基本操作

2026-08-09
  • 数据结构&算法

顺序表（Sequential List）用顺序存储的方式实现线性表——把逻辑上相邻的元素存储在**物理位置上也相邻（地址连续）**的存储单元中。随机存取 O(1)，但插入/删除需移动大量元素。

时间复杂度分析

操作 时间复杂度 原因
按位查找 O(1) 连续存放，直接计算地址
按值查找 O(n) 需逐个遍历比较
插入 / 删除 O(n) 需移动元素（平均移动 n/2 次）

记忆要点

  • 位序从 1 开始（数组下标从 0 开始）
  • 插入从后往前搬，删除从前往后搬——方向不能错
  • 静态分配长度定死不可变；动态分配 malloc 新空间可扩容
  • 存储密度 = 1，随机存取 O(1)，适合查找密集型场景
