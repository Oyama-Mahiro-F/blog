交换排序：冒泡与快速

2026-08-09
  • 数据结构&算法

交换排序族的共同思想是：通过交换逆序的相邻（或跨距离）元素来消除逆序。冒泡排序每次只消除一个逆序对，快速排序则一次划分把一批逆序对”批量”消除，因此快得多。

算法 交换方式 时间复杂度 稳定性
冒泡排序 相邻元素逐个交换 O(n2) 稳定
快速排序 以枢轴为中心跨距离交换 平均 O(nlogn) 不稳定

冒泡排序

每趟从头到尾依次比较相邻元素，若逆序则交换——每趟把最大值”冒”到末尾。若某趟无交换，则已有序，提前结束。

快速排序

快速排序是分治算法：每次选一个枢轴（pivot），将序列划分为左右两部分——左边全部 ≤ pivot，右边全部 ≥ pivot，然后递归排序左右子序列。

算法实现

递归调用栈深度 O(logn)（平均），最坏 O(n)。

快速排序与二叉树

快速排序的递归过程与**二叉排序树（BST）**有着内在联系：

  • 每一趟划分选定枢轴 pivot，相当于以 pivot 为根结点
  • 小于 pivot 的元素 → 左子树；大于 pivot 的元素 → 右子树
  • 递归划分 → 递归构造左右子树
  • 最好情况（每次枢轴接近中位数）：BST 接近平衡，深度 O(logn)
  • 最坏情况（每次枢轴为最值）：BST 退化为单链表，深度 O(n)
  • 快排的时间复杂度等价于对应 BST 的查找路径长度之和
  • 树高即基于当前 pivot 所需进行的交换次数
  • 树的中序遍历即当前 pivot 完成一次排序后的最终序列

性能分析

情况 时间 说明
最好 O(nlogn) 每次划分均匀（左右子序列长度接近）
最坏 O(n2) 正序或逆序（每次枢轴在端点）
平均 O(nlogn)
空间 O(logn) 递归调用栈
稳定性 不稳定 划分时跨越交换

408 考点：快排最坏情况（正序/逆序）→ O(n2)；优化方法：三者取中法选枢轴。

递归分析的数学推导

快速排序的主要时间花费在划分上，对长度为 k 的序列划分时关键字的比较次数是 k−1。

设比较次数为 C(n)，递推式：

C(n)=n−1+C(k)+C(n−k−1)

最好情况（每次划分大致相等，k≈n/2）：

C(n)​≤n+2×C(n/2)≤n+2×[n/2+2×C(n/4)]≤2n+4×C(n/4)≤…≤h×n+2h×C(n/2h)​

当 n/2h=1 时排序结束，即 h=log2​n，C(1) 看成常数因子，则：

C(n)≤n×log2​n+n×C(1) ∴ C(n)≤O(nlog2​n)

最坏情况（每次划分有一个子序列为空，即枢轴总是当前最小或最大关键字——正序或逆序时发生）：

C(n)​=n−1+C(n−1)=(n−1)+(n−2)+⋯+1=2n(n−1)​​ ∴ C(n)=O(n2)

空间复杂度（递归调用栈深度）：

情况 栈深度 说明
最好（划分均匀） ⌊log2​n⌋+1 递归深度 = 二叉树深度
最坏（每次只划出一个元素） O(n) 退化为单链
平均 O(log2​n) 平均接近于最好情况
∴ S(n)=O(log2​n)

两种交换排序对比

项目 冒泡排序 快速排序
思想 相邻逆序逐个交换 枢轴划分，跨距离交换
最好 O(n)（正序提前结束） O(nlogn)（划分均匀）
最坏 O(n2)（逆序） O(n2)（正序或逆序）
平均 O(n2) O(nlogn)
空间 O(1) O(logn)（递归栈）
稳定性 稳定 不稳定
每趟定最终位置 能（确定一个最大值） 能（枢轴归位即最终位置）

易错点：冒泡与快排的”最好/最坏”触发条件恰好相反——冒泡在正序时最快（一趟即停），快排在正序时最慢（每次枢轴都在端点，退化为 O(n2)）。这是 408 高频陷阱。

高频考点速记

考点 记忆
冒泡排序 相邻逆序交换，某趟无交换即提前结束；最好 O(n)（正序）；稳定
快速排序 平均/最好 O(nlogn)，最坏 O(n2)（正序或逆序）；递归栈空间 O(logn)；不稳定
一趟划分比较次数 k−1 次
快排优化 三者取中选枢轴
与 BST 联系 递归过程对应 BST，树高即递归深度，中序遍历即排序结果
基本有序时 快排退化为 O(n2)（此时直接插入最快 O(n)）
每趟能否定最终位置 能（交换类排序，每趟确定一个元素位置）
取前 k 个最小 冒泡/简单选择/堆皆可，堆排序性能最好（n≫k 时）
