串的模式匹配：BF 与 KMP

2026-08-09
  • 数据结构&算法

给定主串 S（长度为 n）和模式串 T（长度为 m，m≤n），模式匹配的任务是：在 S 中找到 T 首次出现的位置（下文一律采用 1 索引）；若匹配失败则返回 0。

最朴素的算法是 BF（Brute-Force，暴力匹配），失配时主串指针一路回溯；而 KMP 利用模式串自身的结构信息（next 数组），让主串指针永不回溯，从而把最坏复杂度从 O(nm) 降到 O(n+m)。两种方法的关系如下：

维度 BF KMP
主串回溯 i 回溯 i 不回溯
时间复杂度 O(n)（最好）/ O(nm)（最坏） O(n+m)
额外空间 O(1) O(m)（next 数组）
适用场景 模式串短、偶发匹配 模式串长 / 字符集小、海量文本

考点：模式匹配题默认 1 索引（严蔚敏教材约定）；返回值是主串中模式串首字符的下标，不是比较次数。

BF 算法（暴力匹配）

算法思想

从 S 的第 1 个字符开始，逐个与 T 比较；一旦某位失配，就放弃本轮已匹配的字符，把 S 的指针回溯到本轮起始位置的下一个位置、T 的指针重置为 1，重新开始。

算法实现

关键：失配时 i 回溯到本轮起始位置的下一个位置（i = i - j + 2），j 重置为 1。注意是 i - j + 2 而非 i - j + 1——因为从 1 开始的索引要”跳过整个本轮”再前进一格。

性能分析

时间复杂度 最好 O(n)（首轮即匹配），最坏 O(nm)
空间复杂度 O(1)
失配代价 每轮失配 i 都要大幅回退，已比较的字符全部作废

最坏情况示例：主串 "0000000001"、模式串 "0001"——每趟都要比到最后一位才知道失败，i 反复回头，总比较次数接近 n×m。

易错点：BF 的”回溯”指的是主串指针 i 回退。很多同学把 j 重置当成重点，但真正拖垮复杂度的是 i 的反复后退——这正是 KMP 要消除的。

KMP 算法

KMP 算法利用模式串自身的结构信息（next 数组），避免主串指针 i 的回溯：每次失配时不再重头开始，而是让 j 回溯到 next[j]，主串的 i 原地不动继续往后走，匹配时间复杂度降为 O(n+m)。

核心概念

理解 next 数组，先要分清三个概念：

  • 前缀：除最后一个字符外，字符串的所有头部子串
  • 后缀：除第一个字符外，字符串的所有尾部子串
  • 最长公共前后缀：前缀和后缀集合的交集中，长度最大的那个元素
模式串 T 前缀 后缀 最长公共前后缀长度
"a" ∅ ∅ 0
"ab" {a} {b} 0
"aba" {a, ab} {a, ba} 1（"a"）
"abab" {a, ab, aba} {b, ab, bab} 2（"ab"）

考点：前缀不含最后一个字符、后缀不含第一个字符，二者都不取完整串。这是手工算 next 时最容易漏的地方。

next 数组定义

在模式串中（下标从 1 开始），next[j] 表示：以模式串第 j 处字符结尾的子串，其最大相同前后缀的长度。

易错点：next[1] = 0 是固定值（失配时 j 退到 0，配合代码中 j == 0 的分支让 i、j 同时前移）；其余位置若没有公共前后缀则取 1，不是取 0。

next 数组的手工推导（高频考点）

手工推导 next 时，逐位观察”以 T[j] 结尾的子串”的最长公共前后缀即可。下面用两个例题完整演示。

例题 1：T = "abcac"（用”T[1..j-1] 的最长公共前后缀长 +1”记法逐位推）

  • j=1：固定 next[1] = 0
  • j=2：考察 T[1..1]="a"，无真前后缀 → 长 0 → next[2] = 1
  • j=3：考察 T[1..2]="ab"，前后缀无公共 → 长 0 → next[3] = 1
  • j=4：考察 T[1..3]="abc"，前后缀无公共 → 长 0 → next[4] = 1
  • j=5：考察 T[1..4]="abca"，公共 "a" 长 1 → next[5] = 1+1 = 2

即 next = 0 1 1 1 2，与上方定义框结果一致。

例题 2：T = "ABCDABD"（KMP 最常考，务必会手推）

逐位看子串 T[1..j-1] 的最长公共前后缀：

j 1 2 3 4 5 6 7
T[j] A B C D A B D
考察子串 T[1..j−1] — A AB ABC ABCD ABCDA ABCDAB
最长公共前后缀 — 0 0 0 0 A(1) AB(2)
next[j] 0 1 1 1 1 2 3

即 next = 0 1 1 1 1 2 3。

考点：手推 next 用”T[1..j-1] 的最长公共前后缀长度 +1”最不易错；next[1]=0 永远固定，其余无公共前后缀时一律为 1。

nextval 数组（改进版）

普通 next 仍有冗余：当 T[i] == T[next[i]] 时，回溯到 next[i] 必然再次失配。nextval 在此基础上”跳得更远”——若回溯后还是同一个字符，就一路继承到更远的 nextval[next[i]]。

nextval 改进原理：若 T[j]=T[next[j]]，即回溯后还是同一个字符，必然再次失配——直接跳到更远的 nextval[next[j]]，少走冤枉路。nextval 不改变匹配结果，只减少无效比较。

BF 与 KMP 对比

维度 BF KMP
主串回溯 i 回溯 i 不回溯
时间复杂度 O(nm)（最坏） O(n+m)
额外空间 O(1) O(m)（next 数组）
适用场景 模式串短 模式串长 / 字符集小
核心手段 失配即重头 next 跳过已知匹配前缀

考点：KMP 的 O(n+m) 是最坏复杂度，且空间换时间——多用 O(m) 的 next 数组；BF 空间 O(1) 但最坏退化到 O(nm)。考试常让你同时写出两者的复杂度。

高频考点速记

考点 记忆
匹配问题定义 主串长 n、模式串长 m（m≤n）；成功返回首位置，失败返回 0（默认 1 索引）
BF 算法 失配时主串指针 i 回溯重试；最好 O(n)、最坏 O(nm)，空间 O(1)
KMP 思想 i 永不回溯，失配时 j 跳到 next[j]，利用模式串自身结构；匹配时间 O(n+m)
next 定义 next[j] = 子串 T[1..j-1] 的最长公共前后缀长度 +1；next[1]=0，其余无公共前后缀为 1
next 手工推导 逐位看 T[1..j-1] 的最长公共前后缀；”ABCDABD“ → 0 1 1 1 1 2 3
next 实例 "abcac"：next = 0 1 1 1 2；”j==0 分支让 i,j 齐进
nextval 改进 若 T[i]=T[next[i]]，则 nextval[i]=nextval[next[i]]——跳过必然再次失配的回溯
nextval 实例 “ABCDABD“：nextval = 0 1 1 1 0 1 3；不改变结果，只减无效比较
KMP 空间 next（nextval）数组 O(m)；BF 仅 O(1)
BF vs KMP BF 主串回溯、空间 O(1)；KMP 主串不回溯、空间 O(m)；复杂度 O(nm) vs O(n+m)
