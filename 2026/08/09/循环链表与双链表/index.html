循环链表与双链表

2026-08-09
  • 数据结构&算法

循环链表将原本指向 NULL 的尾巴重新连回头结点；双链表在每个节点多塞一个指针 prior，用空间换时间把”找前驱”从 O(n) 降到 O(1)。

循环单链表：首尾相连的衔尾蛇

  • 普通单链表判表尾：p->next == NULL
  • 循环单链表判表尾：p->next == L（下一步是否绕回起点）

尾指针（rear）策略：不设头指针、只设尾指针 rear 时，找尾节点 O(1)（直接是 rear），找头结点 O(1)（rear->next）。

口诀：存 A 头，A 尾接 B 头（实质数据），斩 B 头，B 尾接 A 头。

循环双链表：极其优雅的”四通八达”

普通双链表在头尾插入/删除时总要写 if (p->next != NULL) 防雷。循环双链表直接消灭了 NULL：头结点的 prior 指向尾巴，尾巴的 next 指向头，没有死角。

目标：在节点 p 的后面插入新节点 s。
口诀：“先连右边（后继），再连左边（前驱）”——绝对不能先动 p->next，否则大部队失联！

高频考点速记

考点 记忆
循环单链表判表尾 判据从 p->next==NULL 变为 p->next==L
循环单链表尾指针 只设尾指针 rear：找头找尾均 O(1)；仅设头指针找尾 O(n)
合并两个循环单链表 口诀：存 A 头、A 尾接 B 头、斩 B 头、B 尾接 A 头
循环双链表 消灭 NULL，判空 L->next == L，插入无需边界判断
双链表插入 四步连线：先连后继（右臂）、再连前驱（左臂），先动 p->next 必断链
双链表删除 边界防雷 if (p->next != NULL)（NULL 无 prior 域会段错误）
