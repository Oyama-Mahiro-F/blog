数据结构与算法基础

2026-08-30
  • 数据结构&算法

**数据结构（Data Structure）**研究数据的组织、存储与运算方式，算法（Algorithm）是求解特定问题步骤的描述——两者合起来就是 “程序 = 数据结构 + 算法”。408 绪论部分概念题密集：基本概念链、数据结构三要素、算法五特性是选择题高频点，而时间复杂度分析（给出代码段判断阶数）几乎每年必考，空间复杂度则常与递归调用栈一起考查。本文按”概念 → 三要素 → 算法 → 复杂度”主线整理，复杂度部分配 8 段代码例题。

数据结构的基本概念

从大到小理清概念链：数据 → 数据对象 → 数据元素 → 数据项。

术语 定义 例子
数据（Data） 信息的载体，能被计算机程序识别和处理的符号集合 数、字符、图像
数据元素（Data Element） 数据的基本单位，通常作为一个整体进行考虑和处理 学生表中的一条记录
数据项（Data Item） 构成数据元素的不可分割的最小单位 记录中的一个字段（学号）
数据对象（Data Object） 具有相同性质的数据元素的集合，是数据的一个子集 全体学生记录
数据类型（Data Type） 一个值的集合和定义在此集合上的一组操作的总称 原子类型、结构类型
抽象数据类型（ADT） 用数学化语言定义的数据组织及相关操作，与具体实现无关 ADT = (D, S, P)

考点：数据元素是数据的基本单位，数据项是构成数据元素的不可分割的最小单位——“基本”与”最小”是选择题最爱偷换的两个词。
考点：ADT = (D, S, P)，即数据对象、关系集、基本操作集；它只定义逻辑结构与运算，不涉及存储实现。

数据结构的三要素

数据结构是相互之间存在特定关系的数据元素的集合，包含三要素：逻辑结构、存储结构、数据的运算。

逻辑结构

逻辑结构描述数据元素之间的逻辑关系，与数据的存储无关、独立于计算机。按元素间关系分为四类：

逻辑结构 元素关系 特点 典型例子
集合 无确定关系 除”同属一个集合”外，别无其他关系 布尔集合
线性结构 一对一（1:1） 唯一首尾元素，每个元素前驱、后继至多一个 线性表、栈、队列、串
树形结构 一对多（1:n） 分支层次，一个前驱对应多个后继 二叉树、目录树
图状结构 多对多（n:n） 任意两元素间都可能有关系 地图、社交网络

考点：判题型口诀——数前驱/后继个数：一对一为线性、一对多为树、多对多为图；树与图统称非线性结构。

存储结构（物理结构）

存储结构（又称物理结构）描述数据在存储器中的存放方式，有四种：

存储结构 实现方式 优点 缺点 适用场景
顺序存储 逻辑相邻的元素物理位置也相邻（连续单元） 随机存取 O(1)、存储密度大（无指针开销） 插入/删除平均移动一半元素，O(n)；需预分配连续空间 查找多、增删少、规模可预估
链式存储 节点 + 指针指示后继地址，物理位置可不连续 插入/删除只需改指针，O(1)（已定位时）；动态分配 不支持随机存取（取第 i 个要 O(n)）；指针占额外空间 频繁插删、规模多变
索引存储 存储元素信息的同时建立附加索引表（关键字， 地址） 检索快：先查索引再取记录 索引表额外占空间；增删数据要同步维护索引 大型文件、数据库
散列存储 由哈希（Hash）函数按关键字直接计算存储地址 理想情况存取 O(1) 存在冲突需解决；数据无序，不适合范围查询 等值查找

易错点：”链式存储的存取速度比顺序存储快”是错的——链式快在插入/删除，按位存取它必须顺着指针找，是 O(n)；顺序存储才能随机存取 O(1)。
考点：同一种逻辑结构可有多种存储实现（线性表既可顺序也可链式）；存储结构只影响运算的实现效率，不改变元素间的逻辑关系。

逻辑结构 vs 存储结构

对比项 逻辑结构 存储结构
描述内容 数据元素之间的逻辑关系 数据在物理存储器上的映像
是否依赖机器 独立于计算机 依赖于计算机存储器
分类 集合、线性、树、图 顺序、链式、索引、散列
对应运算 决定运算的定义（功能） 决定运算的实现（步骤）
相互关系 一个逻辑结构可对应多种存储结构 是逻辑结构的映像

数据的运算：包括运算的定义与实现。运算的定义针对逻辑结构，指出运算的功能；运算的实现针对存储结构，指出具体操作步骤。

考点：如线性表”第 i 位插入元素”——插入这一功能由逻辑结构定义，顺序表后移元素、链表改指针则是由存储结构决定的实现。

算法的基本概念

算法（Algorithm）是对特定问题求解步骤的一种描述，是指令的有限序列，每条指令表示一个或多个操作。描述方法有：自然语言、伪代码、程序设计语言、流程图（N-S 图）。

算法的五个重要特性：

特性 一句话含义
有穷性 必须在有穷步之后结束，且每一步都在有穷时间内完成
确定性 每条指令含义确切，相同输入只会得到相同输出
可行性 每个操作都可由已实现的基本运算执行有限次来完成
输入 有零个或多个输入（可以为 0 个）
输出 有一个或多个输出（至少 1 个）

易错点：算法 ≠ 程序——算法必须满足有穷性（总会终止），程序可以不终止，如操作系统启动后一直无限运行。输入可以没有，输出不能没有。

“好”算法的设计目标：正确性（正确求解问题）、可读性（便于人理解）、健壮性（输入非法数据时能适当反应处理）、高效率与低存储量（时间复杂度低、空间复杂度低）。

时间复杂度

大 O 的定义与运算规则

撇开编程语言、编译质量、机器速度等软硬件因素，算法的工作量只取决于问题规模 n 与数据初始状态。记时间开销为 T(n)。

大 O 严格定义：T(n)=O(f(n)) 当且仅当存在正常数 c 和 n0​，使得 n≥n0​ 时恒有 T(n)≤c⋅f(n)——即 f(n) 是 T(n) 的渐进上界。因此只关心 n 趋于无穷时的增长数量级：保留最高阶、忽略系数与低阶项。

  • 加法规则（多段代码顺序并列执行）：T(n)=O(f(n))+O(g(n))=O(max(f(n),g(n)))，即相加取最大
  • 乘法规则（循环/操作嵌套执行）：T(n)=O(f(n))×O(g(n))=O(f(n)×g(n))，即直接相乘

常见阶数对比

阶数 名称 典型来源 增长速度
O(1) 常数阶 与 n 无关的有限步骤 最慢（最好）
O(log2​n) 对数阶 变量倍增/折半（二分查找） 极慢
O(n) 线性阶 单层循环、顺序扫描 慢
O(nlog2​n) 线性对数阶 “对数次 × 线性次”嵌套（快排、堆排序平均） 中等
O(n2) 平方阶 双层循环 快
O(n3) 立方阶 三层循环 更快
O(2n) 指数阶 枚举子集 极快
O(n!) 阶乘阶 枚举全排列 最快（最差）

排序（口诀”常对幂指阶“）：O(1)<O(log2​n)<O(n)<O(nlog2​n)<O(n2)<O(n3)<O(2n)<O(n!)

考点：对数的底不影响阶——loga​n 与 logb​n 只差常数倍，O(log2​n) 与 O(logn) 同阶。
小例：比较 O(n2) 与 O(nlogn)：nlog2​nn2​=log2​nn​→∞（n→∞），故 O(n2) 增长更快、阶更差；n 很小时 nlogn 数值可能反而大（n=4 时 16>8），但渐进分析只看 n 趋于无穷。

例题：代码段复杂度分析

例 1 单层循环：O(n)

执行次数求和：T(n)=1+(n+1)+n+1=2n+3 → 取最高阶 n、忽略系数 2 → O(n)。

例 2 内层起点依赖 i：O(n²)

内层次数随 i 递减：T(n)=n+(n−1)+⋯+1=2n(n+1)​=21​n2+21​n → 最高阶 n2、忽略系数 21​ → O(n²)。

例 3 倍增循环：O(logn)

设循环执行 m 次，则 2m≤n，即 m=⌊log2​n⌋+1 → O(log₂n)。判阶技巧：循环变量每次乘 2 / 除 2（i *= 2、i /= 2）→ 对数阶；每次加加减减（i++、i += 2）→ 线性阶。

例 4 内层起点 i*i：O(n√n)

外层虽写到 n，但 i2>n 时内层空转，有效外层只有 ⌊n​⌋ 次。总次数：

i=1∑n​​(n−i2+1)≈n​⋅n−31​n1.5=O(n1.5)

结果 O(n√n)，介于 O(nlogn) 与 O(n2) 之间。

例 5 平方根阶：O(√n)

设执行 m 次，则 (m+1)2>n≥m2，即 m=⌊n​⌋ → O(√n)。见到循环条件含 i * i <= n，次数就是 √n 量级。

例 6 倍增套线性：O(nlogn)

乘法规则：外层 log2​n 次 × 内层 n 次 = nlog2​n → O(nlog₂n)。

例 7 两段并列循环：相加取最大

两段顺序执行：T(n)=n+log2​n → 加法规则保留最高阶 → O(n)。

例 8 递归：时间与递归栈空间

时间：递归共调用 n+1 次、每次 O(1) → T(n) = O(n)；空间：每层调用压入一个栈帧，递归深度为 n → S(n) = O(n)。

时间：区间每次减半，T(n)=T(n/2)+O(1) → O(log₂n)；空间：递归深度等于折半次数 → S(n) = O(log₂n)。

易错点：递归算法的空间复杂度必须计入递归调用栈的深度——递归二分时间 O(logn)、空间也是 O(logn)，不是 O(1)；factorial 时间 O(n)、空间同样 O(n)。

最好、最坏与平均时间复杂度

同一算法在不同输入下的执行次数可能不同，以顺序查找为例：

  • 最好：x 恰为第 1 个元素，比较 1 次 → O(1)
  • 最坏：x 在末尾或不存在，比较 n 次 → O(n)
  • 平均：x 出现在各位置等概率 p=1/n，期望比较次数 n1​∑i=1n​i=2n+1​ → O(n)
类型 考虑情形 顺序查找
最好时间复杂度 输入最”顺利”的情况 O(1)
最坏时间复杂度 输入最”糟糕”的情况，给出上界保证 O(n)
平均时间复杂度 所有输入等概率出现的期望运行时间 O(n)

考点：不做特殊说明时，默认讨论最坏时间复杂度（运行时间的上界）；平均复杂度必须建立在各输入等概率的假设上。

空间复杂度

记空间开销为 S(n)。程序所需空间 = 程序本身（指令、常数、变量）+ 输入数据 + 辅助空间；空间复杂度一般指辅助空间，即除输入数据外额外占用的、随规模 n 变化的部分。

  • 原地工作：无论 n 多大，额外空间都是固定常量 → S(n) = O(1)。如就地逆置、交换排序。
  • 辅助数组：开一维数组 int a[n] → O(n)；开二维数组 int a[n][n] → O(n²)。
  • 递归调用栈：递归深度计入空间复杂度（见例 8）——factorial 深度 n → O(n)，二分深度 logn → O(logn)。

易错点：空间复杂度不算输入数据本身；int a[n] 是 O(n) 而非 O(1)；递归栈深也属于辅助空间，”递归省空间”是错觉。

高频考点速记

考点 记忆
概念链 数据 → 数据元素（基本单位）→ 数据项（最小单位）；数据对象 = 相同性质元素的集合
三要素 逻辑结构、存储结构、数据的运算
逻辑结构 集合无序；线性 1:1；树 1:n；图 n:n
存储结构 顺序（连续、随机存取）、链式（指针、可不连续）、索引（索引表：关键字+地址）、散列（哈希函数直接算地址）
顺序 vs 链式 顺序：存取 O(1)、插删 O(n)；链式：插删 O(1)（已定位时）、存取 O(n)
数据运算 定义针对逻辑结构（功能），实现针对存储结构（步骤）
算法五特性 有穷、确定、可行；输入 0 个或多个、输出 1 个或多个
算法 vs 程序 算法必须有穷（终止），程序可以不终止（如操作系统）
大 O 定义 存在正常数 c 与 n0​，n≥n0​ 时 T(n)≤c⋅f(n)；只看 n→∞ 的数量级
加法/乘法规则 并列相加取最大、嵌套相乘；保留最高阶、忽略系数与低阶项
阶数排序 常对幂指阶：O(1)<O(logn)<O(n)<O(nlogn)<O(n2)<O(n3)<O(2n)<O(n!)
判阶技巧 倍增/折半 → O(logn)；单层 → O(n)；双层 → O(n²)；i*i <= n → O(√n)；递归深度 = 时间量级（因每次 O(1) 时）
三种复杂度 最好/最坏/平均；默认指最坏；平均需输入等概率
空间复杂度 只算辅助空间；原地工作 O(1)；一维数组 O(n)、二维 O(n²)；递归深度计入（factorial O(n)、二分 O(logn)）
