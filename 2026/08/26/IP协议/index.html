IP协议

2026-08-26
  • 计算机网络

IP 协议（Internet Protocol，网际协议）是网络层最核心的无连接协议，负责把 IP 数据报从源主机尽力而为地传送到目的主机。它屏蔽底层物理网络的差异，实现异构网络互联。408 对 IP 的考查集中在：IP 地址、IP 数据报格式、子网划分、CIDR、NAT 与 IPv6。

一、IP 地址概述

**IP 地址（IPv4）长度 32 位（4 字节），由网络号（Net ID）+ 主机号（Host ID）**两部分组成，标识一台主机（或一个网络接口）在互联网中的位置。

采用**点分十进制（Dotted Decimal）**记法：把 32 位分成 4 组，每组 8 位转十进制，用点隔开。

例：11000000 10101000 00000001 00000001 → 192.168.1.1

项目 内容
地址长度 32 位，4 个字节
记法 点分十进制（4 组 0~255）
结构 网络号 + 主机号
分配原则 网络号标识所在网络（全球唯一），主机号标识网络内主机

IP 地址 vs MAC 地址（重点对比）

对比项 IP 地址 MAC 地址
所在层次 网络层 数据链路层
地址结构 32 位（IPv4），网络号 + 主机号 48 位（6 字节）
分配方式 由 ICANN/ISP 分配，可改动 由厂家出厂固化
唯一性 全局唯一 全球唯一（IEEE 分配）
是否反映位置 反映主机所在网络位置 不反映位置（只是网卡标识）
转发依据 路由器按 IP 地址转发分组 交换机按 MAC 地址转发帧

考点：IP 地址反映主机的网络位置（分层寻址），MAC 地址只是网卡物理标识。分组在互联网上用 IP 地址寻址，进入局域网后经 ARP 换成 MAC 地址交付。

二、分类 IP 地址（A/B/C/D/E）

传统 IP 地址按前几位固定标志位分为 A、B、C、D、E 五类：

类别 最高位 第一字节 网络号 主机号 默认掩码 用途
A 类 0 1 ~ 126 8 位 24 位 255.0.0.0（/8） 大型网络
B 类 10 128 ~ 191 16 位 16 位 255.255.0.0（/16） 中型网络
C 类 110 192 ~ 223 24 位 8 位 255.255.255.0（/24） 小型网络（局域网）
D 类 1110 224 ~ 239 — — — 组播（多播）
E 类 11110 240 ~ 255 — — — 保留（实验用）
  • 可用网络数：A 类 126 个、B 类 16382 个、C 类约 209 万个
  • 每网络可用主机数 = 2主机号位数−2（A 类约 1670 万、B 类 65534、C 类 254）

易错点：A 类范围是 1~126，不是 0~127——0.x.x.x 保留（表示本网络），127.0.0.1 是环回测试地址（Loopback，本机回环），不属于任何网络。

特殊地址

网络号 主机号 作源地址 作目的地址 含义 例子
0 0 可以 不可 本网络上的本主机 0.0.0.0
0 host-id 可以 不可 本网络上的主机 host-id —
全 1 全 1 不可 可以 有限广播（各路由不转发） 255.255.255.255
net-id 全 1 不可 可以 直接广播 192.168.1.255
net-id 全 0 — 仅代表本网络 网络地址 192.168.1.0
127 非全 0/全 1 可以 可以 环回测试 127.0.0.1

易错点：网络号全 0（0.x.x.x）只能作源地址；广播地址（主机号全 1）只能作目的地址；127 环回地址源、目的都可用，但 127 的主机号不能取全 0 或全 1。0.0.0.0 还常作默认路由（0.0.0.0/0）。

三、IP 数据报格式（重点）

IP 数据报 = 首部 + 数据。首部固定部分 20B（还可有可变选项，最多 40B）：

字段 长度 作用
版本 4 位 IPv4 取 4
首部长度（IHL） 4 位 以 4B 为单位，最小 5（20B）、最大 15（60B）
总长度 16 位 首部 + 数据，以 1B 为单位，最大 65535B
标识 16 位 分片标记：同一数据报的分片标识相同，用于重组
标志 3 位 DF=1 禁止分片；MF=1 后面还有分片
片偏移 13 位 分片相对位置，以 8B 为单位
生存时间（TTL） 8 位 每过一个路由器减 1，减到 0 丢弃（防环路）
协议 8 位 上层：1=ICMP、2=IGMP、6=TCP、17=UDP、89=OSPF
首部校验和 16 位 只校验首部，每跳重新计算
源 IP 地址 32 位 发送方 IP
目的 IP 地址 32 位 接收方 IP

考点：三个”单位”易混淆——首部长度以 4B 为单位、总长度以 1B 为单位、片偏移以 8B 为单位。
易错点：首部校验和只校验首部不校验数据，且 TTL 每跳减 1，校验和必须每跳重新计算。

MTU 与分片

MTU（最大传输单元） = 链路层帧数据部分的最大长度，即 IP 数据报能通过该链路的长度上限（以太网典型 1500B）。IP 数据报总长度超过 MTU 时必须分片；若 DF=1 禁止分片则直接丢弃并回送 ICMP 差错报文。

IP 数据报分片例题：主机 A 向 B 发送一个 4000B 的 IP 数据报（含 20B 首部），某链路 MTU=1500B，求各分片情况。

  • 每片都带 20B 首部，每片最多带数据 = 1500 − 20 = 1480B
  • 数据部分 = 4000 − 20 = 3980B；分片数 = ⌈3980/1480⌉=3 片
  • 片偏移 = 该片数据起始字节数 ÷ 8
分片 数据长度 总长度 数据起始 片偏移 MF
片 1 1480B 1500B 0 0 1
片 2 1480B 1500B 1480 185 1
片 3 1020B 1040B 2960 370 0

校验：3980=1480+1480+1020；除最后一片外每片数据都是 8 的倍数（1480=8×185）✓

考点：片偏移单位是 8B，因此除最后一片外每片数据长度必须是 8 的倍数；总长度含 20B 首部；分片由路由器或源主机完成，重组只发生在目的主机。

四、子网划分（重点）

子网划分（Subnetting）：向主机号借出若干位作子网号，把一个网络分成多个子网，缓解 IP 地址浪费。

子网掩码：32 位，网络号 + 子网号对应位置 1、主机号对应位置 0。掩码与 IP 地址按位与即得所在子网网络地址。

  • 划分子网数：借 n 位 → 2n 个子网
  • 每子网可用主机数：2m−2（m 为剩余主机号位数；减网络地址和广播地址）

子网划分例题：C 类网络 192.168.1.0 划分 4 个子网。

  • 需 n = log2​4=2 位子网号；掩码 = 255.255.255.11000000 = 255.255.255.192（/26）
  • 剩余主机号 6 位，每子网可用主机数 = 26−2=62；子网步长 = 26=64
子网 子网号 网络地址 可用主机范围 广播地址 可用主机数
子网 1 00 192.168.1.0/26 192.168.1.1 ~ .62 192.168.1.63 62
子网 2 01 192.168.1.64/26 192.168.1.65 ~ .126 192.168.1.127 62
子网 3 10 192.168.1.128/26 192.168.1.129 ~ .190 192.168.1.191 62
子网 4 11 192.168.1.192/26 192.168.1.193 ~ .254 192.168.1.255 62

验算：掩码 255.255.255.192 与 192.168.1.65（01000001）相与 = 01000000 = 64 → 属于子网 2 ✓

同一/跨子网判断：用本子网掩码与目的 IP 相与，等于本子网网络地址 → 同一子网，直接交付；否则交给默认网关（路由器），路由表逐条匹配、最长前缀优先、全不匹配走默认路由 0.0.0.0/0。

考点：子网划分后每子网同样减 2——4 个子网共可用 4×62=248 台机器（原 254 台少 6 台）。掩码必须是连续 1；子网号全 0/全 1 早期禁用，CIDR 后允许。

五、CIDR（无分类域间路由）

CIDR 取消传统的 A/B/C 类划分，用”IP 地址 / 网络前缀长度“表示：

路由聚合例题：把相邻地址块 192.168.1.0/25 与 192.168.1.128/25 聚合为一条路由。

结论：聚合为 192.168.1.0/24（覆盖 0~255 共 256 个地址，恰为两块的并集）。

考点：路由聚合取各地址块最长公共前缀；聚合块必须连续（/25 + /25 → /24；/24 与 /25 不能简单合成）。聚合可减少路由表条目，但可能引入路由黑洞。

最长前缀匹配：目的 IP 匹配多条路由时，选**前缀最长（最具体）**的一条。例：目的 192.168.1.132，路由表有 192.168.1.0/24 与 192.168.1.128/25——两者都匹配，但 /25 前缀更长，优先选择 192.168.1.128/25。默认路由 0.0.0.0/0（前缀 0）匹配一切，只在更具体路由都不匹配时兜底。

六、私有 IP 地址与 NAT

私有 IP 地址（RFC 1918）：只在局域网内部使用，互联网路由器不转发：

私有地址块 范围 规模
10.0.0.0/8 10.0.0.0 ~ 10.255.255.255 大型内网
172.16.0.0/12 172.16.0.0 ~ 172.31.255.255 中型内网
192.168.0.0/16 192.168.0.0 ~ 192.168.255.255 小型内网

NAT（网络地址转换）：把内网私有 IP 转换为公网 IP，使多个内网主机共用一个（或少量）公网 IP 访问互联网。NAT 路由器维护 NAT 转换表（内网 IP:端口 ↔ 公网 IP:端口），常与端口多路复用（NAPT） 结合——用不同端口区分不同内网主机的连接。

考点：NAT 使内网主机访问外网时源 IP 被替换为公网 IP；外网主动访问内网主机困难（需端口映射/内网穿透）——NAT 也起到隔离、保护内网主机的作用。

七、IPv6

IPv6 地址长度 128 位，采用冒号十六进制记法：8 组 4 位十六进制数，用冒号隔开。

压缩规则 例子
每组前导 0 省略 0DB8 → DB8、0000 → 0
连续的 0 组用 :: 压缩（只能用一次） 2001:0DB8:0:0:0:FF00:42:8329 → 2001:DB8::FF00:42:8329

注意：:: 若用两次会产生二义性（无法判断压缩了多少组），故只能用一次。

IPv4 vs IPv6 对比：

对比项 IPv4 IPv6
地址长度 32 位（约 43 亿个） 128 位（约 3.4×1038 个）
记法 点分十进制 冒号十六进制（:: 压缩）
首部 有选项字段，变长 固定 40B，无校验和字段
安全性 靠外部机制（IPSec 可选） IPSec 内置于 IPv6
自动配置 需 DHCP 无状态自动配置
广播 支持广播 取消广播（用组播/任意播）

考点：IPv6 三大改进——地址空间 128 位、首部精简（去校验和）、安全性好（IPSec 内嵌）；并取消广播地址，避免广播风暴。

关联知识点

IP 协议常与下面几个网络层协议一起考查：

协议 作用 协议类型
ARP IP → MAC 地址解析（请求广播、响应单播） —
ICMP 差错报告 + 询问（ping 用回送请求/应答，协议字段 1） 差错报文不再产生差错报文
IGMP IP 组播管理（协议字段 2，D 类 224~239） 组播

考点：ping 用 ICMP 回送请求/应答报文（不是 TCP 也不是 UDP）；ARP 请求是广播、响应是单播；ICMP 只报告差错、不改正差错（纠错由高层完成）。
