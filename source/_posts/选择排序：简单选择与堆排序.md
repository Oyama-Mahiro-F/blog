选择排序族的共同思想是：**每一趟从待排序部分选出关键字最小（或最大）的记录，放到已排序部分的末尾**。两者的区别在于"怎么选最小值"：

| 算法 | 选最小值的方式 | 时间复杂度 |
|:---|:---|:---|
| 简单选择排序 | 线性扫描整个无序区 | $O(n^2)$（每趟 $O(n)$） |
| 堆排序 | 用**堆**维护最大值，取堆顶 | $O(n\log n)$（每趟 $O(\log n)$） |

## 简单选择排序

每趟从待排序部分中选出**最小元素**，与待排序部分的第一个元素交换。

### 排序过程示例

```
初始:  [49  38  65  97  76  13  27]

第1趟: 选最小 13 → 与 49 交换 → [13]  38   65   97   76  49   27
第2趟: 选最小 27 → 与 38 交换 → [13   27]  65   97   76  49   38
第3趟: 选最小 38 → 与 65 交换 → [13   27   38]  97   76  49   65
第4趟: 选最小 49 → 与 97 交换 → [13   27   38   49]  76  97   65
第5趟: 选最小 65 → 与 76 交换 → [13   27   38   49   65]  97   76
第6趟: 选最小 76 → 与 97 交换 → [13   27   38   49   65   76]  97
完成:  [13  27  38  49  65  76  97]
```

### 算法实现

```c++
void SelectSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {    // 找最小元素下标
            if (a[j] < a[minIdx]) minIdx = j;
        }
        if (minIdx != i) {                   // 交换
            int t = a[i]; a[i] = a[minIdx]; a[minIdx] = t;
        }
    }
}
```

### 算法分析

整个算法是二重循环：外循环控制排序的趟数，对 $n$ 个记录排序的趟数为 **$n-1$ 趟**；进行第 $i$ 趟排序时，关键字的比较次数为 $n-i$，则：

$$\text{比较次数} = \sum_{i=1}^{n-1} (n-i) = \frac{n(n-1)}{2}$$

| 项目 | 说明 |
|:---|:---|
| 时间复杂度 | $T(n) = O(n^2)$（与初始顺序无关，每趟必找最小） |
| 空间复杂度 | $S(n) = O(1)$ |
| 稳定性 | **不稳定**（交换可能跳过中间等同元素） |

## 堆排序

**堆**：一棵完全二叉树，满足任意非叶结点的关键字**大于等于**（大顶堆）或**小于等于**（小顶堆）其孩子结点的关键字。

**堆的四条性质**：

1. 堆是一棵采用**顺序存储**结构的完全二叉树，$k_1$ 是根结点
2. 堆的根结点是关键字序列中的**最小**（或**最大**）值——小根堆（或大根堆）；即根到任意结点的路径上关键字值**非递减**（或**非递增**）
3. 从根结点到每一叶子结点路径上的元素序列按值非递减（或非递增）
4. 堆中的**任一子树也是堆**

利用堆顶记录关键字最大（或最小）的性质，从待排序记录中依次选取关键字最大（或最小）的记录，实现对数据记录的排序，这种方法称为**堆排序**。

```
大顶堆示例:              存储为数组:
        97              [97, 76, 65, 49, 38, 13, 27]
       /  \             i 的左孩子: 2i+1
     76    65           i 的右孩子: 2i+2
    /  \   / \
   49  38 13  27
```

### 排序思想

① 对一组待排序的记录，按堆的定义**建立堆**（大顶堆或小顶堆）；

② 将**堆顶记录和最后一个记录交换位置**，则前 $n-1$ 个记录是无序的，而最后一个记录是有序的（最大/最小已归位）；

③ 堆顶记录被交换后，前 $n-1$ 个记录不再是堆，需**重新组织成为一个堆**（向下调整），然后将堆顶记录和倒数第二个记录交换位置；

④ **重复**上述步骤，直到全部记录排好序为止。

![堆排序过程示意](/blog/images/第8章 排序.assets/heaplogith.png)

### 算法实现

```c++
// 将 a[k] 向下调整到正确位置（大顶堆）
void HeapAdjust(int a[], int k, int n) {
    int temp = a[k];
    for (int i = 2 * k + 1; i < n; i = 2 * i + 1) {
        if (i + 1 < n && a[i] < a[i + 1]) i++;   // i 指向较大的孩子
        if (temp >= a[i]) break;                   // 已满足堆定义
        a[k] = a[i];                               // 孩子上移
        k = i;                                     // 继续向下调整
    }
    a[k] = temp;
}

// 堆排序主函数
void HeapSort(int a[], int n) {
    // ① 建堆：从最后一个非叶结点开始逐个调整
    for (int i = n / 2 - 1; i >= 0; i--)
        HeapAdjust(a, i, n);

    // ② 排序：反复取堆顶
    for (int i = n - 1; i > 0; i--) {
        int t = a[0]; a[0] = a[i]; a[i] = t;   // 堆顶与堆尾交换
        HeapAdjust(a, 0, i);                    // 剩余元素调整
    }
}
```

### 性能分析

| 项目 | 说明 |
|:---|:---|
| 建堆时间 | $O(n)$（推导可为 $O(n)$，非 $O(n\log n)$） |
| 每次调整 | $O(\log n)$ |
| 总时间 | $O(n\log n)$（最好/最坏/平均均如此） |
| 空间 | $O(1)$（原地排序） |
| 稳定性 | **不稳定**（交换时可能打破同关键字顺序） |

## 两种选择排序对比

| 项目 | 简单选择排序 | 堆排序 |
|:---|:---|:---|
| 选最值方式 | 线性扫描 $O(n)$ | 取堆顶 + 向下调整 $O(\log n)$ |
| 时间复杂度 | $O(n^2)$ | $O(n\log n)$ |
| 与初始状态关系 | **无关**（每趟必扫完） | **无关**（建堆 $O(n)$ + $n$ 次调整） |
| 空间复杂度 | $O(1)$ | $O(1)$ |
| 稳定性 | **不稳定** | **不稳定** |
| 每趟定最终位置 | 能 | 能 |

> **易错点**：堆排序的**建堆是 $O(n)$ 而非 $O(n\log n)$**——从最后一个非叶结点向下调整，各结点调整高度不同，总和收敛到 $O(n)$。这是 408 选择题高频陷阱。
> **核心记忆**：简单选择与堆排序的时间复杂度都与初始状态无关，但堆排序快得多，因为用堆把"找最值"从 $O(n)$ 降到 $O(\log n)$。

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 简单选择排序 | 每趟选最小与首位交换；比较次数恒为 **$n(n-1)/2$**，与初始状态无关；$O(n^2)$、**不稳定** |
| 堆排序-建堆 | 大顶堆顺序存于数组，孩子下标 $2i+1/2i+2$；**建堆 $O(n)$**（非 $O(n\log n)$） |
| 堆排序-总 | 堆顶与堆尾交换 + 向下调整；总时间 $O(n\log n)$ 与初始状态无关；$O(1)$ 空间；**不稳定** |
| 比较次数与初始状态无关 | **基数、简单选择、堆排序** |
| 每趟能否定最终位置 | 能（选择类排序） |
| 取前 k 个最小 | 冒泡/简单选择/堆皆可，**堆排序性能最好**（$n \gg k$ 时） |
