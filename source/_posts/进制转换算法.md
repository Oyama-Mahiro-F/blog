利用栈将十进制整数转换为 2 进制或 8 进制等目标进制。**除基取余，逆序输出**——先算出的低位余数压在栈底最后输出，完美利用栈的 LIFO 特性实现逆序。

## 算法过程

**第一步：环境初始化**

1. 构造一个空的顺序栈（或链栈）`S`，暂时存储计算产生的余数。
2. 准备一个普通整型变量 `e`，用于最后阶段接收出栈的数据。

**第二步：除基取余，顺序入栈（核心计算层）**

当被转换的十进制数 $n > 0$ 时，持续循环：

1. **求余**：计算当前 $n$ 除以目标进制 $d$ 的余数 $k = n \bmod d$。
2. **压栈**：将余数 $k$ 压入栈 `S` 的栈顶。
3. **降维**：更新 $n = n / d$（整数除法，向下取整）。

**第三步：逆序出栈，完成转换（核心输出层）**

当循环结束（$n = 0$）时，所有余数已按"从低位到高位"的顺序堆叠在栈中。当栈 `S` 不为空时持续循环：

1. **弹栈**：将栈顶元素弹出赋值给 `e`。
2. **输出**：打印变量 `e` 的值。

## 算法实现

```c++
#include <stdlib.h>
#include <stdbool.h>

void Conversion(int n, int d) {
    /* 将十进制整数 n 转换为 d (2或8) 进制数 */
    SqStack S;
    int k, e;

    // 1. 初始化栈
    InitStack(S);

    // 2. 除基取余，压入栈中
    while (n > 0) {
        k = n % d;
        Push(S, k);
        n = n / d;
    }

    // 3. 栈不空时出栈，逆序输出
    while (!StackEmpty(S)) {
        Pop(S, e);
        printf("%d", e);
    }

    printf("\n");
}
```

## 实例：十进制 13 → 二进制 1101

```
【"除基取余，顺序入栈"】         【"逆序出栈"】
n=13: 13%2=1 → Push(1)          Pop → 1 (最高位)
n=6 :  6%2=0 → Push(0)          Pop → 1
n=3 :  3%2=1 → Push(1)          Pop → 0
n=1 :  1%2=1 → Push(1)          Pop → 1 (最低位)
n=0 : 结束

入栈后栈底→顶: [1][0][1][1]     出栈顺序: 1→1→0→1 → 结果 1101 ✓
```

## 考点总结

| 考点 | 记忆 |
|:---|:---|
| 核心思想 | **除基取余，逆序出栈** |
| 为什么用栈 | 余数先算出来的是低位，利用 LIFO 自动逆序输出 |
| 时间复杂度 | $O(\log_d n)$，空间 $O(\log_d n)$ |
