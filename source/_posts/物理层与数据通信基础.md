**物理层（Physical Layer）**是计算机网络体系结构的最低层，任务是在传输介质上**透明地传送比特流**：它并不研究具体的传输介质本身，而是规定与介质接口的**机械、电气、功能、过程**特性，把比特流变换成**信号**、通过**信道**从**信源**送到**信宿**。408 对本章的考查集中在：**基本概念辨析（码元/比特、波特/比特率、带宽）、奈奎斯特定理与香农定理的极限速率计算、编码与调制方式、电路/报文/分组三种交换技术、传输介质与物理层接口特性**，其中两大定理的计算几乎是必考题。

## 数据通信基本概念

### 数据、信号与通信系统模型

**数据（Data）**是传送信息的**实体**，**信号（Signal）**是数据的**电气或电磁表现**——数据回答"运什么"，信号回答"怎么运"。

| 类型 | 含义 | 举例 |
|:---|:---|:---|
| **模拟数据 / 模拟信号** | 取值**连续**变化 | 电话线上的语音电压波形 |
| **数字数据 / 数字信号** | 取值**离散** | 计算机输出的 0/1 比特流 |

通信系统的一般模型：**信源（Source）→ 发送器 → 信道（Channel）→ 接收器 → 信宿（Sink）**，**噪声源**叠加在信道上：

| 部件 | 作用 |
|:---|:---|
| **信源** | 产生和发送数据的源头 |
| **发送器** | 把数据变换成**适合信道传输**的信号（编码/调制） |
| **信道** | 信号的传输通道，**噪声在此叠加** |
| **接收器** | 把信号**恢复**成信宿可接收的形式（解码/解调） |
| **信宿** | 接收数据的终点 |

调制解调器（Modem）同时具有发送器与接收器功能。信道按通信方向分为**单工**（只能单向）、**半双工**（双向但同一时刻只能一方发送）与**全双工**（同时双向收发）：

| 通信方式 | 方向性 | 实例 |
|:---|:---|:---|
| **单工** | 只能**一个方向**传输 | 广播、电视 |
| **半双工** | 双向但**同一时刻只能一方**发送 | 对讲机 |
| **全双工** | **同时双向**收发（需**两条信道**） | 电话 |

| 类型 | 含义 | 场景 |
|:---|:---|:---|
| **基带信号（Baseband）** | 信源发出的**未经调制**的原始信号 | 近距离传输（局域网） |
| **宽带（频带）信号** | 基带信号**调制搬移**到较高频段后的信号 | 远距离传输、频分复用 |

### 码元、比特、波特与带宽（概念辨析）

**码元（Symbol，Code Element）**：用一个**固定时长的信号波形**（数字脉冲）表示的基本波形，该时长称**码元宽度**。若码元有 $V$ 个离散状态（即 $V$ 进制码元），则 **1 个码元携带 $\log_2 V$ 比特**信息（4 进制码元携 2 bit、16 进制码元携 4 bit）。

| 概念 | 含义 | 单位 | 关系 / 说明 |
|:---|:---|:---|:---|
| **码元（Symbol）** | 固定时长的基本信号波形 | 个 | **与进制无关**地数"波形个数" |
| **比特（bit）** | 信息量单位 | bit | 1 码元 = $\log_2 V$ bit |
| **波特率 $B$（Baud）** | 每秒传输的**码元数**（码元速率） | Baud | $B = 1/T$（T 为码元宽度），**与进制无关** |
| **比特率 $R$** | 每秒传输的**比特数**（信息速率/数据率） | bit/s | $R = B \times \log_2 V$ |
| **带宽 $W$** | 信道能通过的**频率范围宽度**（最高−最低频率） | **Hz** | 决定信道极限速率（奈氏/香农） |

> **考点**：**波特率 × log₂(每码元离散状态数) = 比特率**，即 $R = B \times \log_2 V$。波特率与进制无关；**码元速率一定时，进制越高每码元携带比特越多、比特率越大**——这是多进制调制（如 QAM-16）提高数据率的根本手段。
> **易错点**：通信中的"带宽"单位是 **Hz**，日常说的"100 Mb/s 带宽"指**数据率（b/s）**，两者不是同一概念；提到"速率"必须先分清是**波特率（Baud）**还是**比特率（b/s）**。

**速率换算例题**：某系统采用 **QAM-16**（16 种码元状态）调制，码元速率为 **2400 波特**，求比特率；若改用只有 2 种状态的 FSK 调制，比特率变为多少？

| 项目 | 数值 |
|:---|:---|
| 码元速率 $B$ | 2400 Baud |
| 码元状态数 $V$ | 16（QAM-16）/ 2（FSK） |
| 每码元携带比特 | $\log_2 16 = 4$ bit / $\log_2 2 = 1$ bit |

- QAM-16：$R = B \times \log_2 V = 2400 \times \log_2 16 = 2400 \times 4 =$ **9600 b/s**
- FSK：$R = 2400 \times \log_2 2 = 2400 \times 1 =$ **2400 b/s**
- **验算**：每秒传 2400 个码元、每码元 4 bit，$2400 \times 4 = 9600$ bit/秒 ✓
- **结论**：码元速率不变时，16 进制比 2 进制的比特率高 4 倍（$\log_2 16 / \log_2 2 = 4$）。

## 奈奎斯特定理与香农定理

信道能支持的传输速率存在极限：**奈氏准则管"无噪声"，香农定理管"有噪声"**。

### 奈奎斯特定理（奈氏准则）

**适用条件**：**理想低通（无噪声、带宽受限）**信道。为避免**码间串扰（ISI）**，极限码元传输速率为：

$$B_{\max} = 2W \text{（波特，Baud）}$$

对应的极限数据传输率：

$$C = 2W\log_2 V \text{（b/s）}$$

其中 $W$ 为信道带宽（Hz），$V$ 为码元的离散状态数。奈氏准则**只限制码元速率**——码元速率一定时，可以提高 $V$ 来提高比特率，但 $V$ 受噪声与设备复杂度限制、不能无限增大。

**奈氏极限例题**：理想低通信道带宽 **4000 Hz**，码元取 **16 个离散电平**，求最大数据传输率。

| 项目 | 数值 |
|:---|:---|
| 带宽 $W$ | 4000 Hz |
| 离散电平数 $V$ | 16 |
| 极限码元速率 | $2W = 8000$ 波特 |
| 每码元比特数 | $\log_2 16 = 4$ bit |

**计算**：$C = 2W\log_2 V = 2 \times 4000 \times \log_2 16 = 8000 \times 4 =$ **32000 b/s = 32 kb/s**

**验算**：极限码元速率 8000 波特 × 每码元 4 bit = 32000 bit/s ✓

**结论**：该理想信道极限数据率为 32 kb/s；若电平数提高到 256（每码元 8 bit），可翻倍至 $8000 \times 8 = 64000$ b/s。

### 香农定理

**适用条件**：**带宽受限且有高斯噪声**的信道。信噪比越大，信道极限速率越高：

$$C = W\log_2(1 + S/N) \text{（b/s）}$$

$S$ 为信号平均功率、$N$ 为噪声平均功率。信噪比常用分贝表示：

$$S/N(\text{dB}) = 10\lg(S/N) \quad\Longleftrightarrow\quad S/N = 10^{\text{dB}/10}$$

> **考点**：**30 dB → S/N = 1000**（$10^{30/10}$）是最常考的换算；题目给 dB 值时**必须先换算成倍数**再代入香农公式。

**香农容量例题**：某信道带宽 **4000 Hz**，信噪比 **30 dB**，求极限数据传输速率。

| 项目 | 数值 |
|:---|:---|
| 带宽 $W$ | 4000 Hz |
| 信噪比 | 30 dB → $S/N = 10^{30/10} = 1000$ |

**计算**：$C = 4000 \times \log_2(1 + 1000) = 4000 \times \log_2 1001$。由 $2^{10} = 1024$ 略大于 1001，取 $\log_2 1001 \approx 9.97$，得 $C \approx 4000 \times 9.97 \approx$ **39880 b/s ≈ 40 kb/s**

**验算**：$10\lg 1000 = 30$ dB，dB 换算无误 ✓

**结论**：无论采用多么复杂的编码调制技术，该有噪信道的数据率都不可能超过约 40 kb/s——香农给的是**硬上限**。

### 奈氏 vs 香农（对比辨析）

| 对比项 | 奈奎斯特定理 | 香农定理 |
|:---|:---|:---|
| 适用信道 | **理想无噪声**低通信道 | **带宽受限且有噪声**信道 |
| 限制对象 | **码元速率**（$B_{\max}=2W$），经 V 间接限数据率 | **信息速率**（直接给出数据率上限） |
| 公式 | $C = 2W\log_2 V$ | $C = W\log_2(1+S/N)$ |
| 提高速率手段 | 提高 $V$（多进制调制） | 提高信噪比 $S/N$ 或带宽 $W$，**与 V 无关** |
| 结果形态 | 理想情况下随 V 增大可无限大 | 噪声存在时是**硬上限** |
| 实际使用 | 两者**同时满足，取较小者** | 两者**同时满足，取较小者** |

> **考点**：求实际信道极限速率时，**分别用奈氏与香农计算，取较小者**。如上面两例同一信道：奈氏（16 电平）= 32000 b/s < 香农 ≈ 39880 b/s，故实际极限为 **32000 b/s**——香农是"天花板"，奈氏告诉你当前电平数下能摸多高。

## 编码与调制

**编码（Encoding）**：数据变换为**数字信号**；**调制（Modulation）**：数据变换为**模拟信号**（搬移到合适频带）。

### 数字数据编码为数字信号

![常见数字编码波形：NRZ、RZ、NRZI、曼彻斯特、差分曼彻斯特](/blog/images/第2章 物理层.assets/encoding-waveforms.png)

| 编码方式 | 规则 | 每比特电平跳变 | 特点 |
|:---|:---|:---|:---|
| **不归零 NRZ** | 高 1 低 0，码元内电平不变 | 码元内**不跳变** | 实现最简单、无带宽浪费；**无自同步能力**（连续同码元无法分辨边界） |
| **归零 RZ** | 每码元**后半段归零** | 每码元归零 1 次 | 自同步强；但频带宽、效率低 |
| **NRZI（反向不归零）** | 电平**翻转**表示 0、不翻转表示 1（看起点） | 遇 0 才跳 | 差分特性、抗干扰；同步能力弱（USB 使用） |
| **曼彻斯特** | **每比特中间必跳变**，跳变既定时钟又定数据 | **中间 1 次必跳**（边界也可能跳） | 自同步强；**以太网默认编码**；1 bit 占 2 个码元 |
| **差分曼彻斯特** | 中间必跳变**只作时钟**；0/1 看**码元开始处有无跳变** | 中间 1 次 + 边界视数据 | 抗干扰最强；令牌环等局域网 |

跳变方向的约定（哪种方向代表 1）各教材不同（上图采用"上 0 下 1"，IEEE 802.3 相反），**考试以题目给定为准**；关键是分清功能定位：曼彻斯特的中间跳变**既定时钟又定数据**，差分曼彻斯特的中间跳变**只作时钟**、数据由**边界是否跳变**决定。

> **考点**：曼彻斯特与差分曼彻斯特每比特占 **2 个码元**，故**波特率 = 2 × 数据率**、编码效率仅 **50%**；NRZ 效率 100% 但无自同步；**4B/5B** 用 5 bit 编 4 bit 数据（效率 **80%**），打破连续 0/1 以改善同步。
> **易错点**：以太网用**曼彻斯特**编码（不是差分曼彻斯特）；差分曼彻斯特看**起始边界**有无跳变判 0/1。

### 数字数据调制为模拟信号

![三种基本调制方法：ASK/FSK/PSK](/blog/images/第2章 物理层.assets/ask-fsk-psk.png)

| 调制方式 | 载波参数 | 特点 |
|:---|:---|:---|
| **调幅 ASK**（幅移键控） | 改变载波**振幅** | 实现简单；抗干扰最差 |
| **调频 FSK**（频移键控） | 改变载波**频率** | 抗干扰优于 ASK；低速通信常用 |
| **调相 PSK**（相移键控） | 改变载波**相位** | 抗干扰强、频带利用率高（2PSK 绝对调相 / DPSK 相对调相） |

**QAM（正交振幅调制，Quadrature Amplitude Modulation）**：把**调幅与调相结合**——若用 $m$ 种幅值、$n$ 种相位，可产生 $m \times n$ 种码元，**1 码元携带 $\log_2(mn)$ bit**。**QAM-16** 即 16 种码元状态、每码元 4 bit（前文换算例题即用到）。

模拟数据数字化用**脉码调制 PCM**：**抽样 → 量化 → 编码**，其中**采样频率 $f_s \ge 2f_{\max}$**（采样定理），否则产生混叠失真。

## 电路交换、报文交换与分组交换

- **电路交换（Circuit Switching）**：**建立连接 → 通信 → 释放连接**，通信期间**独占**端到端物理通路，数据直达、无存储转发（电话网）。
- **报文交换（Message Switching）**：把**整个报文**作为一个单位，逐站**存储转发**，收完再发（电报网）。
- **分组交换（Packet Switching）**：把报文**拆成较小的分组**，逐站存储转发、可**流水线并行**（因特网）；代价是每个分组带**首部开销**（信息量约增加 5&#126;10%）。

![三种交换方式的时序对比](/blog/images/第2章 物理层.assets/switching-comparison.png)

| 对比项 | 电路交换 | 报文交换 | 分组交换 |
|:---|:---|:---|:---|
| **建立连接** | **需要**（建立/释放） | 不需要 | 数据报不需要；虚电路需要 |
| **传输单位** | 比特流（直达） | **整个报文** | **分组**（报文拆分） |
| 存储转发 | 无 | 有（报文级） | 有（分组级） |
| **时延** | 建立后**最小**、实时性最好 | **大**（大报文逐站收完再发） | **较小**（小分组流水线并行） |
| 线路占用 | **独占**、利用率低 | 不独占、利用率较高 | **统计复用**、利用率高 |
| 拥塞与开销 | 可能呼损（建连失败） | 结点需**大缓冲** | 排队时延 + **首部开销 5&#126;10%** |
| **适用场景** | 数据量大、持续长时间通信 | 早期电报类业务 | **突发式计算机通信（因特网）** |

> **考点**：三种交换的根本区别在**是否建立连接**与**传输单位**——电路交换时延最小但利用率最低；报文与分组交换都采用存储转发，**分组因单位小而时延远小于报文**。分组交换的**数据报与虚电路**是网络层向传输层提供的两种服务，详见后续网络层文章。

### 报文交换 vs 分组交换：时延对比例题

**例题**：一份 **8000 bit** 的报文从 A 经 B、C 转发到 D（**3 段链路**），每段链路速率 **1000 b/s**，忽略传播时延、排队时延与首部开销。比较报文交换与"拆成 4 个等长分组"的分组交换的总时延。

- **报文交换**：每段链路发送整个报文需 $8000 / 1000 = 8$ s，3 段依次串行：

$$t = 3 \times 8 = 24 \text{ s}$$

- **分组交换**：每分组 2000 bit，单段发送时延 $2000 / 1000 = 2$ s；第 1 个分组经 3 段后到达（$3 \times 2 = 6$ s），之后每 2 s 到达一个（流水线并行）：

$$t = (p + k - 1) \times T_{\text{组}} = (4 + 3 - 1) \times 2 = 12 \text{ s}$$

- **验算**：$6 + 3 \times 2 = 12$ s ✓（第 1 组 6 s 到达，第 2&#126;4 组各再隔 2 s）
- **结论**：同一报文，分组交换时延**减半**。一般地，$k$ 段链路、$p$ 个等长分组：报文交换 $t = k \cdot M / R$，分组交换 $t = (p + k - 1) \cdot M / (pR)$——**分组越小、流水线越充分，时延优势越明显**（首部开销也随之增大）。

## 传输介质

**传输介质不属于物理层**（常称"第 0 层"），物理层通过规定电气特性来识别其上的比特流。介质分**导向性（有线）**与**非导向性（无线）**两大类。

### 导向性介质（有线）

| 介质 | 结构 / 原理 | 抗干扰 | 距离与速率 | 典型应用 |
|:---|:---|:---|:---|:---|
| **双绞线（UTP/STP）** | 两根绝缘铜线**按规则绞合**，绞合可**减少电磁干扰**；STP 另加金属屏蔽层 | 一般（绞合 + 屏蔽改善） | 单段约 **100 m** | 电话线、局域网 |
| **同轴电缆** | 内导体 + 绝缘层 + 网状外导体屏蔽 + 塑料外皮 | **优于双绞线** | 更远、速率更高 | **50Ω 基带**（早期局域网）、**75Ω 宽带**（有线电视） |
| **光纤（Optical Fiber）** | 光脉冲（**有光 = 1、无光 = 0**）在纤芯与包层交界面不断**全反射** | **极强**：不受电磁干扰、损耗小、保密性好 | 带宽超高、适合长距离 | 骨干网、干线 |

**单模 vs 多模光纤**：

| 类型 | 光源 | 特点 |
|:---|:---|:---|
| **单模光纤** | **激光二极管**（定向性好） | 损耗小、带宽大，适合**远距离**干线；价格贵 |
| **多模光纤** | **发光二极管** | 存在模间色散、易失真，适合**近距离**；价格便宜 |

### 非导向性介质（无线）

| 介质 | 传播方式 | 特点 | 典型应用 |
|:---|:---|:---|:---|
| **无线电波** | **全方向**传播 | 穿透能力强；频段带宽有限、抗干扰差 | 手机、WLAN、蓝牙 |
| **微波** | **直线（视距）传播** | 频段宽、数据率高；不能穿透建筑物、受天气影响 | 地面微波接力（远距离需中继）、**卫星通信**（传播时延约 250&#126;270 ms） |
| **红外 / 激光** | **定向直线**传播 | 方向性强、防窃听；不能穿过障碍物 | 遥控器、短距点对点链路 |

> **考点**：卫星通信属于微波中继，**端到端传播时延约 250&#126;270 ms**（计算题常考）；无线介质中只有**微波**是直线视距传播。

### 物理层接口的特性

物理层的主要任务之一是规定与传输媒体**接口**的四个特性：

| 特性 | 规定内容 |
|:---|:---|
| **机械特性** | 接口的**形状、尺寸、引脚数目与排列**、固定与锁定方式 |
| **电气特性** | 各引脚线上的**电压范围**、阻抗匹配、传输速率与距离限制 |
| **功能特性** | 某一电平**表示何种意义**、各信号线（数据/控制/定时/接地）的用途 |
| **过程（规程）特性** | 各信号线的**工作时序**与事件出现的**先后顺序** |

> **考点**：四特性分别对应"**形状规格、电压电平、电平含义、工作时序**"，口诀"机电功规"。

物理层互连设备（**中继器、集线器**——集线器即多端口中继器，两者均不能隔离冲突域）按考纲归入数据链路层/局域网部分讨论，详见局域网文章。

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 通信模型 | **信源→发送器→信道→接收器→信宿**；噪声叠加于信道；Modem 兼发送/接收 |
| 码元 vs 比特 | 码元 = 固定时长的信号波形（与进制无关）；1 码元 = $\log_2 V$ bit |
| 速率换算 | $R = B \times \log_2 V$；2400 波特 × QAM-16 → **9600 b/s**；带宽（Hz）≠ 数据率（b/s） |
| 奈氏准则 | **无噪声限码元速率**：$B_{\max}=2W$，$C = 2W\log_2 V$（4000 Hz、16 电平 → 32 kb/s） |
| 香农定理 | **有噪声限信息速率**：$C = W\log_2(1+S/N)$；**30 dB → S/N = 1000** |
| 双定理并用 | 实际极限**取两者较小值**；奈氏靠提高 V 提速率，香农只认带宽与信噪比 |
| 曼彻斯特 | 中间跳变**既定时钟又定数据**；效率 **50%**；**波特率 = 2×数据率**；以太网默认 |
| 差分曼彻斯特 | 中间跳变**只作时钟**，0/1 看**边界有无跳变**；抗干扰最强；令牌环 |
| 编码效率 | NRZ 100%（无自同步）、曼彻斯特/差分 50%、**4B/5B 80%** |
| 调制与 PCM | ASK 调幅 / FSK 调频 / PSK 调相；**QAM = 调幅+调相**（QAM-16 → 4 bit/码元）；PCM 采样频率 ≥ $2f_{\max}$ |
| 三种交换 | 电路：建连、独占、时延最小（电话网）；报文：整报文存储转发、时延大；分组：小单位流水线（因特网） |
| 时延公式 | $k$ 段链路 $p$ 个分组：$t = (p+k-1) \times$ 单分组单段发送时延（例：24 s → 12 s） |
| 有线介质 | 双绞线（绞合抗干扰、约 100 m）；同轴（**50Ω 基带 / 75Ω 宽带**）；光纤（**单模远、多模近**） |
| 无线介质 | 无线电波全向、微波**视距直线**（卫星时延 250&#126;270 ms）、红外定向 |
| 接口四特性 | **机械**（形状）、**电气**（电压）、**功能**（电平含义）、**过程/规程**（时序） |
