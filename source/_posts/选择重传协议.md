**选择重传协议（SR, Selective Repeat）**针对 GBN 的浪费做了改进：接收方**缓存乱序帧**，发送方**只重传超时的那一帧**，凑齐后按序交付上层，窗口再滑动。代价是接收方要**缓存多个帧**、确认要**逐个发**，协议更复杂。

![SR 滑动窗口示意图](/blog/images/第3章 数据链路层.assets/sr-时序图.png)

## 协议要点

| 特性 | SR |
|:---|:---|
| 发送窗口 $W_T$ | **$W_T = W_R \le 2^{n-1}$**（且 $W_T + W_R \le 2^n$） |
| 接收窗口 $W_R$ | $= W_T$（可缓存多个乱序帧） |
| 确认方式 | **逐个确认**（每个正确收到的帧单独确认） |
| 出错处理 | 只重传出错/超时的**那一帧** |
| 帧缓存 | 接收方**缓存乱序帧**，凑齐后按序交付上层 |

## 工作过程

```
发送方 A                             接收方 B
   │── 帧0 ─────────────────────────►│
   │── 帧1 ─────────────────────────►│
   │── 帧2 ────────── 丢失 ─────────►│  ← 帧 2 丢失
   │── 帧3 ─────────────────────────►│  ← 缓存帧3，单独确认
   │── 帧4 ─────────────────────────►│  ← 缓存帧4，单独确认
   │── 帧5 ─────────────────────────►│  ← 缓存帧5，单独确认
   │── 帧6 ─────────────────────────►│  ← 缓存帧6，单独确认
   │── 帧7 ─────────────────────────►│  ← 缓存帧7，单独确认
   │◄── ACK3 ACK4 ACK5 ACK6 ACK7 ───│
   │   (仅帧2 计时器超时 → 只重传帧2)
   │── 帧2 ─────────────────────────►│  ← 收到后凑齐 2~7，按序交付上层
```

> 图：SR——帧 2 丢失后接收方缓存 3~7 并逐个确认，发送方超时后**只重传帧 2**，接收方凑齐 2~7 后按序交付。

## 为什么 $W_T + W_R \le 2^n$

SR 允许**乱序接收 + 缓存**，新旧帧的序号区间不能重叠；取最大值时 $W_T = W_R = 2^{n-1}$。若窗口过大，超时重传的旧帧序号会落入接收方新窗口内，被误认为新帧。

> **考点**：SR 窗口上限 $W_T = W_R \le 2^{n-1}$（n=4 → 8）；**逐个确认**；只重传超时/出错的**那一帧**；接收方**缓存乱序帧**。

## GBN vs SR 对比（同一组数据：n = 4 位序号）

| 对比项 | GBN | SR |
|:---|:---|:---|
| 最大发送窗口 | $2^4 - 1 =$ **15** | $2^3 =$ **8**（$W_T = W_R$） |
| 接收窗口 | 1 | 8 |
| 帧缓存 | 无（丢弃乱序帧） | 有（缓存乱序帧） |
| 重传范围 | 出错帧及**后续所有帧** | 仅**出错帧本身** |
| 确认方式 | 累计确认 | 逐个确认 |
| 开销 | 重传浪费大 | 缓存 + 每帧确认开销大 |

> **考点**：GBN 是"**回退**重传"（窗口大、简单），SR 是"**选择**重传"（只重传错的，但要缓存、逐个确认）。**GBN 接收窗口 = 1，SR 接收窗口 = 发送窗口**。

## 优缺点

| | 说明 |
|:---|:---|
| 优点 | **只重传出错的帧**，信道质量差时带宽浪费远小于 GBN |
| 缺点 | 接收方需要**大缓存**缓存乱序帧；**逐帧确认**开销大；协议实现复杂 |

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| SR 发送窗口 | $W_T = W_R \le 2^{n-1}$（n=4 → 8；且 $W_T + W_R \le 2^n$） |
| SR 接收窗口 | $= W_T$，可**缓存多个乱序帧** |
| 确认方式 | **逐个确认**（每个正确收到的帧单独确认） |
| 出错处理 | **只重传超时/出错的那一帧** |
| 交付方式 | 缓存凑齐后**按序交付**上层，窗口才滑动 |
| GBN vs SR | GBN 回退重传（窗口 15 > SR 8）、接收窗口 1、累计确认；SR 选择重传、接收窗口 = 发送窗口、逐帧确认 |
