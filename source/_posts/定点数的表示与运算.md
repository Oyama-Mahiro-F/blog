**定点数**是小数点位置固定不变的数，是计算机表示数值数据最基本的方式。围绕它，408 考查一条完整的链路：**进位计数制的相互转换 → 真值与机器数（原码/反码/补码/移码）→ 定点数的移位、加减、乘除运算 → 溢出判断 → 加法器与 ALU 的硬件实现**。其中补码加减的溢出判断、原码/补码一位乘、原码除法（加减交替法）的**逐步演算**是大题重灾区，务必动手把每张演算表推一遍。

## 进位计数制及其相互转换

**进位计数制**：用有限数码、按"逢 r 进一"的规则计数。三个关键词：

| 概念 | 含义 |
|:---|:---|
| **基数 r** | 每个数码位可能出现 r 种字符（二进制 0/1，十六进制 0&#126;F） |
| **位权** | 第 i 位的权重为 $r^i$（小数点左侧为正幂、右侧为负幂） |
| **按权展开** | $(K_n...K_0.K_{-1}...K_{-m})_r = \sum K_i \times r^i$ |

计算机采用二进制的原因：**两个稳定状态的物理器件成本低、可靠；0/1 恰好对应逻辑假/真；逻辑门电路易于实现算术运算**。

### 二进制与八进制、十六进制的相互转换

二进制 **3 位一组**对应 1 位八进制、**4 位一组**对应 1 位十六进制；分组**以小数点为中心**，整数部分向左、小数部分向右，两端不足补 0。

```text
(1011010.11)2
  -> 八进制：    001 011 010 . 110  => (132.6)8
  -> 十六进制：  0101 1010 . 1100   => (5A.C)16
验算：1011010.11 = 90.75；132.6(8) = 64+24+2+0.75 = 90.75；5A.C = 5x16+10+0.75 = 90.75 ✓
```

> **考点**：分组方向记牢——**整数向左、小数向右，补 0 只补在两端**；八进制一位展开成 3 位、十六进制一位展开成 4 位。

### 十进制转换为 r 进制

- **整数部分：除基取余**——先取得的余数是**低位**，除到商 0 为止；
- **小数部分：乘基取整**——先取得的整数是**高位**，乘到小数部分为 0（或按精度取够位数）。

**例题**：把 $(11.6875)_{10}$ 转换为二进制。

```text
整数 11：                  小数 0.6875：
11 / 2 = 5  ... 1 (低位)   0.6875 x 2 = 1.375  -> 取 1 (高位)
 5 / 2 = 2  ... 1          0.375  x 2 = 0.75   -> 取 0
 2 / 2 = 1  ... 0          0.75   x 2 = 1.5    -> 取 1
 1 / 2 = 0  ... 1 (高位)   0.5    x 2 = 1.0    -> 取 1
整数 = 1011                小数 = 0.1011

结果：(11.6875)10 = (1011.1011)2
验算：1011 = 8+2+1 = 11；0.1011 = 0.5+0.125+0.0625 = 0.6875 ✓
```

> **易错点**：十进制小数大多**不能精确**转换成二进制，如 $(0.3)_{10} = 0.0100110011...$（0011 无限循环），此时按精度要求截取位数；"先余为低、先整为高"的方向不要写反。

## 真值与机器数

| 概念 | 含义 |
|:---|:---|
| **真值** | 带正负号的实际数值，符合人类书写习惯（如 $+5$、$-0.75$） |
| **机器数** | 数值在机器内的存储形式，**符号被数字化**（通常 0 表正、1 表负） |

**无符号数**：全部二进制位都是数值位、没有符号位，n+1 位无符号整数范围为 $0 \sim 2^{n+1}-1$。有符号数的机器码有四种：**原码、反码、补码、移码**。

## 原码、反码、补码、移码

### 四种机器码的定义

- **原码**：符号位 + 真值的绝对值。直观，但加减要**单独处理符号、比较绝对值大小**，硬件复杂。
- **反码**：正数同原码；负数符号位不变、数值位**按位取反**。主要作原码转补码的中间状态。
- **补码**：正数同原码；负数 = 反码末位 + 1。且 $[[x]_补]_补 = [x]_补$。
- **移码**：在补码基础上**只把符号位取反**（相当于真值加偏置 $2^n$），常用于表示**浮点数的阶码**。

**负数原码转补码的快捷法**：从右往左找到**第一个 1**，这个 1 及其**右边各位不变**、**左边各位按位取反**（符号位不变）。由 $[x]_补$ 求 $[-x]_补$ 则是**连同符号位一起取反、末位加 1**。

```text
原码 -> 反码 -> 补码（8 位字长）        快捷法示例：
+5    0000 0101 0000 0101 0000 0101   [-0.101100]原 = 1.101100
-5    1000 0101 1111 1010 1111 1011        从右第一个 1 及右边 "100" 不变
-127  1111 1111 1000 0000 1000 0001        左边 "101" 取反为 "010"
-128  无法表示  无法表示  1000 0000          [-0.101100]补 = 1.010100
```

补码的几个特殊形式（8 位）：

```text
补码形式      二进制       真值     意义
全 0         0000 0000     0       真值 0 唯一
全 1         1111 1111    -1       全 1 即 -1
1 打头全 0    1000 0000   -128      最小负数，无对应原码/反码
0 打头全 1    0111 1111   +127      最大正数
```

### 四种机器码大对比

| 码制 | 表示方式（n+1 位，n 位数值） | 0 的表示 | 整数表示范围 | 加减运算便利性 |
|:---|:---|:---|:---|:---|
| **原码** | 符号位 + 绝对值 | 2 个：$+0$ = 全 0，$-0$ = 10…0 | $-(2^n-1) \sim 2^n-1$ | 符号单独处理、需比大小，最麻烦 |
| **反码** | 负数数值位取反 | 2 个：全 0、全 1 | $-(2^n-1) \sim 2^n-1$ | 需处理循环进位，基本不单独使用 |
| **补码** | 负数取反加 1 | **唯一**：全 0 | $-2^n \sim 2^n-1$ | **符号位参与运算**、减法变加法，最方便 |
| **移码** | 补码符号位取反 | 唯一：10…0 | $-2^n \sim 2^n-1$ | 不直接做加减；保持大小顺序，便于比较 |

> **考点**：**补码比原码、反码多表示一个最小负数** $-2^n$（8 位即 −128），它没有对应的原码和反码；定点小数补码范围为 $-1 \sim 1-2^{-n}$，同样多出一个 $-1$。
> **易错点**：移码**全 0 时真值最小、全 1 时真值最大**，大小顺序与真值一致——这正是浮点数阶码采用移码、可按无符号数方式直接比较两个浮点数大小的原因。

## 字符与字符串

### ASCII 码

**ASCII** 用 **7 位**二进制表示 **128** 个字符，计算机中用 1 字节存储、**最高位为 0**；00H&#126;1FH 为控制字符（换行 LF = 0AH、回车 CR = 0DH），20H&#126;7EH 为可打印字符。

| 字符 | ASCII（十进制） | 记忆点 |
|:---|:---|:---|
| '0' &#126; '9' | 48 &#126; 57（30H &#126; 39H） | 数字字符 = 30H + 数值 |
| 'A' &#126; 'Z' | 65 &#126; 90（41H &#126; 5AH） | 大写从 65 开始 |
| 'a' &#126; 'z' | 97 &#126; 122（61H &#126; 7AH） | 小写 = 大写 + 32（差 bit5） |
| 空格 | 32（20H） | 最小的可打印字符 |

### 汉字编码与 UTF-8

- **GB2312**：双字节编码，收录 6763 个汉字；**国标码 = 区位码 + 2020H**，**汉字内码 = 国标码 + 8080H**（最高两位置 1，避免与 ASCII 混淆）。
- **UTF-8**：Unicode 的**变长**编码，占 1&#126;4 字节，**与 ASCII 完全兼容**——英文字符 1 字节（'A' 与 ASCII 相同），常用汉字 3 字节（'中' = `11100100 10111000 10101101`）。

### 字符串的存储与大小端

C 语言字符串以**空字符 `'\0'` 结尾**（`strlen` 不计入结尾的 `\0`）；也可用长度字段（Pascal 风格）或定长补空格存储。多字节数据在内存中的字节顺序分两种：

| 方式 | 规则 | 典型场景 |
|:---|:---|:---|
| **大端（Big-Endian）** | **最高有效字节（MSB）存最低地址** | **网络字节序**、Java 虚拟机 |
| **小端（Little-Endian）** | 最低有效字节（LSB）存最低地址 | x86/x64 |

```text
32 位数据 0x12345678 的内存布局（地址从低到高）：
大端：  12 | 34 | 56 | 78    高字节在前，符合书写习惯
小端：  78 | 56 | 34 | 12    低字节在前
```

> **考点**：给一段内存字节序列判断大小端——**最低地址放高字节是大端，放低字节是小端**；网络程序跨主机传输需统一按网络字节序（大端）转换。

## 定点数的表示

**定点数**的小数点位置固定且**隐含、不占存储位**：**定点整数**小数点隐含在最低位之后，**定点小数**小数点隐含在符号位之后、数值位之前。

![定点数的表示格式](/blog/images/计组第2章 数据的表示和计算.assets/fixed-point-format.png)

设字长 n+1 位（1 位符号 + n 位数值），表示范围：

| 码制 | 定点整数 | 定点小数 |
|:---|:---|:---|
| 原码 | $-(2^n-1) \sim 2^n-1$ | $-(1-2^{-n}) \sim 1-2^{-n}$ |
| 补码 | $-2^n \sim 2^n-1$ | $-1 \sim 1-2^{-n}$ |
| 无符号数 | $0 \sim 2^{n+1}-1$ | $0 \sim 1-2^{-(n+1)}$ |

> **考点**：定点数**运算简单、硬件成本低**，但范围有限、精度固定；浮点数靠阶码浮动小数点位置来扩大范围（IEEE 754 另文整理）。

## 定点数的移位运算

**算术移位**针对带符号数，移位后**符号位保持不变**；**逻辑移位**把整个字长当作无符号位串整体移动。添补代码规则：

| 码制 / 类型 | 算术左移（高位丢） | 算术右移（低位丢） |
|:---|:---|:---|
| 原码（正数、负数） | 数值位补 0，符号不变 | 数值位补 0，符号不变 |
| 补码正数 | 补 0 | 补 0 |
| **补码负数** | **低位补 0** | **高位补 1** |
| 反码负数 | 补 1 | 补 1 |
| 逻辑移位（无符号） | 低位补 0 | 高位补 0 |

规律：**正数一律补 0**；负数——原码补 0、反码补 1、补码"**左 0 右 1**"。

- 移位与乘除：算术左移一位 = ×2（可能溢出）；右移一位 = ÷2（补码负数右移**向下取整**，$-1 \gg 1 = -1$）。
- **循环移位**：不带进位位 CF 时数值位自身首尾相接循环；**带 CF** 时 CF 一起进入循环（大循环），常用于字节交换、检测移位中丢失的位。

```text
算术右移（补码负数高位补 1）：[-12]补 = 1111 0100 -> 1111 1010 = -6 ✓（-12/2）
逻辑右移（高位一律补 0）：    1111 0100 -> 0111 1010 = 122（作纯位串处理）
算术左移溢出：[+64]补 = 0100 0000 -> 1000 0000 = -128（符号位被数值冲掉，溢出）
```

## 定点数的加减运算

### 补码加减法

$$[A+B]_补 = [A]_补 + [B]_补 \ (\bmod\ 2^{n+1}) \qquad [A-B]_补 = [A]_补 + [-B]_补$$

- **符号位与数值位一起参与运算**，符号位产生的进位**直接丢弃**；
- 求 $[-B]_补$：把 $[B]_补$ **连同符号位一起取反、末位加 1**。硬件上减法 = "B 取反 + 最低位进位置 1" 的加法，与加法**共用同一套加法器**；
- 原码加减则须**符号单独处理**：同号相加绝对值相加、符号不变；异号相加绝对值大减小、符号随大数。

**例题**（机器字长 8 位 = 双符号位 + 6 位数值，$x = +50$，$y = -39$，求 $[x+y]_补$、$[x-y]_补$ 并判断溢出）：

```text
[x]补 = 00 110010      [y]补 = 11 011001      [-y]补 = 00 100111

(1) [x+y]补：
      00 110010   (+50)
    + 11 011001   (-39)
    -----------
    (1)00 001011        符号位进位丢弃（模 2^8）
    =  00 001011 = +11  双符号位 00 -> 无溢出 ✓（50-39=11）

(2) [x-y]补 = [x]补 + [-y]补：
      00 110010   (+50)
    + 00 100111   (+39)
    -----------
       01 011001       双符号位 01 -> 正溢出！（50+39=89，超出 6 位数值范围 +63）
```

### 溢出概念与判断方法

**溢出（Overflow）**：运算结果超出该字长能表示的范围。**只有同号相加（或异号相减）才可能溢出**，一正一负相加绝不可能溢出。三种判断方法：

| 方法 | 判断规则 | 逻辑表达式 |
|:---|:---|:---|
| **单符号位法** | 同号相加，结果符号与操作数相反则溢出 | $V = A_S B_S \overline{S_S} + \overline{A_S}\,\overline{B_S}\,S_S$ |
| **进位判断法** | 符号位进位 $C_s$ 与最高数值位进位 $C_1$ **不同**则溢出 | $V = C_s \oplus C_1$ |
| **双符号位法** | 结果两符号位不同则溢出：**01 正溢出、10 负溢出** | $V = S_{S1} \oplus S_{S2}$ |

- 双符号位（变形补码/模 4 补码）：00 表正、11 表负，**最高一位才是真正的符号位**；存储时可只存一个符号位，运算时复制成两位；
- **无符号数**越界看 **CF**：加法最高位有进位即溢出；减法 $CF = C_{out} \oplus Sub$（$C_{out}=0$ 表示不够减、有借位）。

> **考点**：上例 (2) 改用单符号位验证：0 110010 + 0 100111 = 1 011001，**正 + 正 = 负**，溢出；此时 $C_s = 0$、$C_1 = 1$，$0 \oplus 1 = 1$——三种方法结论一致，真符号以双符号位的**最高位**为准。

## 定点数的乘法运算

### 原码一位乘法

- **符号位不参与数值运算**：积的符号 $P_s = X_s \oplus Y_s$（同号正、异号负）；
- 数值部分取**绝对值**相乘：部分积 A 初值 0（用**双符号位**暂存进位），每轮看**乘数末位**——为 1 加被乘数绝对值、为 0 加 0，随后 A 与乘数寄存器 C **联合逻辑右移一位**（高位补 0），A 移出的低位进入 C；
- n 位数值共 **n 次加法、n 次右移**，乘积 = A 的数值部分（高位）拼接 C 中移入的低位。

**例题**：$x = 0.1101$，$y = -0.1011$，用原码一位乘求 $x \times y$。

```text
|X| = 00.1101（双符号位）  C = 1011（|Y| 数值位）  A = 00.0000
Ps = Xs xor Ys = 0 xor 1 = 1

轮次  C 末位  操作     部分积 A                     C（乘数）
初始   --    --      00.0000                     1011
 1     1    加 |X|   00.1101
       右移          00.0110                     1101
 2     1    加 |X|   01.0011  (00.0110+00.1101)
       右移          00.1001                     1110
 3     0    加 0     00.1001
       右移          00.0100                     1111
 4     1    加 |X|   01.0001  (00.0100+00.1101)
       右移          00.1000                     1111

数值积 = A 低 4 位 1000 与 C 1111 拼接 = 0.10001111
X × Y = -0.10001111
验算：0.1101 = 13/16，0.1011 = 11/16，13 * 11 = 143 = 10001111(2)，符号为负 ✓
```

### 补码一位乘法（Booth 算法）

补码乘法**符号位直接参与运算**。乘数取补码（连同符号位），末位附加一位**辅助位** $Y_{n+1} = 0$；每步根据**乘数寄存器最低位 $Y_n$ 与辅助位 $Y_{n+1}$** 决定操作：

| $Y_n$ | $Y_{n+1}$ | 操作 |
|:---|:---|:---|
| 0 | 0 | 部分积 + 0，算术右移一位 |
| 0 | 1 | 部分积 $+ [X]_补$，算术右移一位 |
| 1 | 0 | 部分积 $+ [-X]_补$，算术右移一位 |
| 1 | 1 | 部分积 + 0，算术右移一位 |

口诀：看相邻两位的差——**"01 加 $[X]_补$，10 加 $[-X]_补$，00/11 不加"**。n 位数值共 **n+1 次加法、n 次移位**，**最后一步加法后不再移位**；部分积与被乘数均用双符号位补码，移位是**算术右移**（符号位不变，负数补 1）。

**例题**：$x = 0.1101$，$y = -0.1011$，用 Booth 算法求 $[x \times y]_补$。

```text
[X]补 = 00.1101    [-X]补 = 11.0011    [Y]补 = 1.0101    辅助位 = 0

步骤  Yn Yn+1  操作       部分积 A                        C（乘数 | 辅助位）
初始   --     --        00.0000                        10101 | 0
 1     10    加 [-X]补  11.0011  (00.0000+11.0011)
       算术右移         11.1001                        11010 | 1
 2     01    加 [X]补   00.0110  (11.1001+00.1101，进位丢弃)
       算术右移         00.0011                        01101 | 0
 3     10    加 [-X]补  11.0110  (00.0011+11.0011)
       算术右移         11.1011                        00110 | 1
 4     01    加 [X]补   00.1000  (11.1011+00.1101，进位丢弃)
       算术右移         00.0100                        00011 | 0
 5     10    加 [-X]补  11.0111  (00.0100+11.0011)      末步不移位

[X×Y]补 = 11.01110001（A 的数值 0111 拼接 C 高 4 位 0001）
X × Y = -0.10001111
验算：13/16 * 11/16 = 143/256 = 0.10001111，符号为负 ✓
```

![Booth 补码一位乘法演算示例（被乘数为负的情形）](/blog/images/计组第2章 数据的表示和计算.assets/booth-example.png)

> **易错点**：Booth 乘数寄存器的位会逐步被部分积低位替换，判断对象始终是**当前的最低两位**（含辅助位）；与原码一位乘的"逻辑右移补 0"不同，Booth 是**算术右移**，负数部分积高位补 1。

## 定点数的除法运算

原码除法同样**符号位单独处理**（商符 = 两数符号异或），数值部分取绝对值做无符号除法，核心是"**左移 — 试减 — 上商**"：余数 R 减去除数，**够减（R ≥ 0）商 1**，**不够减（R < 0）商 0**。

| 方法 | 不够减时 | 每步加法次数 | 速度 |
|:---|:---|:---|:---|
| **恢复余数法** | 加回除数恢复原余数，再左移试减 | 1&#126;2 次（不固定） | 慢 |
| **加减交替法（不恢复余数法）** | 不恢复，**下一步左移后改加除数** | **固定 1 次** | 快约一倍 |

加减交替法的依据：某步余数 $R_i < 0$ 时，"恢复后左移再减" = $2(R_i + |Y|) - |Y| = 2R_i + |Y|$，故**直接左移加除数**完全等价且省一次加法。

**例题**：$x = 1101$（13），$y = 0011$（3），用**加减交替法**求商与余数（减法用补码实现）。

```text
[|y|]补 = 0 0011    [-|y|]补 = 1 1101（R 用 5 位寄存器，含 1 位符号）
初始：R = 0 0000，Q = 1101（被除数）

步骤  操作                   余数 R        上商   说明
 1    左移（移入被除数位 1）   0 0001
      试减 R + [-|y|]补      1 1110 < 0    0     不恢复
 2    左移（移入 1）          1 1101
      加 [|y|]补             0 0000 >= 0   1
 3    左移（移入 0）          0 0000
      试减 R + [-|y|]补      1 1101 < 0    0     不恢复
 4    左移（移入 1）          1 1011
      加 [|y|]补             1 1110 < 0    0     最后一位商
      末步恢复 + [|y|]补     0 0001              恢复为正余数

商 Q = 0100（4），余数 R = 0001（1）  =>  13 / 3 = 4 ... 1
验算：3 * 4 + 1 = 13 ✓
```

若用**恢复余数法**：上例第 1、3、4 步不够减时都要先"加回除数恢复"，再左移、下一步重新试减，步骤相同但每步多一次加法，最终结果一致。

> **易错点**："够减看余数正负"只对**原码除法**成立；**补码除法**（加减交替）符号位参与运算、够减看**余数与除数是否同号**，且**末位商恒置 1**——两套规则不要混用。

## 串行加法器与并行加法器

### 一位全加器与串行进位加法器

**全加器**有三个输入（本位加数 $A_i$、$B_i$，低位进位 $C_{i-1}$）、两个输出：

$$S_i = A_i \oplus B_i \oplus C_{i-1} \qquad C_i = A_iB_i + (A_i \oplus B_i)C_{i-1}$$

把 n 个全加器级联、低位进位输出接高位进位输入，就是 **n 位串行进位加法器（行波进位加法器，Ripple-Carry Adder）**：

![串行进位（行波）加法器与一位全加器电路](/blog/images/计组第2章 数据的表示和计算.assets/ripple-adder.png)

- **优点**：结构简单、硬件成本最低；**缺点**：高位必须等低位进位逐级传上来，**延迟与字长 n 成正比**，速度慢；
- 它天然提供 $C_n$（符号位进位）与 $C_{n-1}$（最高数值位进位），**一个异或门即可检测带符号数溢出**：$OF = C_n \oplus C_{n-1}$。

### 并行进位加法器（先行进位 CLA）

**CLA（Carry Look-ahead Adder）的核心思想**：把进位表达式**逐位展开**，使每位进位只依赖本位输入 $A_i$、$B_i$ 和最低位进位 $C_{-1}$，从而所有进位**并行产生**、一级门延迟形成。定义两个辅助函数：

- 进位**生成**函数：$G_i = A_iB_i$——本位两数都为 1，必定产生进位；
- 进位**传递**函数：$P_i = A_i \oplus B_i$——本位有 1，低位进位可以穿过本位传向高位。

$$C_0 = G_0 + P_0C_{-1}$$
$$C_1 = G_1 + P_1G_0 + P_1P_0C_{-1}$$
$$C_2 = G_2 + P_2G_1 + P_2P_1G_0 + P_2P_1P_0C_{-1}$$
$$C_3 = G_3 + P_3G_2 + P_3P_2G_1 + P_3P_2P_1G_0 + P_3P_2P_1P_0C_{-1}$$

**例**：$A = 1011$（11），$B = 0111$（7），$C_{-1} = 0$。

```text
G = A and B = 0011      P = A xor B = 1100
C0 = G0 + P0*C-1 = 1 + 0*0 = 1
C1 = G1 + P1*C0  = 0 + 1*1 = 1
C2 = G2 + P2*C1  = 1 + 0*1 = 1
C3 = G3 + P3*C2  = 0 + 1*1 = 1
和 Si = Pi xor C(i-1)：S = 0010，C3 = 1  =>  结果 = 10010（18）✓
四个进位都只由 G、P、C-1 决定，可同时产生（一级门延迟）。
```

> **考点**：位数增大时 $C_i$ 展开式过长，受**门电路扇入限制**，实际采用**分组**实现——**单级先行进位**（组内并行、组间串行）与**多级先行进位**（组间也并行，引入组生成 $G^*$、组传递 $P^*$，公式与位级完全同构）。16 位加法器常分 4 组、每组 4 位。

| 对比 | 串行进位（行波） | 并行进位（CLA） |
|:---|:---|:---|
| 进位产生 | 逐级等待，$C_i$ 依赖 $C_{i-1}$ | 展开并行、同时产生 |
| 延迟 | $O(n)$ 级门延迟 | $O(1)$ 级门延迟 |
| 硬件成本 | 低（n 个全加器级联） | 高（额外的进位生成逻辑） |

## 算术逻辑单元 ALU

**ALU（算术逻辑单元）**是运算器的核心，属于**组合逻辑电路**（无记忆，输出仅由当前输入决定）：既做加减等**算术运算**，也做与/或/非/异或等**逻辑运算**（逻辑运算按位独立、不产生进位）。

```text
             ALUop（来自控制器 CU）
                   |
           +---------------+
   A ----> |               |
           |      ALU      |----> F（n 位运算结果）
   B ----> |               |
           +-------+-------+
                   v
            标志位生成逻辑 ----> OF、CF、SF、ZF（送入 PSW/标志寄存器）
```

- **MUX 选择运算**：内部算术单元（加法器）与逻辑单元的结果由**多路选择器（MUX）**按 ALUop 选择输出；`Sub` 就是 ALUop 之一——Sub=1 时 B 取反、最低位进位置 1，同一套加法器即可做减法；
- 经典芯片 **74181**：4 位 ALU，$M=0$ 做 16 种算术运算、$M=1$ 做 16 种逻辑运算；多片 74181 配合先行进位芯片 **74182** 可级联成任意位宽的 ALU；
- **四个标志位**的生成（详细在 CPU 章）：

| 标志 | 生成逻辑 | 含义 |
|:---|:---|:---|
| **ZF** | 结果全部位**或非** | 结果为 0（可用于比较相等） |
| **SF** | 取结果最高位 $F_{n-1}$ | 结果符号（带符号数才有意义） |
| **OF** | $C_n \oplus C_{n-1}$ | **带符号数**溢出 |
| **CF** | $C_{out} \oplus Sub$ | **无符号数**进位/借位 |

> **考点**：带符号数溢出看 **OF**、无符号数越界看 **CF**——同一套加法器硬件，仅按标志位区别解释；条件转移指令正是读取这些标志位实现分支。

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 二/八/十六进制 | 3 位一组 ↔ 八进制，4 位一组 ↔ 十六进制；小数点为中心，两端补 0 |
| 十进制转二进制 | 整数除 2 取余（先余为低），小数乘 2 取整（先整为高）；0.3 类小数无限循环 |
| 原码 | 符号 + 绝对值；0 有两个；$-(2^n-1) \sim 2^n-1$（n 位数值） |
| 补码 | 负数取反加 1；0 唯一；$-2^n \sim 2^n-1$，多一个最小负数（8 位即 −128） |
| 补码转换 | 负数原→补：从右第一个 1 及右边不变、左边取反；求 $[-x]_补$：连同符号位取反加 1 |
| 移码 | 补码符号位取反（加偏置 $2^n$）；全 0 最小、全 1 最大；用于浮点阶码、便于比较 |
| ASCII | '0'=48（30H）、'A'=65（41H）、'a'=97（61H）；大小写差 32；7 位编码、字节最高位 0 |
| 大小端 | 大端：高字节存低地址（网络字节序）；小端相反（x86）；`strlen` 不含结尾 '\0' |
| 算术移位 | 补码负数：左移补 0、右移补 1；原码数值恒补 0；反码负数补 1；正数全补 0 |
| 补码加减 | $[A \pm B]_补 = [A]_补 + [\pm B]_补$，符号位参与运算、进位丢弃 |
| 溢出判断 | 双符号位 01 正溢、10 负溢；$V = C_s \oplus C_1$；仅同号加/异号减可能溢出 |
| 原码一位乘 | 符号异或、数值取绝对值；看乘数末位决定加被乘数或 0；n 加 n 移，逻辑右移补 0 |
| Booth 补码一位乘 | $Y_nY_{n+1}$：01 加 $[X]_补$、10 加 $[-X]_补$、00/11 不加；n+1 加 n 移，末步不移位 |
| 原码除法（加减交替） | 不够减商 0 且不恢复，下一步左移改加除数；每步固定 1 次加法 |
| CLA | $G_i = A_iB_i$（生成）、$P_i = A_i \oplus B_i$（传递）；进位展开并行产生，一级门延迟 |
| 标志位 | ZF 全 0；SF 取最高位；OF = $C_n \oplus C_{n-1}$（带符号）；CF = $C_{out} \oplus Sub$（无符号） |
