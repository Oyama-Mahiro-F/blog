**问题描述**：设 $S_1=\{a_0,a_1,\dots,a_{n-1}\}$、$S_2=\{b_0,b_1,\dots,b_{m-1}\}$、$S_3=\{c_0,c_1,\dots,c_{k-1}\}$ 是三个**升序**数组，定义三元组 $(a_i,\ b_j,\ c_k)$ 的**距离**为：

$$D = |a_i - b_j| + |b_j - c_k| + |c_k - a_i|$$

求所有三元组中距离的最小值。

> 王道《数据结构》线性表经典综合题（408 常考思路），要求设计**时间上尽可能高效**的算法。三个数组均有序是本题的关键突破口。

## 核心性质：距离化简

对任意三个数，设排序后为 $x \le y \le z$，则：

$$D = |x-y| + |y-z| + |z-x| = (y-x) + (z-y) + (z-x) = 2(z-x)$$

即 **$D = 2 \times (\text{最大值} - \text{最小值})$**，中间数 $y$ 在求和中被**抵消**。求最小距离等价于：**从三个数组中各取一个数，使最大值与最小值之差最小**。

## 暴力法

三重循环枚举所有三元组，逐一代入距离公式：

```c++
int minDistance(int a[], int n, int b[], int m, int c[], int k) {
    int ans = INT_MAX;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            for (int t = 0; t < k; t++) {
                int x = a[i], y = b[j], z = c[t];
                int mx = x > y ? (x > z ? x : z) : (y > z ? y : z);
                int mn = x < y ? (x < z ? x : z) : (y < z ? y : z);
                int d = 2 * (mx - mn);
                if (d < ans) ans = d;
            }
    return ans;
}
```

时间复杂度 $O(nmk)$，数据规模稍大就不可行。

## 三指针贪心算法

### 思路

利用有序性，用三个指针 $i,j,t$ 分别扫描三个数组：

1. 三个指针初始指向各自数组**首元素**
2. 每轮计算当前三元组距离，更新答案
3. **移动最小值所在数组的指针**（向后 +1）
4. 任一指针越界即停止

### 为什么移动"最小"的指针

固定当前三元组，最大值 $M$ 与最小值 $m$ 已经确定。若**不移动** $m$ 所在指针，则 $m$ 不变而 $M$ 只会增大或不变，差值 $M-m$ **不可能变小**；唯一的改进可能，就是**增大最小值**——即移动指向最小元素的指针。每一步都做这个唯一可能改善的选择，故贪心正确。

```c++
#include <climits>

int minDistance(int a[], int n, int b[], int m, int c[], int k) {
    int i = 0, j = 0, t = 0;              // 三个指针
    int ans = INT_MAX;
    while (i < n && j < m && t < k) {
        int x = a[i], y = b[j], z = c[t];
        int mx = x > y ? (x > z ? x : z) : (y > z ? y : z);
        int mn = x < y ? (x < z ? x : z) : (y < z ? y : z);
        int d = 2 * (mx - mn);            // 当前三元组距离
        if (d < ans) ans = d;
        if (x == mn) i++;                 // 移动最小元素所在指针
        else if (y == mn) j++;
        else t++;
    }
    return ans;
}
```

> 每一轮三个指针中**至少**有一个前进，且指针永不回退，总移动次数不超过 $n+m+k$。

## 执行过程示例

$a = [1, 3, 8]$，$b = [2, 5, 9]$，$c = [4, 6, 7]$：

| 轮次 | $a[i]$ | $b[j]$ | $c[t]$ | 最小 | 最大 | $D=2(M-m)$ | 移动 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---|
| 1 | 1 | 2 | 4 | 1 | 4 | 6 | $i$ → $a[1]=3$ |
| 2 | 3 | 2 | 4 | 2 | 4 | 4 | $j$ → $b[1]=5$ |
| 3 | 3 | 5 | 4 | 3 | 5 | 4 | $i$ → $a[2]=8$ |
| 4 | 8 | 5 | 4 | 4 | 8 | 8 | $t$ → $c[1]=6$ |
| 5 | 8 | 5 | 6 | 5 | 8 | 6 | $j$ → $b[2]=9$ |
| 6 | 8 | 9 | 6 | 6 | 9 | 6 | $t$ → $c[2]=7$ |
| 7 | 8 | 9 | 7 | 7 | 9 | 4 | $t$ 越界，停止 |

最小距离为 **4**，例如三元组 $(3, 2, 4)$：$|3-2|+|2-4|+|4-3| = 1+2+1 = 4$ ✓

## 复杂度分析

| 时间复杂度 | $O(n + m + k)$ |
|:---|:---|
| 空间复杂度 | $O(1)$（仅三个指针） |
| 对比暴力 | $O(nmk)$ → $O(n+m+k)$，质的飞跃 |

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 距离公式 | 排序后 $D = 2(\max - \min)$，中间数抵消 |
| 移动策略 | 每轮移动**最小元素**所在指针（唯一可能改善的选择） |
| 终止条件 | 任一指针越界 |
| 时间复杂度 | $O(n+m+k)$，空间 $O(1)$ |

> **延伸**：本题是"$k$ 个有序序列覆盖最小区间"问题的特例（$k=3$），对应 LeetCode 632 *Smallest Range Covering Elements from K Lists*；若数组无序，先排序再套用本算法即可。
