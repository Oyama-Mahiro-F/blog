交换排序族的共同思想是：**通过交换逆序的相邻（或跨距离）元素来消除逆序**。冒泡排序每次只消除一个逆序对，快速排序则一次划分把一批逆序对"批量"消除，因此快得多。

| 算法 | 交换方式 | 时间复杂度 | 稳定性 |
|:---|:---|:---|:---|
| 冒泡排序 | 相邻元素逐个交换 | $O(n^2)$ | **稳定** |
| 快速排序 | 以枢轴为中心跨距离交换 | 平均 $O(n\log n)$ | **不稳定** |

## 冒泡排序

每趟从头到尾依次比较相邻元素，若逆序则交换——每趟把最大值"冒"到末尾。若某趟无交换，则已有序，提前结束。

### 排序过程示例

```
初始:  49  38  65  97  76  13  27

第1趟: 38↙49  65  76↙97  13↙97  27↙97   → 38  49  65  76  13  27  [97]
第2趟: 38  49  65  13↙76  27↙76 [76  97]  → 38  49  65  13  27  [76  97]
...
```

（"↙" 表示交换方向）

### 算法实现

```c++
void BubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {           // 逆序则交换
                int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
                swapped = 1;
            }
        }
        if (!swapped) break;                 // 无交换 → 已有序
    }
}
```

### 性能分析

| 情况 | 时间 | 说明 |
|:---|:---|:---|
| 最好（正序） | $O(n)$ | 一趟无交换即结束 |
| 最坏（逆序） | $O(n^2)$ | |
| 平均 | $O(n^2)$ | |
| 空间 | $O(1)$ | |
| 稳定性 | **稳定** | `>` 不交换相等元素 |

## 快速排序

快速排序是**分治**算法：每次选一个**枢轴（pivot）**，将序列划分为左右两部分——左边全部 $\leq$ pivot，右边全部 $\geq$ pivot，然后递归排序左右子序列。

![快速排序示意图](/blog/images/第8章 排序.assets/alg-sort-fast-1.jpg)

### 算法实现

```c++
int Partition(int a[], int low, int high) {
    int pivot = a[low];                      // 选第一个元素为枢轴
    while (low < high) {
        while (low < high && a[high] >= pivot) high--;
        a[low] = a[high];                    // 比 pivot 小的移到左边
        while (low < high && a[low] <= pivot) low++;
        a[high] = a[low];                    // 比 pivot 大的移到右边
    }
    a[low] = pivot;                          // 枢轴归位
    return low;
}

void QuickSort(int a[], int low, int high) {
    if (low < high) {
        int pos = Partition(a, low, high);   // 一趟划分
        QuickSort(a, low, pos - 1);          // 递归左半
        QuickSort(a, pos + 1, high);         // 递归右半
    }
}
```

> 递归调用栈深度 $O(\log n)$（平均），最坏 $O(n)$。

### 快速排序与二叉树

快速排序的递归过程与**二叉排序树（BST）**有着内在联系：

- 每一趟划分选定枢轴 pivot，相当于以 pivot 为**根结点**
- 小于 pivot 的元素 → **左子树**；大于 pivot 的元素 → **右子树**
- 递归划分 → 递归构造左右子树

```
序列: [38  13  49  76  97  65  27]

以 49 为枢轴:  左: [38  13  27]  →  右: [76  97  65]
               以 38 为枢轴:          以 76 为枢轴:
                 左: [13  27]           左: [65]
                 以 13 为枢轴:            右: [97]
                   右: [27]

对应的 BST 结构:          49
                        /  \
                      38    76
                     /     /  \
                   13     65  97
                     \
                      27
```

> - **最好情况**（每次枢轴接近中位数）：BST 接近**平衡**，深度 $O(\log n)$
> - **最坏情况**（每次枢轴为最值）：BST 退化为**单链表**，深度 $O(n)$
> - 快排的时间复杂度等价于对应 BST 的**查找路径长度之和**
> - 树高即基于当前 pivot 所需进行的**交换次数**
> - 树的**中序遍历**即当前 pivot 完成一次排序后的最终序列

### 性能分析

| 情况 | 时间 | 说明 |
|:---|:---|:---|
| 最好 | $O(n\log n)$ | 每次划分均匀（左右子序列长度接近） |
| 最坏 | $O(n^2)$ | 正序或逆序（每次枢轴在端点） |
| 平均 | $O(n\log n)$ | |
| 空间 | $O(\log n)$ | 递归调用栈 |
| 稳定性 | **不稳定** | 划分时跨越交换 |

> **408 考点**：快排最坏情况（正序/逆序）→ $O(n^2)$；优化方法：**三者取中法**选枢轴。

### 递归分析的数学推导

快速排序的主要时间花费在**划分**上，对长度为 $k$ 的序列划分时关键字的比较次数是 **$k-1$**。

设比较次数为 $C(n)$，递推式：

$$C(n) = n - 1 + C(k) + C(n - k - 1)$$

**最好情况**（每次划分大致相等，$k \approx n/2$）：

$$
\begin{aligned}
C(n) &\leq n + 2 \times C(n/2) \\
     &\leq n + 2 \times [n/2 + 2 \times C(n/4)] \\
     &\leq 2n + 4 \times C(n/4) \\
     &\leq \dots \\
     &\leq h \times n + 2^h \times C(n/2^h)
\end{aligned}
$$

当 $n / 2^h = 1$ 时排序结束，即 $h = \log_2 n$，$C(1)$ 看成常数因子，则：

$$C(n) \leq n \times \log_2 n + n \times C(1)$$

$$\therefore\ C(n) \leq O(n \log_2 n)$$

**最坏情况**（每次划分有一个子序列为空，即枢轴总是当前最小或最大关键字——**正序或逆序时发生**）：

$$
\begin{aligned}
C(n) &= n - 1 + C(n - 1) \\
     &= (n - 1) + (n - 2) + \dots + 1 \\
     &= \frac{n(n-1)}{2}
\end{aligned}
$$

$$\therefore\ C(n) = O(n^2)$$

**空间复杂度**（递归调用栈深度）：

| 情况 | 栈深度 | 说明 |
|:---|:---|:---|
| 最好（划分均匀） | $\lfloor \log_2 n \rfloor + 1$ | 递归深度 = 二叉树深度 |
| 最坏（每次只划出一个元素） | $O(n)$ | 退化为单链 |
| 平均 | $O(\log_2 n)$ | 平均接近于最好情况 |

$$\therefore\ S(n) = O(\log_2 n)$$

## 两种交换排序对比

| 项目 | 冒泡排序 | 快速排序 |
|:---|:---|:---|
| 思想 | 相邻逆序逐个交换 | 枢轴划分，跨距离交换 |
| 最好 | $O(n)$（正序提前结束） | $O(n\log n)$（划分均匀） |
| 最坏 | $O(n^2)$（逆序） | $O(n^2)$（**正序或逆序**） |
| 平均 | $O(n^2)$ | $O(n\log n)$ |
| 空间 | $O(1)$ | $O(\log n)$（递归栈） |
| 稳定性 | **稳定** | **不稳定** |
| 每趟定最终位置 | 能（确定一个最大值） | 能（枢轴归位即最终位置） |

> **易错点**：冒泡与快排的"最好/最坏"触发条件**恰好相反**——冒泡在**正序**时最快（一趟即停），快排在**正序**时最慢（每次枢轴都在端点，退化为 $O(n^2)$）。这是 408 高频陷阱。

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 冒泡排序 | 相邻逆序交换，某趟**无交换即提前结束**；最好 $O(n)$（正序）；**稳定** |
| 快速排序 | 平均/最好 $O(n\log n)$，**最坏 $O(n^2)$（正序或逆序）**；递归栈空间 $O(\log n)$；**不稳定** |
| 一趟划分比较次数 | $k-1$ 次 |
| 快排优化 | **三者取中**选枢轴 |
| 与 BST 联系 | 递归过程对应 **BST**，树高即递归深度，**中序遍历**即排序结果 |
| 基本有序时 | 快排退化为 $O(n^2)$（此时直接插入最快 $O(n)$） |
| 每趟能否定最终位置 | 能（交换类排序，每趟确定一个元素位置） |
| 取前 k 个最小 | 冒泡/简单选择/堆皆可，**堆排序性能最好**（$n \gg k$ 时） |
