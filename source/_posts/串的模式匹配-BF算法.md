给定主串 $S$（长度为 $n$）和模式串 $T$（长度为 $m$，$m \leq n$），在 $S$ 中找到 $T$ **首次出现**的位置（1 索引）；匹配失败返回 0。

## 算法思想

从 $S$ 的第 1 个字符开始，逐个与 $T$ 比较，若匹配失败则 $S$ 指针**回溯**到下一个位置重新开始。

```
S = "ababcabcacbab"
T = "abcac"

第1趟: a b a b c a b c a c b a b
      a b c a c               → S[1]!=匹配 S[3]!=T[3], 失败

第2趟: a b a b c a b c a c b a b
        a b c a c             → S[2]!=匹配 S[2]!=T[1], 失败

...最终在位置 6 匹配成功
```

## 算法实现

```c++
int Index_BF(SString S, SString T) {
    int i = 1, j = 1;
    while (i <= S.length && j <= T.length) {
        if (S.ch[i] == T.ch[j]) {
            i++; j++;                        // 继续比较下一字符
        } else {
            i = i - j + 2;                   // i 回溯
            j = 1;                           // j 回溯到起点
        }
    }
    if (j > T.length) return i - T.length;   // 匹配成功
    return 0;                                 // 匹配失败
}
```

> 关键：失配时 $i$ 回溯到本轮起始位置的下一个位置（`i = i - j + 2`），$j$ 重置为 1。

## 性能分析

| 时间复杂度 | 最好 $O(n)$，最坏 $O(nm)$ |
|:---|:---|
| 空间复杂度 | $O(1)$ |
| 适用场景 | 模式串短 |

**最坏情况示例**：主串 `"0000000001"`、模式串 `"0001"`——每趟都要比较到最后一位才失败，i 反复回溯。

## BF vs KMP 对比

| 维度 | BF | KMP |
|:---|:---|:---|
| 主串回溯 | $i$ 回溯 | $i$ **不回溯** |
| 时间复杂度 | $O(nm)$（最坏） | $O(n+m)$ |
| 额外空间 | $O(1)$ | $O(m)$（next 数组） |
| 适用场景 | 模式串短 | 模式串长 / 字符集小 |

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| BF 算法 | 失配时主串指针 **i 回溯**重试；最好 $O(n)$、最坏 **$O(nm)$**，空间 $O(1)$ |
| 匹配问题定义 | 主串长 $n$、模式串长 $m$（$m\leq n$）；成功返回起始位置，失败返回 0 |
