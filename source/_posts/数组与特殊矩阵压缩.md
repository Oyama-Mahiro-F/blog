**数组（Array）**是线性表的推广：给线性表的元素再附上更多下标约束，就得到多维数组。数组一旦定义，**维数与维界就固定不变**，只做**存取与修改**，不做插入删除；又因采用顺序存储，给定下标即可按公式**一步算出地址**，是典型的**随机存取**结构。408 对本章的考查几乎全是计算题：**多维数组的地址计算（行优先/列优先）**、**特殊矩阵压缩后的下标映射（对称、三角、三对角）**，再辅以**稀疏矩阵三元组与十字链表**的概念辨析。

## 数组的定义与性质

**数组**是由 $n$（$n>1$）个**相同数据类型**的数据元素 $a_1, a_2, \dots, a_n$ 构成的**有限序列**。

| 视角 | 含义 |
|:---|:---|
| 一维数组 | 就是线性表，每个元素是一个值 |
| 二维数组 | "**线性表的线性表**"：每一行是一个线性表，行本身又作为表的元素 |
| $n$ 维数组 | 每个元素受 $n$ 个下标约束，是线性表的逐层推广 |

| 性质 | 说明 |
|:---|:---|
| 元素个数固定 | 定义后**维数、维界不再改变**——无插入、删除，只有存取和修改 |
| 顺序存储 | 存放在**一片连续地址**中 |
| 随机存取 | 任给一组下标，按地址公式 $O(1)$ 直接定位 |

> **考点**：数组是**线性表的推广**，二维数组是"数据元素为线性表"的线性表；数组定义后**不能插入删除**（维界固定），这是它与线性表的本质区别。

## 多维数组的存储与地址计算

### 一维数组的地址计算

每个元素占 $d$ 字节（有的教材记 $L$），下标从 0 开始时：

$$LOC(a_i) = LOC(a_0) + i \times d$$

下标从 1 开始则为 $LOC(a_i) = LOC(a_1) + (i-1) \times d$。一句话：**首地址 +（前面元素个数）× 每元素字节数**。

推广到 $n$ 维数组 $A[b_1][b_2]\dots[b_n]$（行优先、0 基，$b_q$ 为各维长度）：

$$LOC(j_1, \dots, j_n) = LOC(0, \dots, 0) + \Big(\sum_{p=1}^{n} j_p \prod_{q=p+1}^{n} b_q\Big) \times d$$

即**后面的下标先"相乘折算"**：二维时 $\prod$ 退化为 $j_1 \times b_2 + j_2$，正对应 $(i \times n + j)$。

### 行优先与列优先（重点对比）

多维数组必须摊平成一维内存序列，摊平顺序有两种：

- **行优先**：先存满第 0 行，再存第 1 行……按"**前 $i$ 行满（$i \times n$ 个）+ 第 $i$ 行前 $j$ 个**"计数；
- **列优先**：先存满第 0 列，再存第 1 列……按"**前 $j$ 列满（$j \times m$ 个）+ 第 $j$ 列前 $i$ 个**"计数。

| 对比项 | 行优先（Row-major） | 列优先（Column-major） |
|:---|:---|:---|
| 摊平顺序 | 逐行存：$A[0][0], A[0][1], \dots$ | 逐列存：$A[0][0], A[1][0], \dots$ |
| 公式（0 基，$m$ 行 $n$ 列） | $LOC(i,j) = LOC(0,0) + (i \times n + j) \times d$ | $LOC(i,j) = LOC(0,0) + (j \times m + i) \times d$ |
| 公式（1 基，$A[1..m][1..n]$） | $LOC(1,1) + ((i-1) \times n + (j-1)) \times d$ | $LOC(1,1) + ((j-1) \times m + (i-1)) \times d$ |
| 前面元素个数（0 基） | $i \times n + j$ | $j \times m + i$ |
| 采用的语言 | **C/C++/Java/Pascal** | **Fortran/MATLAB** |

```text
A[2][3] 的两种摊平方式（0 基）：
行优先： A[0][0] A[0][1] A[0][2]   A[1][0] A[1][1] A[1][2]
         |–––––– 第 0 行 ––––––|   |–––––– 第 1 行 –––––|
列优先： A[0][0] A[1][0]   A[0][1] A[1][1]   A[0][2] A[1][2]
         |–– 第 0 列 ––|   |–– 第 1 列 ––|   |–– 第 2 列 ––|
```

> **易错点**：**下标从 0 还是 1 开始**是地址计算的第二大失分点——1 基必须把每个下标**先减 1** 再代入；行优先公式的系数是**列数 $n$**，列优先公式的系数是**行数 $m$**，两者代反必错。最稳的思路：先数"该元素**前面有多少个元素**"，再乘 $d$ 加首地址。

### 二维数组地址计算例题（0 起始下标）

**例 1**：数组 $A[0..5][0..7]$（6 行 8 列），$LOC(A[0][0]) = 1000$，每个元素占 4 字节，求 $A[3][5]$ 在行优先、列优先下的地址。

**行优先**（前面有 $i \times n + j$ 个元素，$n = 8$ 为列数）：

$$LOC(A[3][5]) = 1000 + (3 \times 8 + 5) \times 4 = 1000 + 29 \times 4 = \mathbf{1116}$$

**列优先**（前面有 $j \times m + i$ 个元素，$m = 6$ 为行数）：

$$LOC(A[3][5]) = 1000 + (5 \times 6 + 3) \times 4 = 1000 + 33 \times 4 = \mathbf{1132}$$

**验算**：行优先下 $A[3][5]$ 前有 3 个整行（$3 \times 8 = 24$ 个）加 5 个元素，共 29 个 ✓；列优先下有 5 个整列（$5 \times 6 = 30$ 个）加 3 个元素，共 33 个 ✓。

> **考点**：行优先数到"第 $i$ 行之前"、列优先数到"第 $j$ 列之前"——**公式里当乘法系数的，正是"整行/整列"的个数**（行优先乘列数 $n$，列优先乘行数 $m$）。

### 二维数组地址计算例题（1 起始下标）

**例 2**：数组 $A[1..6][1..8]$（仍为 6 行 8 列），$LOC(A[1][1]) = 1000$，每个元素占 4 字节，求 $A[3][5]$ 的地址。

**行优先**：

$$LOC(A[3][5]) = 1000 + \big[(3-1) \times 8 + (5-1)\big] \times 4 = 1000 + 20 \times 4 = \mathbf{1080}$$

**列优先**：

$$LOC(A[3][5]) = 1000 + \big[(5-1) \times 6 + (3-1)\big] \times 4 = 1000 + 26 \times 4 = \mathbf{1104}$$

**验算**：1 基时 $A[3][5]$ 前面有 2 个整行（16 个）+ 4 个 = 20 个元素，$1000 + 20 \times 4 = 1080$ ✓。

> **易错点**：两例虽然都写 $A[3][5]$，但 0 基指**第 4 行第 6 列**、1 基指**第 3 行第 5 列**——**同一写法在不同口径下不是同一个元素**，答案自然不同；审题第一步先看下标从几开始。

## 特殊矩阵的压缩存储

**压缩目的**：对**值相同的多个元素只分配一个存储空间**（如对称矩阵的 $a_{ij}$ 与 $a_{ji}$），对**零元素不分配空间**，把 $n \times n$ 矩阵压进一维数组，同时**仍能用映射公式由下标直接算出存放位置**。

### 各特殊矩阵压缩后元素个数对比

| 矩阵类型 | 压缩存储的范围 | 压缩后元素个数 |
|:---|:---|:---|
| 对称矩阵（存下三角，**含**主对角线） | $i \geq j$ 的元素 | $\frac{n(n+1)}{2}$ |
| 对称矩阵（存**严格**下三角，不含对角线） | $i > j$ 的元素 | $\frac{n(n-1)}{2}$ |
| 下三角矩阵 | $i \geq j$ 的元素 + 末位 1 个常数 $c$ | $\frac{n(n+1)}{2} + 1$ |
| 上三角矩阵 | $i \leq j$ 的元素 + 末位 1 个常数 $c$ | $\frac{n(n+1)}{2} + 1$ |
| 三对角矩阵 | 三条对角线（$\lvert i-j \rvert \leq 1$） | $3n - 2$ |

> **易错点**：对称矩阵**含不含主对角线**是两套口径——含对角线存 $\frac{n(n+1)}{2}$ 个（408 主流口径），不含对角线存 $\frac{n(n-1)}{2}$ 个；三角矩阵另一侧全是同一常数 $c$，还要**末位多存 1 个**。

### 对称矩阵

$A[i][j] = A[j][i]$，只需存**下三角（含主对角线）**共 $\frac{n(n+1)}{2}$ 个元素，按行优先存入一维数组 $B$；$i < j$ 的元素借助对称性映射到 $A[j][i]$ 的位置。**映射公式**（下三角按行存储，$i \geq j$）：

| 口径 | 公式 | 首元素位置 |
|:---|:---|:---|
| $i, j$ 与 $B$ 下标都从 1 计 | $k = \frac{i(i-1)}{2} + j$ | $a_{11} \to B[1]$ |
| $i, j$ 从 1 计、$B$ 下标从 0 计（教材常用式） | $k = \frac{i(i-1)}{2} + j - 1$ | $a_{11} \to B[0]$ |
| $i, j$ 与 $B$ 下标都从 0 计 | $k = \frac{i(i+1)}{2} + j$ | $a_{00} \to B[0]$ |

推导思路统一为"**数前面**"：$a_{ij}$（$i \geq j$）前面有 $i-1$ 个完整的短行，共 $1 + 2 + \dots + (i-1) = \frac{i(i-1)}{2}$ 个，本行内前面还有 $j-1$ 个。

```text
n=4 对称矩阵按下三角压缩进 B（矩阵与数组都从 1 计）：
B[1]  B[2]  B[3]  B[4]  B[5]  B[6]  B[7]  B[8]  B[9]  B[10]
a11   a21   a22   a31   a32   a33   a41   a42   a43   a44
```

第 $i$ 行存 $a_{i1} \dots a_{ii}$，共 $1+2+3+4 = \frac{4 \times 5}{2} = 10$ 个。

> **考点**：$i < j$ 的元素**不是不存**，而是利用 $A[i][j] = A[j][i]$ **交换行列**后代入同一公式（$B$ 从 0 计时 $k = \frac{j(j-1)}{2} + i - 1$）。

**对称矩阵压缩例题**：$n = 10$ 的对称矩阵压缩存下三角（含对角线），共 $\frac{10 \times 11}{2} = 55$ 个元素，求 $a_{74}$ 的下标 $k$（$i = 7 \geq j = 4$，下三角按行存储）。

- **口径一（$B$ 下标从 1 计）**：$k = \frac{7 \times 6}{2} + 4 = 21 + 4 = \mathbf{25}$，即 $a_{74} = B[25]$；
- **口径二（$B$ 下标从 0 计，$k = \frac{i(i-1)}{2} + j - 1$）**：$k = 21 + 4 - 1 = \mathbf{24}$，即 $a_{74} = B[24]$。

**验算**：$a_{74}$ 前面有前 6 个短行 $1 + 2 + \dots + 6 = 21$ 个，再加本行前面的 $a_{71}, a_{72}, a_{73}$ 共 3 个，合计 24 个 → 数组 0 基下标 24、1 基下标 25 ✓。

**同矩阵 $i < j$ 一问**：求 $a_{47}$ 的下标——交换为 $a_{74}$，口径二下 $k = \frac{7 \times 6}{2} + 4 - 1 = 24$，与 $a_{74}$ 落在**同一单元** $B[24]$，这正是"相同元素只存一份"。

**上三角同理一问**：同矩阵改存**上三角**（含对角线、按行），求 $a_{47}$（$i = 4 \leq j = 7$）的下标——前 3 行共 $\frac{(i-1)(2n-i+2)}{2} = \frac{3 \times 18}{2} = 27$ 个，行内再让过 $j - i = 3$ 个，故 0 基 $k = 27 + 3 = \mathbf{30}$（1 基 $k = 31$）。上三角公式为 $k = \frac{(i-1)(2n-i+2)}{2} + (j - i)$；$i > j$ 的元素统一读**末位常数** $c$（0 基下标 $\frac{n(n+1)}{2} = 55$ 处）。下三角矩阵的映射则与对称矩阵下三角完全相同，只是 $i < j$ 时读常数 $c$。

> **易错点**：上三角公式里行内偏移是 $j - i$ 而不是 $j - 1$——上三角第 $i$ 行从**主对角线** $a_{ii}$ 开始，$a_{ii}$ 自身偏移为 0。

### 三对角矩阵（带状矩阵）

非零元素集中在以主对角线为中心的**三条对角线**上，即 $\lvert i-j \rvert \leq 1$，其余全为 0。第 1 行、第 $n$ 行各只有 **2** 个非零元，中间每行 **3** 个，共 $3n - 2$ 个，按行压缩进一维数组。

**映射公式**（矩阵下标从 1 计、数组下标从 0 计）：$a_{ij}$（$\lvert i-j \rvert \leq 1$）前面的元素个数为

$$\underbrace{3(i-1) - 1}_{\text{前 } i-1 \text{ 行}} + \underbrace{(j - i + 1)}_{\text{行内}} = 2i + j - 3$$

即 **$k = 2i + j - 3$**（0 基数组；数组也从 1 计则 $k = 2i + j - 2$）。推导：前面 $i-1$ 行共 $3(i-1) - 1 = 3i - 4$ 个（第 1 行比 3 个少 1），行内从 $a_{i,i-1}$ 存起，$a_{ij}$ 前还有 $j - i + 1$ 个。

```text
n=5 三对角矩阵按行压缩进 B（矩阵 1 计、数组 0 计）：
B[0] B[1]  B[2] B[3] B[4]  B[5] B[6] B[7]  B[8]  B[9] B[10]  B[11] B[12]
a11  a12   a21  a22  a23   a32  a33  a34   a43   a44  a45    a54   a55
```

验证 $a_{45}$：$k = 2 \times 4 + 5 - 3 = 10$，正是 $B[10]$ ✓。

**三对角矩阵例题**：$n = 6$ 的三对角矩阵（矩阵下标从 1 计），求 $a_{34}$ 的下标 $k$。

- 前面行元素数：$3 \times (3-1) - 1 = 5$ 个；
- 行内偏移：第 3 行按 $a_{32}, a_{33}, a_{34}$ 存放，$a_{34}$ 前有 $j - i + 1 = 2$ 个；
- 前面共 $5 + 2 = 7$ 个 → **0 基 $k = 7$**（1 基 $k = 8$）；
- **公式验算**：$k = 2 \times 3 + 4 - 3 = 7$ ✓。

**反求演示**：已知 1 基 $k = 8$，反求 $i, j$。逐行累计元素数：前 1 行 2 个、前 2 行 5 个、前 3 行 8 个——$k = 8$ 恰落在第 3 行行尾 → $i = 3$；行内第 $8 - 5 = 3$ 个元素，即 $j = i - 2 + 3 = 4$ → 该元素为 $a_{34}$ ✓。

> **考点**：总数是 $3n - 2$ 而非 $3n$，因为**首行、尾行各只有 2 个非零元**；反求时用"逐行累计刚好覆盖 $k$"定行号，再由行内序号定列号。

## 稀疏矩阵

**稀疏矩阵**：非零元素个数**远远少于**元素总数（通常占比**不足 5%**）的矩阵。零元素多到不值得存放，且其分布**没有规律**，无法套公式定位，只能"见一个存一个"。

### 三元组表示

每个非零元记为三元组 **$(行号, 列号, 值)$**，全部三元组**按行序（同行按列序）**存成线性表，另附三个总体信息：行数 $mu$、列数 $nu$、非零元个数 $tu$。

```text
设 3×4 矩阵仅 3 个非零元：a[1][2]=5, a[2][3]=-2, a[3][1]=8

三元组表（按行序）：(1, 2, 5)  (2, 3, -2)  (3, 1, 8)
```

**转置思想**：**按列序转置**——对原三元组表按列号从小到大逐列扫描，每扫到一列就把该列元素依次写入新表，即得按行序排列的转置三元组表；直接转置要扫描 $nu$ 趟，时间 $O(nu \times tu)$；**快速转置**先统计每列非零元个数、一次性定位填入，时间 $O(nu + tu)$。

> **易错点**：三元组表只是"非零元的清单"，给定 $(i, j)$ **必须查找才能定位**——稀疏矩阵压缩后**失去了随机存取特性**。

### 十字链表

每个非零元占一个**结点**，含五个域：$(i, j, e, right, down)$，同一结点**同时挂在所在行的行链表**（`right` 指针串联）**和所在列的列链表**（`down` 指针串联）上，另设**行表头数组与列表头数组**指向各行、列的首结点——一个结点被行、列两条链**共享**。

| 结点域 | 含义 |
|:---|:---|
| `i, j, e` | 行号、列号、元素值 |
| `right` | 指向**同一行**中的下一个非零元结点 |
| `down` | 指向**同一列**中的下一个非零元结点 |

> **考点**：十字链表适合**非零元结构频繁变化的运算**（矩阵加法、乘法等）——运算中非零元会增减，三元组表需整体移动元素，十字链表只需局部修改几条指针。

## 压缩存储后还是随机存取吗

| 存储结构 | 能否 $O(1)$ 定位 | 依据 |
|:---|:---|:---|
| 普通一维/二维数组 | **能** | 地址公式直接计算 |
| 对称/三角/三对角矩阵压缩 | **能** | 元素分布**有规律**，映射公式由下标一步算出 $k$ |
| 稀疏矩阵三元组表 | **不能** | 须按行号/列号**查找或扫描**三元组表 |
| 稀疏矩阵十字链表 | **不能** | 须沿行、列指针**遍历** |

> **考点**：辨析口径——**特殊矩阵压缩后仍是随机存取**（任给下标可由映射公式直接定位），**稀疏矩阵压缩后不是**（三元组、十字链表都要查找/遍历）。

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 数组定义 | $n$ 个**同类型**元素的有限序列，**线性表的推广**；维数维界固定，只存取/修改、不插删 |
| 一维寻址 | $LOC(a_i) = LOC(a_0) + i \times d$（0 基）；1 基改为 $(i-1) \times d$ |
| 二维行优先 | $LOC = LOC(0,0) + (i \times n + j) \times d$，前面共 $i \times n + j$ 个元素 |
| 二维列优先 | $LOC = LOC(0,0) + (j \times m + i) \times d$，系数换成**行数** $m$ |
| 0/1 起始 | 1 基先把各下标减 1；万能思路：**首地址 + 前面元素个数 × $d$** |
| 语言对应 | 行优先：**C/C++/Java/Pascal**；列优先：**Fortran/MATLAB** |
| 对称矩阵 | 存下三角含对角线 $\frac{n(n+1)}{2}$ 个；$i \geq j$ 时 $k = \frac{i(i-1)}{2} + j - 1$（0 基数组） |
| $i<j$ 的元素 | 交换行列存 $a_{ji}$：$k = \frac{j(j-1)}{2} + i - 1$，与 $a_{ij}$ 同一单元 |
| 三角矩阵 | $\frac{n(n+1)}{2}$ 个 + **末位常数 $c$**；上三角 $k = \frac{(i-1)(2n-i+2)}{2} + (j-i)$ |
| 三对角矩阵 | $\lvert i-j \rvert \leq 1$，共 **$3n - 2$** 个；1 基 $k = 2i + j - 2$（0 基 $2i+j-3$） |
| 稀疏矩阵 | 非零元**不足 5%**；三元组 $(i, j, v)$ **按行序**排列，**失去随机存取** |
| 转置 | 按列序转置 $O(nu \times tu)$；**快速转置**（按列计数定位）$O(nu + tu)$ |
| 十字链表 | 结点 $(i, j, e, right, down)$ 同挂**行、列两条链**，共享结点，适合**矩阵加减** |
| 随机存取辨析 | 特殊矩阵压缩后**公式可定位 = 仍随机存取**；稀疏矩阵压缩后**不是** |
