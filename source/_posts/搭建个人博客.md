## 前言

本博客使用 [Hexo](https://hexo.io/) 搭建，选用 Material Design 风格的 [hexo-theme-indigo](https://github.com/yscoder/hexo-theme-indigo) 主题。

## 环境准备

- **Node.js**：Hexo 基于 Node.js，需提前安装
- **Git**：用于版本管理和部署到 GitHub Pages

## 快速开始

```bash
# 安装 Hexo CLI
npm install -g hexo-cli

# 初始化博客
hexo init my-blog
cd my-blog

# 安装依赖
npm install

# 启动本地服务器
hexo server
```

浏览器访问 `http://localhost:5000` 即可预览。

## 配置主题

将主题文件夹放入 `themes/` 目录，修改 `_config.yml`：

```yaml
theme: indigo
```

## 写作

```bash
# 创建新文章
hexo new "我的第一篇文章"
```

文章使用 Markdown 编写，支持 LaTeX 数学公式（KaTeX 服务端渲染）。

## 部署

```bash
# 生成静态文件
hexo generate

# 部署到 GitHub Pages
hexo deploy
```
