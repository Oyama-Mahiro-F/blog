单链表插入/删除的核心都是"**寻找前驱**"。已知位置时插入/删除仅需改指针，$O(1)$；按位操作需先遍历找前驱，$O(n)$。

## 按位插入（在第 i 个位置插入元素 e）

**黄金法则**：先连后面大部队，再让前驱牵自己——指针赋值顺序绝对不能反！

![单链表插入节点](/blog/images/第2章 线性表.assets/Pointer Relationship-2026-06-10-121132.png)

```c++
bool ListInsert(LinkList L, int i, ElemType e) {
    if (i < 1) return false; // 位置不合法

    LNode *p = L; // p 指向头结点
    int j = 0;    // 当前 p 指向的是第几个节点

    // 1. 寻找第 i-1 个节点（前驱节点）
    while (p != NULL && j < i - 1) {
        p = p->next;
        j++;
    }

    if (p == NULL) return false; // i 值超过了链表长度

    // 2. 创建新节点 s
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;

    // 3 & 4. 核心钩链操作
    s->next = p->next; // 步骤一：新节点连上后面的大部队
    p->next = s;       // 步骤二：前驱节点连上新节点

    return true;
}
```

> 如果先执行 `p->next = s;`，那么 p 原本后面的节点地址就彻底丢失了——内存泄漏 + 链表断裂！

## 按序号删除（删除第 i 个节点）

删除解剖三步曲：**长途跋涉找前驱 → 派驻哨兵防泄漏 → 逻辑跨越与物理超度**。

![单链表删除节点](/blog/images/第2章 线性表.assets/Pointer Relationship-2026-06-10-121132-17810938573874.png)

```c++
bool ListDelete_Index(LinkList L, int i, ElemType *e) {
    int j = 0;
    LNode *p = L; // p 初始指向头结点（序号0）
    LNode *q;     // 用于锁定目标的辅助指针

    // 1. 寻找第 i-1 个节点（前驱）
    while (p != NULL && j < i - 1) {
        p = p->next;
        j++;
    }

    // 2. 极其严格的边界防雷检查
    // p == NULL：i 远远超过了链表的长度
    // p->next == NULL：第 i-1 个节点后面没有第 i 个节点可删
    // j > i - 1：拦截 i = 0 或负数不合法序号
    if (p == NULL || p->next == NULL || j > i - 1) {
        return false; // 删除失败，位置不合法
    }

    // 3. 执行安全的删除手术
    q = p->next;        // 步骤一：哨兵 q 锁定第 i 个节点
    p->next = q->next;  // 步骤二：前驱 p 绕过 q，连向第 i+1 个节点
    *e = q->data;       // 步骤三：提取被删节点的数据交给 e
    free(q);            // 步骤四：物理释放内存

    return true; // 删除成功
}
```

## 按值删除：删除第一个值为 key 的节点

**短路求值拦截崩溃**：`while (q != NULL && q->data != key)` 中，若链表中没有 key，q 最终变成 NULL，短路求值会直接跳出循环；顺序写反会因访问 `NULL->data` 崩溃！

```c++
bool DeleteFirstKey(LinkList L, ElemType key) {
    LNode *p = L;           // p 充当前驱指针，初始指向头结点
    LNode *q = L->next;     // q 充当探路指针，初始指向第一个有效节点

    // 1. 探路员 q 在前搜索，前驱 p 在后紧跟
    // 安全铁律：必须先判断 q != NULL，再判断 q->data != key
    while (q != NULL && q->data != key) {
        p = q;              // p 挪到当前 q 的位置，成为新的前驱
        q = q->next;        // q 迈步走向下一个节点
    }

    // 2. 循环跳出后的边界检查
    if (q == NULL) {
        return false;       // 查到了链表尽头也没找到 key
    }

    // 3. 找到了！此时 q 停在第一个 key 节点上，p 稳站其前驱
    p->next = q->next;      // 核心断链：前驱 p 越过 q
    free(q);                // 物理销毁

    return true;            // 删除成功
}
```

## 按值删除：删除所有值为 key 的节点

**核心灵魂**：删除发生时 `p` 绝对不能动！删除一个 key 后，`q` 接手 `p->next` 继续探测，防止连续相同 key 漏网。

```c++
void DeleteAllKeyNodes(LinkList L, ElemType key) {
    LNode *p = L;           // p 充当前驱指针，初始指向头结点
    LNode *q = L->next;     // q 充当工作指针，用来遍历检查每个节点

    while (q != NULL) {
        if (q->data == key) {
            // 【情况 A：命中目标，执行切除】
            p->next = q->next; // 前驱 p 越过 q
            free(q);           // 物理释放
            q = p->next;       // 核心灵魂！q 重新指向新的后继，但 p 保持原地不动！
        }
        else {
            // 【情况 B：未命中目标，双指针安全同步后移】
            p = q;             // p 挪到当前 q 的位置
            q = q->next;       // q 迈步走向下一个节点
        }
    }
}
```

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 单链表插入 | **先连后面大部队，再让前驱牵自己**（防断链） |
| 单链表删除 | 派哨兵 `q` **锁定目标** → 绕过 → `free(q)` |
| 删除所有 key | 删除后 **p 原地不动**，只让 q 接手 p->next 继续探路 |
| 已知位置的插入/删除 | 仅改指针，$O(1)$；按位操作需找前驱，$O(n)$ |
