**存储系统**是计算机组成原理的核心章节之一。理想存储器要**容量大、速度快、价格低**，但三者不可兼得，于是催生了**层次化存储结构**；不同介质、不同存取方式的存储器又形成了**分类辨析**考点。408 对本章的考查集中在：**存储器分类、层次结构、SRAM 与 DRAM、ROM 与 Flash、主存与 CPU 的连接（容量扩展）、双端口与多模块存储器**。

## 存储器的分类

### 按存储介质分类

| 类型 | 存储介质 | 特点 | 典型代表 |
|:---|:---|:---|:---|
| **半导体存储器** | 半导体电路（触发器/电容） | 体积小、速度快、功耗低 | 主存（DRAM）、Cache（SRAM） |
| **磁表面存储器** | 磁性材料涂层 | 非易失、容量大、速度慢 | 硬盘（HDD）、磁带 |
| **光存储器** | 光学介质 | 非易失、可移动 | CD、DVD、光盘 |

### 按存取方式分类（重点辨析）

| 类型 | 存取原理 | 存取时间与位置的关系 | 典型代表 |
|:---|:---|:---|:---|
| **随机存取（RAM）** | 按地址直接访问任意单元 | **与物理位置无关**，每个单元存取时间相同 | SRAM、DRAM、主存、Cache |
| **顺序存取（SAM）** | 从头按顺序查找 | **与位置有关**，越靠后越慢 | **磁带** |
| **直接存取（DAM）** | 先**直接定位**到一个区域，再在区域内**顺序搜索** | 介于两者之间（先寻道、再等待旋转） | **磁盘**、光盘 |
| **相联存取（CAM）** | 按**内容**并行比较检索，而非按地址 | 与位置无关，速度极快 | Cache 的行标记、TLB |

> **考点**：**磁盘是直接存取，不是随机存取**——必须先移动磁臂定位磁道（直接定位），再等待目标扇区旋转到磁头下方（顺序搜索）；磁带才是顺序存取。
> **易错点**：**ROM 也是随机存取方式**（按地址访问、存取时间与位置无关），"只读"说的是**内容可变性**，不要把 ROM 归为顺序存取。

### 按内容可变性与信息可保存性分类

| 分类维度 | 类别 | 含义 | 典型代表 |
|:---|:---|:---|:---|
| **内容可变性** | 读写存储器 | 正常工作时可读**可写** | RAM |
| **内容可变性** | 只读存储器 | 正常工作时**只能读**，断电不丢 | ROM（BIOS、固件） |
| **信息可保存性** | 易失性存储器 | **断电后信息丢失** | SRAM、DRAM（主存） |
| **信息可保存性** | 非易失性存储器 | 断电后信息**长期保存** | ROM、Flash、磁盘、磁带 |

**存储器分类维度速查**：

| 分类依据 | 类别 |
|:---|:---|
| 按存储介质 | 半导体 / 磁表面 / 光存储器 |
| 按存取方式 | 随机存取 / 顺序存取 / 直接存取 / 相联存取 |
| 按内容可变性 | 读写（RAM）/ 只读（ROM） |
| 按信息可保存性 | 易失性 / 非易失性 |
| 按在计算机中的作用 | 高速缓存（Cache）/ 主存 / 辅存 |

## 存储器的层次化结构

```text
            speed faster / capacity smaller / price higher
                        +----------------+
                        |   register     |
                        +----------------+
                        |  Cache (SRAM)  |
                        +----------------+
                        |  main mem DRAM |
                        +----------------+
                        | disk / SSD     |
                        +----------------+
                        | tape / archive |
                        +----------------+
            speed slower / capacity larger / price lower
```

| 层次 | 存储器 | 速度（数量级） | 容量（数量级） | 位价 |
|:---|:---|:---|:---|:---|
| L0 | 寄存器 | 与 CPU 同级（亚 ns） | 几十&#126;几百 B | 最高 |
| L1 | **Cache（SRAM）** | **1&#126;10 ns** | 几十 KB&#126;几 MB | 很高 |
| L2 | **主存（DRAM）** | **50&#126;100 ns** | 几 GB&#126;几十 GB | 中 |
| L3 | **辅存（磁盘/SSD）** | **ms 级**（HDD） | 几百 GB&#126;几 TB | 低 |

### 两级存储层次解决的两个矛盾

| 存储层次 | 解决的矛盾 | 速度差 | 管理者 | 数据交换单位 |
|:---|:---|:---|:---|:---|
| **Cache — 主存** | CPU 与主存的**速度**矛盾 | 约 10 倍 | **硬件**自动完成，对所有程序员透明 | 块 |
| **主存 — 辅存** | 存储系统的**容量**矛盾 | 约 10 万倍 | **操作系统 + 硬件**（发展出虚拟存储器） | 页 |

- 层次结构能够成立的依据是程序访问的**局部性原理**：**时间局部性**（刚访问过的项不久后再次被访问）与**空间局部性**（被访问项附近的项紧接着被访问）——高频数据自然集中在上层。
- 整个体系呈**金字塔**：越往上**越快、越小、越贵**；目标是用低成本获得接近上层速度、接近下层容量的**整体性能**。
- 主存的主要技术指标：**存取周期 $T_m$ > 存取时间 $T_a$**（存取后有恢复/预充电）；**主存带宽 $B_m = \dfrac{W}{T_m}$**（$W$ 为存储字长），即**每秒可访问的位数**。

> **考点**：**Cache-主存层次解决速度，主存-辅存层次解决容量**；两者的理论基础都是局部性原理。Cache 与虚拟存储器的细节另文展开。

## 半导体随机存取存储器

### SRAM（静态随机存取存储器）

**SRAM 的存储元是一个双稳态**触发器**（6 管 MOS 电路）**，只要不断电，0/1 状态就稳定保持，因此叫"静态"。

| 特性 | 说明 |
|:---|:---|
| 存储元 | **6 管（6T）触发器**（锁存器） |
| 刷新 | **不需要**刷新 |
| 读出 | **非破坏性读出**（触发器状态不变，无需重写） |
| 地址送入 | 地址**一次送入**（行、列地址不分先后） |
| 速度 | **快**（ns 级） |
| 集成度/功耗/位价 | 集成度**低**、功耗**大**、位价**高** |
| 用途 | **Cache** |

SRAM 芯片引脚分三组：**地址线**（位数决定存储单元数，如 10 根 $\Rightarrow 2^{10}=1\text{K}$ 个单元）、**数据线**（位数决定存储字长）、**控制线**（**片选 $\overline{CS}$、读写控制 $\overline{WE}$**）。

### DRAM（动态随机存取存储器）

**DRAM 靠电容存储电荷记忆信息**，存储元为 **1 个 MOS 管 + 1 个电容（1T1C）**：有电荷为 1、无电荷为 0。

- **破坏性读出**：读出时电容电荷流向位线而流失，读后必须紧跟**再生（重写）**恢复原值。
- **必须定时刷新**：电容会漏电，电荷一般只能维持 **2 ms**，必须在最大刷新间隔内对**所有行**刷一遍。
- **刷新按行进行**：刷新本质是"只读不输出的假读"——每次选中**一整行**，行上所有单元经读出放大器同时读出并写回，**不需要列地址**；刷新一行耗时 ≈ 一个存取周期。
- **刷新与再生不同**：**再生**是被动的、随机的，只在**破坏性读出后**针对被读单元重写；**刷新**是主动的、定时的，不管单元是否被访问，到点就对整行补充电荷。

### DRAM 的地址分时复用

DRAM 芯片把地址**分两次送入**：先送**行地址**（**$\overline{RAS}$ 行地址选通**下降沿锁存），再送**列地址**（**$\overline{CAS}$ 列地址选通**下降沿锁存），行、列地址**共用同一组地址引脚**，使芯片引脚数**几乎减半**（1K 个单元只需 5 根地址线而非 10 根）。

### DRAM 的三种刷新方式

| 刷新方式 | 做法 | 死区 | 特点 |
|:---|:---|:---|:---|
| **集中刷新** | 在一段时间内集中、连续逐行刷完全部行 | **有**（死区 = 行数 × 存取周期），期间 CPU 不能访存 | 控制简单，死区时间长 |
| **分散刷新** | 把刷新插入到**每个存取周期之后**（读写一次 + 刷新一行） | **无** | 存取周期被拉长为"读写 + 刷新"，**系统速度减半** |
| **异步刷新** | 在最大刷新间隔内**每隔 刷新间隔÷行数 刷一行** | 极小（每次仅刷一行，阻塞一个存取周期） | 折中方案，**现代 DRAM 主流** |

**DRAM 刷新例题**：某 DRAM 芯片存储阵列共 **128 行**，电容电荷最大保持时间（须刷完一遍的间隔）为 **1 ms**，存取周期 **0.5 μs**，分析三种刷新方式。

- **集中刷新**：死区 = $128 \times 0.5\,\mu s = 64\,\mu s$；死时间率 = $\dfrac{64}{1000} \times 100\% = 6.4\%$（1 ms 内 CPU 有 64 μs 完全不能访存）。
- **分散刷新**：每个存取周期变为 $0.5\,\mu s + 0.5\,\mu s = 1\,\mu s$（读写一个周期 + 刷新一行一个周期），无死区，但访存速度**降低一半**。
- **异步刷新**：每隔 $\dfrac{1\,ms}{128} \approx 7.8\,\mu s$ 刷新一行；**验算**：$1\,ms \div 7.8\,\mu s \approx 128$ 行 ✓，每行都在 1 ms 内被刷新到，死区仅 0.5 μs。

> **考点**：刷新的单位是**行**（不需要列地址）；三种方式中**分散刷新无死区但周期最长、集中刷新死区最长、异步刷新死区极小**。
> **易错点**：刷新对 CPU 是**透明的**（由存储器控制电路完成，不是操作系统的事）；刷新期间仍占用存储器，集中刷新才有明显"死区"。

### SRAM 与 DRAM 的对比（必备）

| 对比项 | SRAM | DRAM |
|:---|:---|:---|
| 存储元 | **6T 触发器**（锁存器） | **1T1C 电容**（存电荷） |
| 刷新 | **不需要** | **必须**（2 ms 内按行刷完） |
| 破坏性读出 | **否** | **是**（读后需再生重写） |
| 地址送入 | 一次送入 | **分时复用**（$\overline{RAS}$ 行、$\overline{CAS}$ 列两次送） |
| 运行速度 | **快** | 较慢 |
| 集成度 | 低 | **高** |
| 功耗 | 大 | 小 |
| 位价（成本） | **高** | **低** |
| 主要用途 | **Cache** | **主存** |

> **考点**：记住三条主线——**结构（触发器 vs 电容）决定是否刷新、是否破坏性读出；引脚（是否分时复用）；用途（Cache vs 主存）**。

### 只读存储器（ROM）

ROM 正常工作时**只能读出**，结构简单、**非易失**，常存放 BIOS、固件等固定程序。按擦写能力演进：

| 类型 | 全称 | 写入（编程）方式 | 擦除方式 |
|:---|:---|:---|:---|
| **MROM** | 掩膜式 ROM | **出厂时掩膜工艺固化** | **不可改写** |
| **PROM** | 一次性可编程 ROM | 用户**一次性**编程（烧断熔丝） | **不可擦除** |
| **EPROM** | 可擦除可编程 ROM | 用户可多次编程 | **紫外线**照射擦除（整片擦除，需取出开窗照射） |
| **EEPROM** | 电可擦除可编程 ROM | 用户可多次编程 | **电擦除**，可按字节在线擦写 |
| **Flash** | 闪存 | 电写入 | 电擦除，**按块擦除**（EEPROM 的改进型） |

> **考点**：演进主线 **MROM → PROM（一次） → EPROM（紫外线擦） → EEPROM（电擦） → Flash（按块擦）**，擦除越来越方便、粒度越来越大。
> **易错点**：PROM 烧断熔丝是**物理破坏**，不可恢复；EPROM 擦除须**整片**进行，且要从设备上取下。

### Flash 闪存

**Flash 是 EEPROM 的改进型**，按**块（Block）**擦除、按**页/字节**读写，密度高、成本低，兼具 RAM 的电可改写与 ROM 的非易失性。

| 类型 | 读取方式 | 特点 | 典型应用 |
|:---|:---|:---|:---|
| **NOR Flash** | 支持**随机按字节读取**，可**就地执行（XIP）** | 读快写慢、容量小 | BIOS/UEFI 固件、嵌入式代码 |
| **NAND Flash** | **按页读写、按块擦除** | 密度高、成本低、容量大 | U 盘、存储卡、**SSD** |

- **SSD（固态硬盘）**一句话：SSD = **NAND Flash 阵列 + 主控芯片**的存储设备，**写前必须先擦除**（先整块擦、再按页写），靠磨损均衡延长寿命——细节属辅存章节。
- Flash 写入以**电荷打入浮栅**方式保存信息，因此擦写次数有限（有寿命）。

> **考点**：**NOR 可 XIP（CPU 直接取指执行）、NAND 高密度做大容量**；Flash 断电不丢信息，既非 RAM 也非严格意义的 ROM。

## 主存储器与 CPU 的连接

主存通过**地址总线、数据总线、控制总线**与 CPU 相连：

![主存与 CPU 的连接](/blog/images/计组第3章 存储器层次结构.assets/cpu-mainmem-connection.png)

| 总线 | 方向 | 作用 | 位数由谁决定 |
|:---|:---|:---|:---|
| **地址总线** | CPU → 主存（**单向**） | 传送访存地址 | **MAR 位数** → 决定**最大寻址范围** |
| **数据总线** | CPU ↔ 主存（**双向**） | 传送读出/写入数据 | **MDR 位数** → 决定**存储字长**（一次传送位数） |
| **控制总线** | CPU → 主存 | 传送读/写命令等控制信号 | 读、写、片选线 |

芯片级连接要点：芯片的**地址线**接总线低位地址选片内单元，**数据线**接数据总线，**片选 $\overline{CS}$** 决定本芯片是否工作，**读写 $\overline{WE}$** 控制读/写方向。单芯片容量不够时需要**容量扩展**。

### 位扩展（加大字长）

**位扩展**：芯片**字数够、位数不够**时，多片**并联**拼位数——**地址线、片选、读写全部并联**（各片同时被选中、同时工作），**只有数据线分开**各接总线的一段。

![位扩展连接](/blog/images/计组第3章 存储器层次结构.assets/bit-expansion.png)

> 图：两片 1K×4 位芯片位扩展为 1K×8 位——地址 A0&#126;A9、$\overline{CS}$、$\overline{WE}$ 并联，数据 D0&#126;D3 与 D4&#126;D7 分别接总线。

### 字扩展（加大字数）

**字扩展**：芯片**位数够、字数不够**时，多组芯片**串联**扩容量——**低位地址线、数据线、读写线全部并联**，**高位地址经译码器产生片选**，任一时刻**只有一片（组）被选中**输出，其余芯片处于高阻态。

| 片选方案 | 做法 | 特点 |
|:---|:---|:---|
| **线选法** | 每根高位地址线**直接**接一组芯片的 $\overline{CS}$ | 简单、无需译码器，但地址空间**不连续**、浪费 |
| **译码片选法** | 高位地址接**译码器**（如 2:4、3:8），输出接各组 $\overline{CS}$ | n 条地址线译出 $2^n$ 个片选，地址**连续唯一**，**常用** |

### 字位同时扩展

**字位同时扩展**：字数、位数都不够时，**先位扩展拼出所需位宽，再字扩展拼出所需容量**。

**芯片数通用公式**：设目标存储器为 $M \times N$ 位，芯片为 $L \times K$ 位，则所需芯片数

$$d = \frac{M \times N}{L \times K} = \frac{M}{L} \times \frac{N}{K}$$

其中 $\dfrac{N}{K}$ 是**每组片数**（位扩展），$\dfrac{M}{L}$ 是**组数**（字扩展）。$K=N$ 时退化为纯字扩展，$L=M$ 时退化为纯位扩展。

### 存储器扩展例题（核心）

**题目**：用 **1K×4 位**的 SRAM 芯片组成 **4K×8 位**存储器，求所需芯片数、每组片数、组数、地址线/数据线数量，并说明 2:4 译码器的片选连接。

**逐项求解**：

- **所需芯片数**：$d = \dfrac{4K \times 8}{1K \times 4} = 8$ 片。
- **位扩展**：每组片数 = $\dfrac{8}{4} = 2$ 片——两片并联拼出 8 位字长，芯片 1 数据线 $D_0&#126;D_3$ 接总线 $D_0&#126;D_3$，芯片 2 接 $D_4&#126;D_7$。
- **字扩展**：组数 = $\dfrac{4K}{1K} = 4$ 组。
- **地址线**：目标 $4K = 2^{12}$ 个单元 → 系统**地址线 12 根** $A_{11}&#126;A_0$；每片 $1K = 2^{10}$ → **片内地址 10 根** $A_9&#126;A_0$（各组并联）。
- **数据线**：存储字长 8 位 → **数据总线 8 根** $D_7&#126;D_0$。
- **片选**：高位地址 $A_{11}A_{10}$（2 位）接 **2:4 译码器**输入，4 个输出 $\overline{Y_0}&#126;\overline{Y_3}$（低电平有效）分别接第 0&#126;3 组的 $\overline{CS}$。

```text
                    +--------------+
   A11 A10 -------> |  2:4 decoder |
                    |  in:  A11A10 |
                    |  Y0  Y1  Y2  Y3   (active low)
                    +--|---|---|---+
                       |   |   |   +--- CS of group 3
                       |   |   +------- CS of group 2
                       |   +----------- CS of group 1
                       +--------------- CS of group 0

   group 0 (addr 0000H - 03FFH):
   +---------------+   +---------------+
   | chip 1  1Kx4  |   | chip 2  1Kx4  |
   | A0-A9         |   | A0-A9         |    A9..A0  <- common low addr bus
   | D0-D3         |   | D4-D7         |    each chip connects its own data bits
   | CS | WE       |   | CS | WE       |    CS and WE wired in parallel
   +---------------+   +---------------+

   group 1..3: same wiring, only CS differs (Y1 / Y2 / Y3)
```

**地址分配**：

| 组号 | $A_{11}A_{10}$ | 片选 | 地址范围 |
|:---|:---|:---|:---|
| 组 0 | 00 | $\overline{Y_0}$ | 0000H&#126;03FFH |
| 组 1 | 01 | $\overline{Y_1}$ | 0400H&#126;07FFH |
| 组 2 | 10 | $\overline{Y_2}$ | 0800H&#126;0BFFH |
| 组 3 | 11 | $\overline{Y_3}$ | 0C00H&#126;0FFFH |

**验算**：总容量 = $8 \text{ 片} \times 1K \times 4 \text{ 位} = 32K$ 位 $= 4K \times 8$ 位 ✓；地址空间 $2^{12} = 4K$ 个单元，每组占 1K ✓；任一地址只有一组 $\overline{Y_i}$ 有效，仅该组 2 片工作 ✓。

> **考点**：**位扩展"并联地址、拆分数据"，字扩展"并联数据、译码选片"**；芯片数公式 $d=\dfrac{M}{L}\times\dfrac{N}{K}$。
> **易错点**：系统地址线数由**目标容量**决定（12 根），不是芯片地址线数（10 根）；译码器输入接的是**高位地址** $A_{11}A_{10}$；若改用线选法，2 根高位线只能区分 2 组（00/11 或 10/01 组合受限），4 组必须用 2:4 译码。

## 双端口存储器与多模块存储器

为提高主存速度，除缩短存取周期外，还可**并行**：同一存储器提供多个访问端口，或拆成多个存储体交叉工作。

### 双端口存储器

双端口存储器是**同一个存储体配两套独立的端口**（各自的地址线、数据线、控制线），两个端口可**同时**访问**不同**存储单元，实现并行访问（典型应用：CPU 与 DMA、双 CPU 共享内存）。

- 两端口访问**不同单元**：并行工作，互不影响。
- 两端口访问**同一单元**且**同时写**（或一读一写）：发生**访问冲突**，由片内**$\overline{BUSY}$ 忙标志逻辑仲裁**——被判为"忙"的一方延迟访问，写冲突时写入值以仲裁结果为准。

> **考点**：双口 RAM 解决的是"**速度**"（并行访问同一存储体），冲突靠 **BUSY 标志仲裁**，这不是两个独立存储器。

### 多体并行存储器

把主存拆成 $m$ 个独立的**存储体（bank）**，各体有自己的地址寄存器与读写电路，按"体号放在地址的哪一端"分为两种编址方式。

### 高位交叉编址（顺序编址）

- **体号在高地址位**、体内地址在低位，地址在**同一存储体内连续**增长：先编满 M0，再编 M1，以此类推。
- **优点**：便于**扩大容量**——需要扩容时**加一个存储体**即可（体号位扩展）；各体可独立服务**不同任务**（如一个体执行程序、一个体进行 DMA）。
- **缺点**：程序**顺序访问**时地址连续、都落在同一体内，**不能流水并行**，对带宽无帮助——连续读 4 个字耗时 $4T$。

### 低位交叉编址（交叉编址）

- **体号在低地址位**、体内地址在高位：**连续地址依次分布在不同存储体中**（模 $m$ 交叉），如 4 体交叉时 0000H 在 M0、0001H 在 M1、0002H 在 M2、0003H 在 M3、0004H 又回 M0。
- **原理**：对第 $i$ 体启动一次存取后，不必等它结束（只需等**总线传送周期** $r$），就可启动第 $i+1$ 体——各体**流水线式**轮流工作，宏观上**每个 $r$ 交出一个字**，**大幅提高主存带宽**。

![多体并行存储器](/blog/images/计组第3章 存储器层次结构.assets/multi-bank-interleave.png)

- 设存取周期为 $T$、总线传送周期为 $r$，交叉体数为 $m$，取 $r = \dfrac{T}{m}$。**流水线不间断的条件是 $m \geq \dfrac{T}{r}$**——体数太少时，下一轮启动会撞上前一体尚未结束的存取周期，流水线出现断流。

> **考点**：**高位交叉"体号在高位、利于扩容、不利提速"；低位交叉"体号在低位、连续地址跨体、流水提带宽"**；交叉存储器又称**模 $m$ 编址存储器**。

### 低位交叉流水线例题（必考）

**题目**：某机主存采用 **4 体低位交叉**编址，存取周期 $T = 200\,ns$，总线传送周期 $r = \dfrac{T}{m} = 50\,ns$，每个字 32 位。求：连续读取 4 个字、连续读取 12 个字的耗时；若 12 个字都在**同一存储体**中，耗时又是多少？

**求解**：

- **校验条件**：$m = 4$，$\dfrac{T}{r} = \dfrac{200}{50} = 4$，$m \geq \dfrac{T}{r}$ 成立 ✓，流水线可不间断。
- **连续读 $m=4$ 个字**：首字经一个完整存取周期 $T$ 读出，之后每隔 $r$ 交出一个字：

$$t = T + (m-1)r = 200 + (4-1) \times 50 = 350\,ns$$

- **连续读 $n=12$ 个字**（跨 4 体流水）：

$$t = T + (n-1)r = 200 + 11 \times 50 = 750\,ns$$

- **退化情形**：12 个字都在同一存储体 → 同一体存取周期未结束前**不能再次启动**，必须逐个等 $T$：

$$t = nT = 12 \times 200 = 2400\,ns$$

- **对比高位交叉**：连续 4 字落在同一体内，耗时 $4T = 800\,ns$，是低位交叉 350 ns 的约 $2.3$ 倍。
- **带宽对比**：读 4 字共 $4 \times 32 = 128$ 位，低位交叉 $B = \dfrac{128\,bit}{350\,ns} \approx 3.7 \times 10^{8}\,bit/s$；顺序访问 $\dfrac{128\,bit}{800\,ns} = 1.6 \times 10^{8}\,bit/s$，**带宽提高约 2.3 倍**；连续字数 $n$ 越大越接近理想值 $m$ 倍。

> **考点**：**连续读 $n$ 个字（$m$ 体低位交叉）$t = T + (n-1)r$；同一存储体退化 $t = nT$**；流水线条件 $m \geq \dfrac{T}{r}$。
> **易错点**：首字仍需完整 $T$，不能按 $nT$ 直接乘；求"访问程序/数组"类题目先看**地址是否连续且跨体**，若访问不连续或集中在同一体，流水线优势消失。

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 分类维度 | 按介质（半导体/磁/光）、按存取方式、按内容可变性（读写/只读）、按可保存性（易失/非易失） |
| 随机 vs 顺序 vs 直接 | 随机=与位置无关（主存，**ROM 也算随机存取**）；顺序=磁带；直接=先定位道再顺序搜索（**磁盘**）；相联=按内容（Cache 标记） |
| 层次结构 | **Cache-主存解决速度，主存-辅存解决容量**；依据=**局部性原理**；越往上越**快、小、贵** |
| SRAM vs DRAM | **触发器 vs 电容**；**免刷新 vs 必刷新**；**非破坏 vs 破坏性读出**；快/贵/Cache vs 慢/便宜/主存 |
| DRAM 刷新 | **按行刷新**（不需列地址）；电容约 2 ms 漏完；刷新一行 ≈ 一个存取周期 |
| 三种刷新方式 | **集中**有死区（行数×存取周期）；**分散**无死区但周期加倍；**异步**折中（2 ms÷行数 刷一行），现代主流 |
| DRAM 地址复用 | **RAS 锁行、CAS 锁列**，行列地址分两次送，引脚减半 |
| ROM 家族 | MROM（掩膜）→PROM（熔丝一次）→EPROM（**紫外线**擦）→EEPROM（**电擦**）→Flash（**按块擦**） |
| Flash | **NOR 可 XIP、随机按字节读**；**NAND 按页读写按块擦、密度高**；SSD=NAND 阵列+主控，写前先擦除 |
| CPU-主存三总线 | 地址线单向（MAR 定**寻址范围**）、数据线双向（MDR 定**字长**）、控制线传读写命令 |
| 容量扩展 | **位扩展**并联地址拆分数据；**字扩展**并联数据、高位译码选片；**先位后字**；线选法地址不连续，**译码片选法**（n 条线选 $2^n$ 组）常用 |
| 芯片数公式 | $d=\dfrac{M}{L}\times\dfrac{N}{K}$（组数×每组片数）；$M/L$ 字扩展、$N/K$ 位扩展 |
| 主存带宽 | $B_m = \dfrac{W}{T_m}$，即**每秒访问位数**；存取周期 $T_m >$ 存取时间 $T_a$ |
| 双端口存储器 | 两套端口独立并行；访问同一单元冲突由 **BUSY 标志仲裁** |
| 高位 vs 低位交叉 | 高位=体号在高位、**顺序编址利扩容**；低位=体号在低位、**连续地址跨体、流水提带宽** |
| 低位交叉流水线 | 连续读 $n$ 字 $t = T + (n-1)r$，$r=T/m$；同一体退化 $t = nT$；条件 **$m \geq T/r$** |
