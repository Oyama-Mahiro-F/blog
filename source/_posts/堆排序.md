**堆**：一棵完全二叉树，满足任意非叶结点的关键字**大于等于**（大顶堆）或**小于等于**（小顶堆）其孩子结点的关键字。

**堆的四条性质**：
1. 堆是一棵采用**顺序存储**结构的完全二叉树，$k_1$ 是根结点
2. 堆的根结点是关键字序列中的**最小**（或**最大**）值——小根堆（或大根堆）
3. 从根结点到每一叶子结点路径上的元素序列按值非递减（或非递增）
4. 堆中的**任一子树也是堆**

利用堆顶记录关键字最大（或最小）的性质，从待排序记录中依次选取关键字最大（或最小）的记录，实现对数据记录的排序，这种方法称为**堆排序**。

```
大顶堆示例:              存储为数组:
        97              [97, 76, 65, 49, 38, 13, 27]
       /  \             i 的左孩子: 2i+1
     76    65           i 的右孩子: 2i+2
    /  \   / \
   49  38 13  27
```

## 排序思想

① 对一组待排序的记录，按堆的定义**建立堆**（大顶堆或小顶堆）；

② 将**堆顶记录和最后一个记录交换位置**，则前 $n-1$ 个记录是无序的，而最后一个记录是有序的（最大/最小已归位）；

③ 堆顶记录被交换后，前 $n-1$ 个记录不再是堆，需**重新组织成为一个堆**（向下调整），然后将堆顶记录和倒数第二个记录交换位置；

④ **重复**上述步骤，直到全部记录排好序为止。

## 算法实现

```c++
// 将 a[k] 向下调整到正确位置（大顶堆）
void HeapAdjust(int a[], int k, int n) {
    int temp = a[k];
    for (int i = 2 * k + 1; i < n; i = 2 * i + 1) {
        if (i + 1 < n && a[i] < a[i + 1]) i++;   // i 指向较大的孩子
        if (temp >= a[i]) break;                   // 已满足堆定义
        a[k] = a[i];                               // 孩子上移
        k = i;                                     // 继续向下调整
    }
    a[k] = temp;
}

// 堆排序主函数
void HeapSort(int a[], int n) {
    // ① 建堆：从最后一个非叶结点开始逐个调整
    for (int i = n / 2 - 1; i >= 0; i--)
        HeapAdjust(a, i, n);

    // ② 排序：反复取堆顶
    for (int i = n - 1; i > 0; i--) {
        int t = a[0]; a[0] = a[i]; a[i] = t;   // 堆顶与堆尾交换
        HeapAdjust(a, 0, i);                    // 剩余元素调整
    }
}
```

## 性能分析

| 项目 | 说明 |
|:---|:---|
| 建堆时间 | $O(n)$（推导可为 $O(n)$，非 $O(n\log n)$） |
| 每次调整 | $O(\log n)$ |
| 总时间 | $O(n\log n)$（最好/最坏/平均均如此） |
| 空间 | $O(1)$（原地排序） |
| 稳定性 | **不稳定**（交换时可能打破同关键字顺序） |

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 堆排序-建堆 | 大顶堆顺序存于数组，孩子下标 $2i+1/2i+2$；**建堆 $O(n)$**（非 $O(n\log n)$） |
| 堆排序-总 | 堆顶与堆尾交换 + 向下调整；总时间 $O(n\log n)$ 与初始状态无关；$O(1)$ 空间；**不稳定** |
| 取前 k 个最小 | 冒泡/简单选择/堆皆可，**堆排序性能最好**（$n \gg k$ 时） |
