基数排序（Radix Sorting，又称**桶排序**或**数字排序**）：按待排序记录的关键字组成成分（或"位"）进行排序。它和前面各种内部排序方法**完全不同——不需要进行关键字的比较和记录的移动**，借助多关键字排序思想实现单逻辑关键字的排序。

## 多关键字排序思想

**最高位优先（MSD, Most Significant Digit first）**：先按第一个关键字 $K^1$ 排序分组，再对每个子序列按 $K^2$ 排序……最后将所有子序列依次联接成有序序列。

**最低位优先（LSD, Least Significant Digit first）**：与 MSD 相反，排序顺序从**最低位开始**——先按 $K^d$ 排序，再按 $K^{d-1}$，直到 $K^1$。

## LSD 基数排序过程

从最低位开始，依次对每一位进行"分配 → 收集"，高位在后保证高位权重更大。

```
初始: 278  109  063  930  589  184  505  269  008  083

按个位分配:
  0: 930
  3: 063  083
  4: 184
  5: 505
  8: 278  008
  9: 109  589  269
收集 → 930  063  083  184  505  278  008  109  589  269

按十位分配:
  0: 505  008  109
  3: 930
  6: 063  269
  8: 083  184  589
收集 → 505  008  109  930  063  269  083  184  589  278

按百位分配收集 → 008  063  083  109  184  269  278  505  589  930
```

## 链式基数排序实现（LSD）

① 首先以**静态链表**存储 $n$ 个待排序记录；

② 一趟排序过程：
- **分配**：按当前位 $K^d$ 的值，改变记录指针，将链表中的记录分配到 $r$ 个链表（桶）中，用 `f[i]`、`e[i]` 作为第 $i$ 个链表的头结点和尾结点；
- **收集**：改变所有非空链表的尾结点指针，使其指向下一个非空链表的第一个结点，将 $r$ 个链表重新链接成一个链表；

③ 依次按 $K^{d-1}, K^{d-2}, \dots, K^1$ 进行，共 $d$ 趟排序后完成。

```c++
#define RADIX 10                           // 基数（如十进制为 10）

void RadixSort(RecType R[], int n, int d) {
    int f[RADIX], e[RADIX];                // 桶的头、尾指针
    int i, j, k, p;

    for (i = 1; i <= n; i++)               // 建立静态链表
        R[i].next = i + 1;
    R[n].next = 0;                         // 最后一个结点 next=0
    p = 1;                                 // p 指向链表中第一个结点

    for (i = 1; i <= d; i++) {             // 共 d 趟排序
        for (j = 0; j < RADIX; j++)        // 初始化桶指针
            f[j] = e[j] = 0;

        while (p != 0) {                   // 分配
            k = GetDigit(R[p].key, i);     // 取第 i 位数字
            if (f[k] == 0)
                f[k] = p;                  // 桶的第一个结点
            else
                R[e[k]].next = p;          // 链接到桶尾
            e[k] = p;                      // 更新桶尾
            p = R[p].next;
        }

        j = 0;
        while (f[j] == 0) j++;             // 找第一个非空桶
        p = f[j];                          // p 指向第一个非空桶头
        k = e[j];                          // k 指向当前桶尾
        for (j++; j < RADIX; j++) {        // 收集：链接所有桶
            if (f[j] != 0) {
                R[k].next = f[j];          // 前一桶尾 → 下一桶头
                k = e[j];                  // 指向新桶尾
            }
        }
        R[k].next = 0;                     // 最后一桶尾结束链
    }
}
```

> 一趟分配：遍历链表，按当前位的值分入 $r$ 个桶；一趟收集：将 $r$ 个桶首尾相连，重新形成链表。

## 性能分析

| 项目 | 说明 |
|:---|:---|
| 时间复杂度 | $O(d(n+r))$，$d$ 为位数，$r$ 为基数 |
| 空间 | $O(r + n)$（需要 $r$ 个队列） |
| 稳定性 | **稳定** |

> 基数排序适用于 $n$ 大但 $d$ 小的场景，且关键字能拆分为多个独立的"位"。

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 基数排序 | **不比较不移动**，LSD 从低位"分配→收集" $d$ 趟；时间 $O(d(n+r))$、空间 $O(n+r)$；**稳定** |
| 适用场景 | $n$ 大 $d$ 小 |
| 比较次数与初始状态 | 无关：**基数、简单选择** |
