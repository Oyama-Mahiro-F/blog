**树（Tree）**是 408 数据结构的核心考点：它是**递归定义**的非线性结构，并且与二叉树之间存在**一一对应的转换关系**——这使得树的存储、遍历问题几乎都能"借"二叉树的算法来解决。408 对本章的考查集中在四块：**树的基本概念与性质计算、三种存储结构（双亲/孩子/孩子兄弟）、树与森林同二叉树的相互转换、树和森林的遍历与二叉树遍历的对应关系**，其中"遍历对应关系"几乎年年必考。二叉树本身的性质与遍历见姊妹文章《二叉树的递归遍历》《二叉树的非递归遍历与层序遍历》，本文不再重复。

## 树的基本概念

**树的递归定义**：树是 $n\ (n \ge 0)$ 个结点的有限集，$n = 0$ 时为**空树**；非空树满足：① 有且仅有一个**根结点（Root）**；② 其余结点可分为 $m\ (m \ge 0)$ 个**互不相交**的有限集 $T_1, T_2, \dots, T_m$，每个集合本身又是一棵树，称为根的**子树（Subtree）**。定义本身就是递归的——"子树仍是树"，这正是树的遍历、求高度等算法都写成递归形式的根源。

### 术语辨析

```text
              A          ← 根结点，第 1 层
            / | \
           B  C  D       ← B、C、D 互为兄弟，双亲都是 A
          / \      \
         E   F      G    ← E、F 与 G 互为堂兄弟（双亲 B、D 互为兄弟）
            |            ← 第 4 层
            H            ← H 是叶子（度为 0）
```

| 术语 | 含义 | 示例 / 提醒 |
|:---|:---|:---|
| 结点的**度** | 该结点的**孩子个数** | A 的度为 3，B 的度为 2 |
| 树的**度** | 全树所有结点度的**最大值** | 上图树的度为 3 |
| **分支结点** | 度不为 0 的结点 | 叶子以外的结点 |
| **叶子（Leaf）** | 度为 0 的结点 | 上图 C、E、F、H |
| **双亲 / 孩子** | 直接前驱 / 直接后继 | 每个结点**双亲唯一**，孩子可有多个 |
| **兄弟** | 同一双亲的孩子之间 | B、C、D 互为兄弟 |
| **堂兄弟** | 双亲在同一层（双亲互为兄弟）的结点 | E、F 与 G |
| **祖先 / 子孙** | 根到该结点路径上的所有结点 / 某结点子树中的全部结点 | A、B 是 E 的祖先；B 的子孙含 E、F |
| **层次 / 高度（深度）** | 根为第 1 层，孩子层 = 双亲层 + 1；树的高度 = **最大层数** | 上图高度为 4 |
| **路径 / 路径长度** | 两结点间所经的结点序列 / 路径上经过的**边数** | 根到 H 的路径长度为 3 |
| **有序树 / 无序树** | 各子树是否有左右次序之分 | 有序树交换子树次序即得**不同的树** |
| **森林** | $m\ (m \ge 0)$ 棵**互不相交**的树的集合 | $m = 0$ 为**空森林**，合法 |

> **考点**：**结点的度看"自己有几个孩子"，树的度取全树最大值**；度为 m 的树中**至少存在一个度为 m 的结点**，其余结点的度均不超过 m。
> **易错点**：**度为 m 的树至少有 m + 1 个结点**（根 + m 个孩子）；高度为 h 的树至少有 h 个结点（单链）。树中任意两结点间**路径唯一**；路径长度按**边数**计，根到自身为 0。

## 树的重要性质（常考五条）

| # | 性质 | 公式 |
|:---|:---|:---|
| 1 | 结点数 = 所有结点度数之和 + 1 | $n = \sum d_i + 1$ |
| 2 | 度为 m 的树第 i 层最多 $m^{i-1}$ 个结点 | $i \ge 1$，第 1 层即根 |
| 3 | 高度 h 的 m 叉树最多 $\frac{m^h - 1}{m - 1}$ 个结点 | 等比数列求和（$m > 1$） |
| 4 | n 个结点的 m 叉树**最小高度** | $\lceil \log_m(n(m-1)+1) \rceil$ |
| 5 | 度为 m 的树的叶子数 $n_0$ | $n_0 = 1 + n_2 + 2n_3 + \dots + (m-1)n_m$ |

**性质 1 推导**：除根外，每个结点有且仅有一条边连向双亲，故分支数（边数）$= n - 1$；每条边又恰好对应一个结点的一次"度"，所以度数之和 $= n - 1$，即 $n = \sum d_i + 1$。

**性质 3 推导**：把前 h 层（每层取最多）求等比数列和：

$$\sum_{i=1}^{h} m^{i-1} = \frac{m^h - 1}{m - 1}$$

**性质 4 推导（放缩求下界）**：高度为 h 的 m 叉树最多容纳 $\frac{m^h - 1}{m - 1}$ 个结点，要装下 n 个结点必须

$$\frac{m^h - 1}{m - 1} \ge n \;\Rightarrow\; m^h \ge n(m-1) + 1 \;\Rightarrow\; h \ge \log_m\!\big(n(m-1)+1\big)$$

取整数即得最小高度 $\lceil \log_m(n(m-1)+1) \rceil$；达到最小高度时**除最后一层外每层都放满**。

> **易错点**：性质 2、3、4 描述的都是"**每层塞满**"的极限情形——求**最少高度**时逐层放满，求**最多高度**时退化成**单链**（h = n）；别把"最多结点"与"最少结点"的方向弄反。

**例题（性质计算）**：一棵度为 4 的树中，度为 4 的结点 20 个、度为 3 的结点 10 个、度为 2 的结点 1 个、度为 1 的结点 10 个，求叶子结点数。

设叶子（度为 0）结点 $n_0$ 个。

第一步，写出总结点数：

$$n = n_0 + n_1 + n_2 + n_3 + n_4 = n_0 + 10 + 1 + 10 + 20 = n_0 + 41$$

第二步，写出度数之和（即分支数，叶子度为 0 不贡献）：

$$\sum d_i = 1 \times 10 + 2 \times 1 + 3 \times 10 + 4 \times 20 = 10 + 2 + 30 + 80 = 122$$

第三步，由性质 1（$n = \sum d_i + 1$）列方程求解：

$$n_0 + 41 = 122 + 1 = 123 \;\Rightarrow\; n_0 = 82$$

**验算**：用性质 5 直接算 $n_0 = 1 + n_2 + 2n_3 + 3n_4 = 1 + 1 + 2 \times 10 + 3 \times 20 = 82$ ✓；边数 $= n - 1 = 123 - 1 = 122$ = 度数和 ✓。

> **考点**：解"求叶子数"的万能钥匙只有一把——**结点数 = 度数和 + 1**。先用 $n_0$ 表示总点数，再算度数和，联立即可；熟记 $n_0 = 1 + \sum_{i \ge 2}(i-1)\,n_i$ 可秒选答案。
> **易错点**：度数和**不含**叶子（度为 0）；别给 $n_0$ 也乘上度；"度为 4 的树"只保证**存在**度为 4 的结点，不是每个结点都有 4 个孩子。

## 树的存储结构

树的多叉形态无法直接套用二叉链表，408 要求掌握三种方案：**双亲表示法、孩子表示法、孩子兄弟表示法**。

### 双亲表示法

用一组**连续空间**（数组）存结点，每个结点附设一个 **parent 域，存放其双亲在数组中的下标**；根结点的 parent = −1。

```c
#define MAX_TREE_SIZE 100
typedef struct {                 // 结点结构
    int data;                    // 数据域
    int parent;                  // 双亲下标，根为 -1
} PTNode;
typedef struct {                 // 树结构
    PTNode nodes[MAX_TREE_SIZE];
    int n, root;                 // 结点数、根的位置
} PTree;
```

```text
  A(0)            下标  data  parent
 / | \            0     A     -1   ← 根
B(1) C(2) D(3)    1     B      0
 |                2     C      0
E(4)              3     D      0
                  4     E      1   ← E 的双亲 B 在下标 1
```

**特点**：找双亲 $O(1)$（直接读 parent 域）；**找孩子必须遍历整个数组 $O(n)$**。这正是**并查集**的存储底子。

### 孩子表示法（孩子链表）

**顺序 + 链式**结合：头结点排成数组，每个头结点拉出一条**单链表**，依次串起自己的所有孩子。

```c
typedef struct CTNode {          // 孩子链表结点
    int child;                   // 孩子在数组中的下标
    struct CTNode *next;
} *ChildPtr;
typedef struct {                 // 头结点（数组元素）
    int data;
    ChildPtr firstchild;         // 指向第一个孩子结点
} CTBox;
typedef struct {
    CTBox nodes[MAX_TREE_SIZE];
    int n, root;
} CTree;
```

```text
  A(0)            0  A ──→ [1] ──→ [2] ──→ [3] ──→ NULL
 / | \            1  B ──→ [4] ──→ NULL
B(1) C(2) D(3)    2  C ──→ NULL
 |                3  D ──→ NULL
E(4)              4  E ──→ NULL
```

**特点**：**找孩子方便**（顺链表逐个走）；**找双亲要遍历所有链表 $O(n)$**。补救：给头结点再加一个 **parent 域**（双亲孩子表示法），则找双亲、找孩子都 $O(1)$/近常数，代价是空间增大。

### 孩子兄弟表示法（二叉链表）

每个结点设两个指针：**firstchild 指向第一个孩子，nextsibling 指向下一个兄弟**，即"**左孩子右兄弟**"。

```c
typedef struct CSNode {
    int data;
    struct CSNode *firstchild;   // 左：第一个孩子
    struct CSNode *nextsibling;  // 右：下一个兄弟
} CSNode, *CSTree;
```

```text
  A                       A
 /|\                     /
B C D        ──→        B ─→ C ─→ D      firstchild 向下指孩子
 |                      |                nextsibling 向右指兄弟
E                       E
```

关键赋值：`A.firstchild = B`，`B.nextsibling = C`，`C.nextsibling = D`，`B.firstchild = E`；叶子结点左右皆空。

**特点**：存储形态与**二叉树的二叉链表完全一致**（同一结构、两种解释），是**树与二叉树相互转换的桥梁**——408 默认的树的链式存储就是它；缺点同样是找双亲不方便。

### 三种存储结构对比

| 对比项 | 双亲表示法 | 孩子表示法 | 孩子兄弟表示法 |
|:---|:---|:---|:---|
| 存储方式 | **纯顺序**（数组） | 顺序 + 链式（孩子链表） | **纯链式**（二叉链表） |
| 结点域 | data + **parent** | data + **firstchild** | data + firstchild + nextsibling |
| 找双亲 | **$O(1)$** 直接读域 | $O(n)$ 遍历所有链表 | $O(n)$，不方便 |
| 找孩子 | $O(n)$ 遍历数组 | **方便**，顺链走 | 第一个孩子 $O(1)$，其余沿右链 |
| 空间开销 | 最省（每结点 1 个下标） | 头数组 + n 条孩子链 | 每结点 2 个指针 |
| 优点 | 找双亲快、实现简单 | 孩子操作高效、可加 parent 域补救 | **与二叉树结构统一**，可复用二叉树算法 |
| 缺点 | 找孩子慢 | 找双亲慢 | 找双亲慢 |
| 适用场景 | 频繁找双亲（**并查集**） | 频繁找孩子 | 树 ↔ 二叉树转换、通用处理 |

> **考点**：按需求选结构——**频繁找双亲选双亲表示法，频繁找孩子选孩子表示法，要与二叉树互相转换选孩子兄弟表示法**。
> **易错点**：双亲表示法中**根的 parent = −1**，这是判根的唯一标志；孩子链表里存的是孩子的**数组下标**而非结点值。

## 树、森林与二叉树的相互转换

转换规则只有一条，来自孩子兄弟表示法：**左孩子右兄弟**。

### 树 → 二叉树

**口诀**：结点的**左指针指向第一个孩子，右指针指向下一个兄弟**。

例：把下面这棵 4 层、度为 3 的树 $A\big(B(E,F),\ C,\ D(G(H))\big)$ 转为二叉树：

```text
        A                        A
      / | \                    /
     B  C  D                  B
    / \     \                / \
   E   F     G              E   C
             |               \   \
             H                F   D
                                 /
                                G
                               /
                              H
```

逐结点写出指针（左 = firstchild，右 = nextsibling）：

| 结点 | 左（firstchild） | 右（nextsibling） |
|:---|:---|:---|
| A | B | **NULL（根无右子树）** |
| B | E | C |
| C | NULL | D |
| D | G | NULL |
| E | NULL | F |
| F | NULL | NULL |
| G | H | NULL |
| H | NULL | NULL |

转换要点：

- 原树中**横向的兄弟关系**（B → C → D）变成二叉树里**沿右链下坠的一条链**；每个结点**第一个孩子**走左链，其余孩子依次挂在右链上。
- **树转成的二叉树，根结点一定没有右子树**——根没有兄弟。

### 森林 → 二叉树

**两步走**：① 每棵树各自按"左孩子右兄弟"转成二叉树；② 把各棵二叉树的**根用右指针串起来**——把后一棵树的根看成前一棵树根的**兄弟**。

例：森林 = 树 1 $A(B(D),\ C)$ 与树 2 $X(Y,\ Z)$：

```text
树 1 转换：A.left = B，B.left = D，B.right = C
树 2 转换：X.left = Y，Y.right = Z
串根：A.right = X

        A
       / \
      B   X
     / \  /
    D  C Y
         \
          Z
```

**特点**：森林转成的二叉树**根结点有右子树**，右链上的结点数 = 森林中其余树的棵数。

### 二叉树 → 树、森林（逆变换）

转换是**互逆**的，还原时倒着走：

1. **沿根的右链拆开**：根结点与右链上的每个结点各自作为一棵树的根——**根的右链长为几，就还原出几棵树；右链为空则只还原出一棵树**。
2. **左链还原为孩子**：对拆出的每棵二叉形态，结点的**左孩子是它的第一个孩子**，左孩子的**右链**依次是它的其余孩子。

> **考点**：看到转换结果先看**根结点有无右子树**——无 → 原来是一棵**树**；有 → 原来是**森林**（树的棵数 = 根的右链长度 + 1）。
> **易错点**："根无右子树"只对**树**转来的二叉树成立；森林转来的二叉树**根必有右子树**。此外**非根结点的右子树一般不为空**（挂着兄弟），别一看到右子树就说"是森林"。

## 树和森林的遍历

### 树的遍历：只有先根与后根

- **先根遍历**：先访问根，再**依次**先根遍历每一棵子树。
- **后根遍历**：先**依次**后根遍历每一棵子树，**最后访问根**。

> **辨析（树为什么没有中根遍历）**：二叉树的中序把根"夹"在左、右子树之间，位置唯一；而树有 k 棵子树时，根有 k − 1 个可能的"中间位置"，**根的访问时机无法唯一确定**，故树只定义先根、后根两种遍历。

### 森林的遍历

森林由若干棵树组成，**逐棵处理**：

- **先序遍历森林**：依次对每棵树做**先根**遍历。
- **中序遍历森林**（即"后根遍历森林"）：依次对每棵树做**后根**遍历。

### 与二叉树遍历的对应关系（必考）

| 遍历 | 树 | 森林 | 对应二叉树遍历 |
|:---|:---|:---|:---|
| 先根 / 先序 | 根 → 依次各子树 | 依次先序遍历各棵树 | **= 二叉树先序遍历** |
| 后根 / 中序 | 依次各子树 → 根 | 依次中序（后根）遍历各棵树 | **= 二叉树中序遍历** |

**推演例题（转换 + 遍历逐点验证）**：仍用上文那棵树 $A\big(B(E,F),\ C,\ D(G(H))\big)$。

先写出树的两个遍历序列（按定义直接走）：

```text
先根遍历：A → B → E → F → C → D → G → H   （根最先，叶子随后）
后根遍历：E → F → B → C → H → G → D → A   （子树走完根才出场）
```

再对转换后的二叉树做中序（左 · 根 · 右），逐层展开：

| 展开 | 结果片段 |
|:---|:---|
| 中序(A) = 中序(B) · A · 空（根无右子树） | 末位是 A |
| 中序(B) = 中序(E) · B · 中序(C) | E F B …… |
| 中序(E) = 左空 · E · 中序(F) | E F |
| 中序(C) = 左空 · C · 中序(D) | …… C …… |
| 中序(D) = 中序(G) · D · 右空 | H G D |
| 中序(G) = 中序(H) · G | H G |

拼接得二叉树中序序列 **E F B C H G D A**，与树的后根遍历**逐位相同** ✓；同理二叉树先序 **A B E F C D G H** 与树的先根遍历逐位相同 ✓。

**森林例**：森林 = 树 1 $A(B(D),\ C)$ + 树 2 $X(Y,\ Z)$（上文转换例）。二叉树先序 = **A B D C X Y Z**，恰等于森林先序 = 树 1 先根（A B D C）+ 树 2 先根（X Y Z）✓；二叉树中序 = **D B C A Y Z X**，恰等于森林中序 = 树 1 后根（D B C A）+ 树 2 后根（Y Z X）✓。

> **考点**：四条对应一句话记住——**"先"对"先"、"后"对"中"：树先根 = 先序，树后根 = 中序，森林先序 = 先序，森林中序 = 中序**。给转换后的二叉树求原树/森林的遍历序列（或反向）是最常见的考法。
> **易错点**：树和森林**都没有独立的"中根遍历"定义**——"森林的中序"就是逐棵树的后根，与二叉树中序等价；题目说"森林的中序遍历"和"后根序遍历"是同一回事，别当成两种序列。

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 树的递归定义 | 根唯一 + m ≥ 0 棵**互不相交**的子树；n = 0 空树、m = 0 空森林均合法 |
| 结点数与度数 | **结点数 = 度数和 + 1**（分支数 = n − 1） |
| 叶子数公式 | $n_0 = 1 + n_2 + 2n_3 + \dots + (m-1)n_m$ |
| 每层最多结点 | 第 i 层 $m^{i-1}$ 个；高度 h 最多 $\frac{m^h-1}{m-1}$ 个 |
| 最小高度 | $\lceil \log_m(n(m-1)+1) \rceil$；除最后一层外每层放满 |
| 双亲表示法 | 数组 + parent 下标（根为 −1）；找双亲 $O(1)$，找孩子 $O(n)$ |
| 孩子表示法 | 头数组 + 孩子链表；找孩子方便，找双亲难（可加 parent 域补救） |
| 孩子兄弟表示法 | 二叉链表 firstchild / nextsibling；**树 ↔ 二叉树转换的桥梁** |
| 树 → 二叉树 | **左孩子右兄弟**；转换后**根无右子树** |
| 森林 → 二叉树 | 各树先各自转，**根用右链串起**（根视为兄弟）；转换后根有右子树 |
| 二叉树还原 | **根 + 右链拆开**：右链长 k → 还原 k + 1 棵树；左链还原为孩子 |
| 树的遍历 | 只有先根、后根，**没有中根**（根的访问时机不唯一） |
| 遍历对应（必考） | 树先根 ↔ 先序；树后根 ↔ 中序；森林先序 ↔ 先序；森林中序 ↔ 中序 |
