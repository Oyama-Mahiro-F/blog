队列（Queue）是**只允许在一端插入、另一端删除**的线性表，遵循 **FIFO（先进先出）**。插入端叫**队尾（rear）**，删除端叫**队头（front）**。

三种实现方式各有分工：

| 实现 | 存储 | 核心问题 | 判满 |
|:---|:---|:---|:---|
| 循环队列 | 顺序（数组） | **假溢出** → 取模绕回解决 | `(rear+1) % MAXSIZE == front` |
| 链式队列 | 链式（链表） | 无假溢出，天然动态 | 不存在（除非内存耗尽） |
| 双端队列 | 两端都可入可出 | 合法输出序列判断 | 视受限类型而定 |

## 循环队列（顺序实现）

顺序队列用数组存储，`rear` 只会单调递增，导致 `front` 之前腾出的空间无法被利用——这就是**假溢出 (False Overflow)** 问题。解决办法：**循环队列**——将数组逻辑上视为环形，当指针到达数组末尾时通过**取模运算**绕回头部：

$$\text{rear} = (\text{rear} + 1) \bmod \text{MAXSIZE}$$
$$\text{front} = (\text{front} + 1) \bmod \text{MAXSIZE}$$

### 核心难点：判空 vs 判满

循环队列中 `front == rear` 既是空队条件也是满队条件，**必须区分**！三种经典方案：

| 方案 | 判空条件 | 判满条件 | 元素个数 | 特点 |
|:---|:---|:---|:---|:---|
| **牺牲一个单元** | `Q.front == Q.rear` | `(Q.rear + 1) % MAXSIZE == Q.front` | `(Q.rear - Q.front + MAXSIZE) % MAXSIZE` | **408 最常考，默认方案** |
| **增设 size 变量** | `Q.size == 0` | `Q.size == MAXSIZE` | `Q.size` | 直观，需增加 size 字段 |
| **增设 tag 标记** | `front==rear && tag==0` | `front==rear && tag==1` | 取决于 tag | tag=0 上次出队，tag=1 上次入队 |

> 考研默认采用**牺牲一个单元**方案。最大容纳元素数 = `MAXSIZE - 1`。

### 核心操作（牺牲一个单元方案，408 默认）

`front = rear = 0` 为初始值，`rear` 指向下一个空位。

```c++
#define MAXSIZE 50          // 定义队列中元素的最大个数

typedef struct {
    int data[MAXSIZE];      // 存放队列元素的静态数组
    int front;              // 队头指针
    int rear;               // 队尾指针
} SqQueue;
```

```c++
void InitQueue(SqQueue &Q) {
    Q.front = Q.rear = 0;       // 初始都指向下标 0，表示空队列
}

bool QueueEmpty(SqQueue Q) {
    return Q.front == Q.rear;   // 头尾指针重合即为空
}

bool QueueFull(SqQueue Q) {
    return (Q.rear + 1) % MAXSIZE == Q.front;
}

bool EnQueue(SqQueue &Q, int x) {
    // ① 先判满
    if ((Q.rear + 1) % MAXSIZE == Q.front)
        return false;

    // ② 存入 rear 指向的空位，③ rear 环形后移
    Q.data[Q.rear] = x;
    Q.rear = (Q.rear + 1) % MAXSIZE;
    return true;
}

bool DeQueue(SqQueue &Q, int &x) {
    // ① 先判空
    if (Q.front == Q.rear)
        return false;

    // ② 取出队头元素，③ front 环形后移
    x = Q.data[Q.front];
    Q.front = (Q.front + 1) % MAXSIZE;
    return true;
}

int QueueLength(SqQueue Q) {
    return (Q.rear - Q.front + MAXSIZE) % MAXSIZE;
    // +MAXSIZE 处理 rear 绕回后小于 front 的情况
}

bool GetHead(SqQueue Q, int &x) {
    if (Q.front == Q.rear)
        return false;           // 队空
    x = Q.data[Q.front];        // 直接读，不出队
    return true;
}
```

| 操作 | 核心步骤 |
|:---|:---|
| 入队 | `Q.data[Q.rear] = x; Q.rear = (Q.rear + 1) % MAXSIZE`（先存再移），$O(1)$ |
| 出队 | `x = Q.data[Q.front]; Q.front = (Q.front + 1) % MAXSIZE`（先取再移），$O(1)$ |
| 读队头 | `x = Q.data[Q.front]`，**不修改 front**，$O(1)$ |

### front 和 rear 的初始化方式（考研必背）

| 特性 | 方式一 `f=r=0` | 方式二 `f=0,r=-1` |
|:---|:---:|:---:|
| **rear 含义** | 下一个空位 | 当前队尾元素 |
| **初始值** | `front = 0, rear = 0` | `front = 0, rear = -1` |
| **判空** | `Q.front == Q.rear` | `Q.front > Q.rear` |
| **判满（牺牲单元）** | `(Q.rear + 1) % MAXSIZE == Q.front` | 不适用于循环队列 |
| **入队** | 先存再移 rear | 先移 rear 再存 |
| **出队** | 先取再移 front | 先取再移 front |
| **元素个数** | `(Q.rear - Q.front + MAXSIZE) % MAXSIZE` | `Q.rear - Q.front + 1` |

> **考研提醒**：408 默认采用**方式一**（`front = rear = 0`，rear 指向队尾下一位置，牺牲一个单元判满）。审题时先看清初始化值，再推导对应代码！

## 链式队列

链式队列（Linked Queue）用链表实现队列，`front` 指向队头、`rear` 指向队尾。链式队列**不会满**、不需要循环——天然没有假溢出问题。

> **核心设计原则**：入队在 `rear` 端（尾插法）、出队在 `front` 端（头删法），均为 $O(1)$。队头必须设在链表头部（否则出队找前驱退化为 $O(n)$）。

### 结构定义

```c++
// 队列的结点
typedef struct QNode {
    int data;
    struct QNode *next;
} QNode;

// 链式队列（包含头尾指针）
typedef struct {
    QNode *front;    // 指向队头（带头结点时指向头结点）
    QNode *rear;     // 指向队尾结点
} LinkQueue;
```

### 带头结点链式队列（408 最常考，逻辑统一）

头结点不存数据，`front` 永远指向头结点，第一个数据结点由 `front->next` 访问。

```c++
void InitQueue(LinkQueue &Q) {
    Q.front = Q.rear = (QNode *)malloc(sizeof(QNode));
    Q.front->next = NULL;       // 头结点的 next 置空
}

bool QueueEmpty(LinkQueue Q) {
    return Q.front == Q.rear;
}

bool EnQueue(LinkQueue &Q, int x) {
    QNode *s = (QNode *)malloc(sizeof(QNode));
    s->data = x;
    s->next = NULL;

    Q.rear->next = s;       // ① 将新结点链到队尾之后
    Q.rear = s;             // ② rear 后移到新结点
    return true;            // 链队不会满
}

bool DeQueue(LinkQueue &Q, int &x) {
    if (Q.front == Q.rear)          // 判空
        return false;

    QNode *p = Q.front->next;       // ① 锁定队头结点（头结点之后第一个）
    x = p->data;                    // ② 取出数据
    Q.front->next = p->next;        // ③ 头结点跳过 p

    if (Q.rear == p)                // ★ 若出队的恰好是最后一个元素
        Q.rear = Q.front;           //    rear 指回头结点，恢复空队

    free(p);                        // ④ 释放结点
    return true;
}

bool GetHead(LinkQueue Q, int &x) {
    if (Q.front == Q.rear)
        return false;               // 队空
    x = Q.front->next->data;        // 头结点之后第一个结点
    return true;
}
```

| 项目 | 内容 |
|:---|:---|
| 初始状态 | `front` 和 `rear` 都指向新创建的头结点 |
| 判空 | `Q.front == Q.rear`（头尾指针重合） |
| 入队核心 | `Q.rear->next = s; Q.rear = s`（尾插法），空队插入无需特殊处理 |
| 出队核心 | `p = front->next; front->next = p->next; free(p)` |
| 关键边界 | 出队最后一个元素后 **`Q.rear = Q.front`** 恢复空队 |

### 不带头结点链式队列

`front` 直接指向第一个数据结点。空队列时 `front = rear = NULL`。**入队第一个元素需要特殊处理**。

```c++
void InitQueue(LinkQueue &Q) {
    Q.front = Q.rear = NULL;    // 两个指针都置空
}

bool QueueEmpty(LinkQueue Q) {
    return Q.front == NULL;
}

bool EnQueue(LinkQueue &Q, int x) {
    QNode *s = (QNode *)malloc(sizeof(QNode));
    s->data = x;
    s->next = NULL;

    if (Q.front == NULL) {      // ★ 空队列：首尾都指向新结点
        Q.front = Q.rear = s;
    } else {                    // 非空队列：正常尾插
        Q.rear->next = s;
        Q.rear = s;
    }
    return true;                // 链队不会满
}

bool DeQueue(LinkQueue &Q, int &x) {
    if (Q.front == NULL)
        return false;           // 队空

    QNode *p = Q.front;         // ① 锁定队头
    x = p->data;
    Q.front = p->next;          // ② front 后移

    if (Q.rear == p)            // ★ 出队最后一个元素
        Q.rear = NULL;          //    rear 也要置空

    free(p);
    return true;
}
```

| 项目 | 内容 |
|:---|:---|
| 判空 | `Q.front == NULL` |
| 空队入队 | `Q.front = Q.rear = s`（两指针都指向新结点） |
| 出队最后元素 | 额外判断 `Q.rear == p` → **`Q.rear = NULL`** |

### 带头 vs 不带头对比

| 维度 | 带头结点 | 不带头结点 |
|:---|:---|:---|
| 初始值 | `front = rear = malloc(…); front->next = NULL` | `front = rear = NULL` |
| 判空 | `Q.front == Q.rear` | `Q.front == NULL` |
| 入队（空队） | 无需特殊处理 | `Q.front = Q.rear = s`（特殊处理） |
| 出队（最后） | `Q.rear = Q.front` | `Q.rear = NULL` |
| **考研倾向** | **★ 408 最常考，逻辑统一** | 需要多种边界判断 |

## 双端队列 (Deque)

### 定义

允许在**两端**都进行插入和删除操作。是栈和队列的泛化形式。

```
  dequeue <- +---+---+---+---+---+ <- enqueue
  enqueue -> |   |   |   |   |   | -> dequeue
             +---+---+---+---+---+
               left                right
```

> 图：双端队列示意——左端与右端均可进行入队与出队操作。

### 分类

| 类型 | 左端入 | 左端出 | 右端入 | 右端出 | 说明 |
|:---|:---:|:---:|:---:|:---:|:---|
| **双端队列** | ✓ | ✓ | ✓ | ✓ | 全功能，两端均可入可出 |
| **输入受限双端队列** | ✗ | ✓ | ✓ | ✓ | 只能从一端插入，两端均可删除 |
| **输出受限双端队列** | ✓ | ✓ | ✓ | ✗ | 两端均可插入，只能从一端删除 |

### 考研核心考点：合法序列判断

> 给定输入序列 `1, 2, 3, 4`，判断某个输出序列能否由特定类型的双端队列生成。

- **解题关键**：模拟过程，逐个检查目标序列中的元素是否可以从左端或右端合法进入/离开。
- **常见结论**：
  - 普通队列（一端入一端出）：输出序列唯一（即输入序列本身）。
  - 双端队列：合法序列数量远超普通队列，但少于栈（卡特兰数）。
  - 具体题目中需画图模拟，不可记结论。

## 三种队列实现对比

| 维度 | 循环队列（顺序） | 链式队列 | 双端队列 |
|:---|:---|:---|:---|
| 核心问题 | 假溢出 → 循环队列解决 | 无（天然动态） | 合法输出序列判断 |
| 容量 | 有限（`MAXSIZE - 1`） | 无限（仅受物理内存） | 视实现而定 |
| 判满 | `(rear+1) % MAXSIZE == front` | 不存在 | 视实现而定 |
| 入队/出队 | $O(1)$（偶尔扩容 $O(n)$） | 严格 $O(1)$ | 两端均 $O(1)$ |
| 适用场景 | 元素个数可预估 | 元素个数未知、波动极大 | 需要两端操作（如滑动窗口） |

## 栈 vs 队列 对比总结

| 维度 | 栈 (Stack) | 队列 (Queue) |
|:---|:---|:---|
| 原则 | LIFO 后进先出 | FIFO 先进先出 |
| 插入端 | 栈顶 (`top`) | 队尾 (`rear`) |
| 删除端 | 栈顶 (`top`) | 队头 (`front`) |
| 顺序实现核心问题 | 上溢出 (overflow) | **假溢出** (false overflow) |
| 顺序实现解决方案 | 动态扩容 / 共享栈 | **循环队列**（取模运算） |
| 链式实现判空 | `S.top->next == NULL` | `Q.front == Q.rear` |
| 双端版本 | — | 双端队列 (Deque) |
| 经典应用 | 括号匹配、表达式求值、DFS、函数调用 | 层次遍历、BFS、进程调度 |

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 顺序队列致命问题 | **假溢出**：rear 单调递增，front 前方已空位置无法再利用 |
| 循环队列核心思想 | **取模运算**绕回 |
| 判空（默认方案） | `front == rear` |
| 判满（牺牲单元） | **(rear+1) % MAXSIZE == front**，最大容量 MAXSIZE-1 |
| 元素个数公式 | **(rear - front + MAXSIZE) % MAXSIZE** |
| size 变量方案 | 判空 size==0、判满 size==MAXSIZE |
| tag 标记方案 | **tag=0 上次出队、tag=1 上次入队** |
| 链队设计原则 | 入队**尾插法**、出队**头删法**均 $O(1)$；**队头必须设在链表头部** |
| 带头结点链队 | 判空 front==rear；**出队最后元素令 rear=front** 恢复空队 |
| 不带头结点链队 | 判空 front==NULL；**空队入队 front=rear=s** 特殊处理 |
| 不带头结点出队最后元素 | 判断 rear==p 后令 **rear=NULL** |
| 双端队列分类 | 输入受限（只能一端插、两端删）/ 输出受限（两端插、只能一端删） |
| 双端队列合法序列 | 画图模拟，**不可死记结论** |
