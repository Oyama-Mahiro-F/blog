BST 可能退化为单链表（$h=n$）→ 查找效率降为 $O(n)$。AVL 在 BST 基础上添加**平衡约束**：任意结点左右子树高度差不超过 1，从而将树高控制在 $O(\log n)$。

## 结点类型定义

```c
typedef struct BSTNode {
    KeyType key;                             // 关键字域
    int Bfactor;                             // 平衡因子域（hL - hR）
    struct BSTNode *Lchild, *Rchild;         // 左、右孩子指针
} BSTNode;
```

> AVL 结点比普通 BST 结点多一个 `Bfactor` 字段。

## 定义与术语

| 术语 | 定义 |
|:---|:---|
| **平衡因子（BF）** | $BF = h_L - h_R$，取值为 $\{-1, 0, 1\}$ |
| AVL 条件 | 所有结点的 $\|BF\| \leq 1$ |
| 最小不平衡子树 | 离插入点最近的、$\|BF\| > 1$ 的结点为根的子树 |

## 平衡化旋转：四种失衡类型

插入/删除后：

1. 沿路径向上更新平衡因子
2. 找到第一个 $\|BF\| > 1$ 的结点 A（最小不平衡子树的根）
   - 删除时：站在失衡节点 A 上，看左右子树谁更高——**较高的孩子就是 B**；再看 B 的左右子树谁更高——**较高的孩子就是 C**；若 B 两个孩子一样高，选**和 A 到 B 同方向的那个**
3. 根据插入位置选择旋转类型（LL / RR / LR / RL）
4. 旋转后 A 的 BF 恢复为 -1/0/1，整个树恢复平衡

| 情况 | 插入位置 | 旋转方式 | 核心操作 |
|:---|:---|:---|:---|
| **LL** | 左子树的左子树 | 右单旋 | 树的左边太重，顺时针向右"掰" |
| **RR** | 右子树的右子树 | 左单旋 | 树的右边太重，逆时针向左"掰" |
| **LR** | 左子树的右子树 | 先左后右双旋 | 先左旋捋直（变 LL 型），再整体右旋 |
| **RL** | 右子树的左子树 | 先右后左双旋 | 先右旋捋直（变 RR 型），再整体左旋 |

> **旋转法则**：被挤掉的节点，直接挂到降级节点的空缺位置上。

**LL 旋转图解（右单旋）**：

```
旋转前（A的BF=2）:          右旋 →          旋转后（B的BF=0）:
        A                                      B
       / \                                    / \
      B   Ar                                Bl   A
     / \                                        / \
    Bl  Br                                     Br  Ar
插入Bl导致失衡
```

**LR 旋转图解（先左后右双旋）**：

```
旋转前（A的BF=2）:    先左旋B子树（→LL）    再右旋A:
        A                  A                    C
       / \                / \                  / \
      B   Ar      →      C   Ar       →      B   A
     / \                / \                  / \ / \
    Bl  C              B  Cr               Bl Cl Cr Ar
       / \            / \
      Cl  Cr        Bl  Cl(?)
插入C的子树导致失衡
```

## AVL 树的查找

查找过程与普通 BST **完全一样**——从根开始，小于走左、大于走右。

- 和给定关键字比较的次数**不超过树的深度**
- 含有 $n$ 个结点的 AVL 树最大深度为 $\approx 1.44\log_2(n+1)$
- 平均查找长度和 $\log_2 n$ 一个数量级

## 性能分析

| 项目 | 值 |
|:---|:---|
| 含有 $n$ 个结点的 AVL 最大高度 | $\approx 1.44\log_2(n+1)$ |
| 查找 | $O(\log_2 n)$ |
| 插入 | $O(\log_2 n)$（最多一次旋转，发生在最小不平衡子树根处） |
| 删除 | $O(\log_2 n)$（可能多次旋转直到根） |

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| AVL 平衡因子 | $BF=h_L-h_R\in\{-1,0,1\}$；$\vert BF\vert>1$ 处为最小不平衡子树根 |
| AVL 四旋转 | **LL 右单旋、RR 左单旋、LR 先左后右、RL 先右后左** |
| AVL 旋转法则 | 被挤掉的结点挂到**降级结点的空缺位置** |
| AVL 复杂度 | 高 $\approx1.44\log_2(n+1)$；插入最多 **1** 次旋转、删除可 $O(\log n)$ 次 |
