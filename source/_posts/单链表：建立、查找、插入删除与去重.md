单链表通过"指针"将一个个零散的内存块（节点）串联起来。每个节点包含**数据域 (data)** 和**指针域 (next)**。

```c++
typedef struct LNode {
    ElemType data;        // 数据域
    struct LNode *next;   // 指针域，指向下一个节点
} LNode, *LinkList;       // LNode 强调这是一个节点，LinkList 强调这是一个链表
```

**头结点机制**：头指针指向头结点；头结点不存放数据。

- 有头结点：判空条件 `p->next == NULL`
- 无头结点：判空条件 `p == NULL`

> **贯穿全文的两条铁律**：
> ① **钩链顺序**永远是「先连后面大部队，再让前驱牵自己」——顺序反了会断链 + 内存泄漏。
> ② **删除时前驱指针原地不动**，只让探路指针接手 `p->next`，否则连续重复项会漏网。

## 建立：头插法与尾插法

### 头插法（逆序建表）

"后来居上"——每次新来的节点都抢占"第一名"的位置，紧紧贴在头结点后面。核心两步钩链：**先连后面大部队，再让前驱牵自己**（防止断链）。

```c++
// 头插法创建单链表 (逆序建表)
LinkList CreateList_Head() {
    int data;

    // 1. 建立头结点
    LinkList L = (LinkList)malloc(sizeof(LNode));
    L->next = NULL; // 致命防雷点：头结点必须置空，否则遍历会陷入野指针！

    // 2. 循环读取数据
    scanf("%d", &data);
    while (data != 9999) { // 假设 9999 为输入结束标志

        // 申请新节点并赋值
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = data;

        // 3. 核心钩链：永远插在头结点之后
        s->next = L->next;
        L->next = s;

        scanf("%d", &data);
    }

    return L;
}
```

**特点**：输入顺序与链表顺序相反（逆序建表），时间复杂度 $O(n)$。

### 尾插法（顺序建表）

"先来后到，排队上车"——核心在于维护一个**尾指针 `r` (rear)**，每来一个节点挂在最后面，然后尾指针后移。

```c++
// 尾插法创建单链表 (正序建表)
LinkList CreateList_Tail() {
    int data;

    // 1. 建立头结点
    LinkList head = (LinkList)malloc(sizeof(LNode));

    // 2. 极其关键：定义尾指针 r，初始状态下，头结点就是尾巴
    LNode *s, *r = head;

    // 3. 循环读取数据
    scanf("%d", &data);
    while (data != 9999) { // 假设 9999 为输入结束标志

        // 申请新节点并赋值
        s = (LNode *)malloc(sizeof(LNode));
        s->data = data;

        // 4. 核心钩链：永远插在尾指针 r 之后
        r->next = s; // 步骤一：把新节点 s 挂在当前尾巴 r 的后面
        r = s;       // 步骤二：尾指针 r 向后移动，重新指向新的尾巴 s

        scanf("%d", &data);
    }

    // 5. 致命考点：循环结束后，必须亲手将尾节点的指针置空！
    r->next = NULL;

    return head;
}
```

**特点**：输入顺序与链表顺序一致（顺序建表），时间复杂度 $O(n)$。

## 查找：按序号与按值

与顺序表（数组）$O(1)$ 的随机访问不同，单链表的物理内存是分散的。要想找到第 $i$ 个元素，唯一办法就是"顺藤摸瓜"：从头结点开始，顺着 `next` 指针一节一节往后数。因此单链表只能**顺序存取**，查找复杂度 $O(n)$。

遍历时指针移动的三种基本操作：

- **`q = p`（共享同一节点）**：没有产生新的物理节点，只是让 q 和 p 指向内存中的同一个实体：

![节点赋值 q = p](/blog/images/第2章 线性表.assets/Pointer Relationship-2026-06-10-120108.png)

- **`q = p->next`（探路）**：q 越过 p，直接获取后继节点的地址，常用于遍历或删除前的"锁定"目标：

![赋值为直接后继 q = p->next](/blog/images/第2章 线性表.assets/image-20260610200251684.png)

- **`p = p->next`（指针后移）**：p 放弃当前节点，更新指向为下一个节点，是遍历链表的"履带行进"：

![指针向后移动 p = p->next](/blog/images/第2章 线性表.assets/Pointer Relationship-2026-06-10-120528.png)

### 按序号查找

返回带头结点的单链表 L 中第 $i$ 个位置的结点指针：

```c++
LNode* GetElem(LinkList L, int i) {
    // 1. 极其关键的边界防雷
    if (i < 0) {
        return NULL; // 位置不合法
    }
    if (i == 0) {
        return L;    // 如果 i=0，按惯例返回头结点（插入操作找前驱时非常有用）
    }

    // 2. 初始化探路员 p 和计数器 j
    int j = 1;          // j 表示当前 p 指向的是第几个真正的数据结点
    LNode *p = L->next; // p 初始指向第一个数据结点

    // 3. 核心遍历：只要没找完，且前方还有路，就一直往下走
    while (p != NULL && j < i) {
        p = p->next; // 走到下一个结点
        j++;         // 计数器加 1
    }

    // 4. 返回结果
    // 循环结束有两种情况：
    // 情况 A: j == i，找到了！此时 p 指向第 i 个结点。
    // 情况 B: p == NULL，还没数到 i 链表就断了，返回 NULL。
    return p;
}
```

### 按值查找

查找值为 e 的第一个结点指针：

```c++
LNode* LocateElem(LinkList L, ElemType e) {
    LNode *p = L->next; // p 初始指向第一个真实的数据结点

    // 只要 p 没走到尽头，且当前结点的值不是我们要找的 e，就继续往下走
    while (p != NULL && p->data != e) {
        p = p->next;
    }

    // 循环结束时有两种可能：
    // 1. p 停在了 p->data == e 的结点上（找到了）
    // 2. p 走到了尽头变成了 NULL（没找到）
    // 无论哪种情况，直接返回 p 都是绝对正确的！
    return p;
}
```

## 插入与删除

单链表插入/删除的核心都是"**寻找前驱**"。已知位置时插入/删除仅需改指针，$O(1)$；按位操作需先遍历找前驱，$O(n)$。

### 按位插入（在第 i 个位置插入元素 e）

**黄金法则**：先连后面大部队，再让前驱牵自己——指针赋值顺序绝对不能反！

![单链表插入节点](/blog/images/第2章 线性表.assets/Pointer Relationship-2026-06-10-121132.png)

```c++
bool ListInsert(LinkList L, int i, ElemType e) {
    if (i < 1) return false; // 位置不合法

    LNode *p = L; // p 指向头结点
    int j = 0;    // 当前 p 指向的是第几个节点

    // 1. 寻找第 i-1 个节点（前驱节点）
    while (p != NULL && j < i - 1) {
        p = p->next;
        j++;
    }

    if (p == NULL) return false; // i 值超过了链表长度

    // 2. 创建新节点 s
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;

    // 3 & 4. 核心钩链操作
    s->next = p->next; // 步骤一：新节点连上后面的大部队
    p->next = s;       // 步骤二：前驱节点连上新节点

    return true;
}
```

> 如果先执行 `p->next = s;`，那么 p 原本后面的节点地址就彻底丢失了——内存泄漏 + 链表断裂！

### 按序号删除（删除第 i 个节点）

删除解剖三步曲：**长途跋涉找前驱 → 派驻哨兵防泄漏 → 逻辑跨越与物理超度**。

![单链表删除节点](/blog/images/第2章 线性表.assets/Pointer Relationship-2026-06-10-121132-17810938573874.png)

```c++
bool ListDelete_Index(LinkList L, int i, ElemType *e) {
    int j = 0;
    LNode *p = L; // p 初始指向头结点（序号0）
    LNode *q;     // 用于锁定目标的辅助指针

    // 1. 寻找第 i-1 个节点（前驱）
    while (p != NULL && j < i - 1) {
        p = p->next;
        j++;
    }

    // 2. 极其严格的边界防雷检查
    // p == NULL：i 远远超过了链表的长度
    // p->next == NULL：第 i-1 个节点后面没有第 i 个节点可删
    // j > i - 1：拦截 i = 0 或负数不合法序号
    if (p == NULL || p->next == NULL || j > i - 1) {
        return false; // 删除失败，位置不合法
    }

    // 3. 执行安全的删除手术
    q = p->next;        // 步骤一：哨兵 q 锁定第 i 个节点
    p->next = q->next;  // 步骤二：前驱 p 绕过 q，连向第 i+1 个节点
    *e = q->data;       // 步骤三：提取被删节点的数据交给 e
    free(q);            // 步骤四：物理释放内存

    return true; // 删除成功
}
```

### 按值删除：删除第一个值为 key 的节点

**短路求值拦截崩溃**：`while (q != NULL && q->data != key)` 中，若链表中没有 key，q 最终变成 NULL，短路求值会直接跳出循环；顺序写反会因访问 `NULL->data` 崩溃！

```c++
bool DeleteFirstKey(LinkList L, ElemType key) {
    LNode *p = L;           // p 充当前驱指针，初始指向头结点
    LNode *q = L->next;     // q 充当探路指针，初始指向第一个有效节点

    // 1. 探路员 q 在前搜索，前驱 p 在后紧跟
    // 安全铁律：必须先判断 q != NULL，再判断 q->data != key
    while (q != NULL && q->data != key) {
        p = q;              // p 挪到当前 q 的位置，成为新的前驱
        q = q->next;        // q 迈步走向下一个节点
    }

    // 2. 循环跳出后的边界检查
    if (q == NULL) {
        return false;       // 查到了链表尽头也没找到 key
    }

    // 3. 找到了！此时 q 停在第一个 key 节点上，p 稳站其前驱
    p->next = q->next;      // 核心断链：前驱 p 越过 q
    free(q);                // 物理销毁

    return true;            // 删除成功
}
```

### 按值删除：删除所有值为 key 的节点

**核心灵魂**：删除发生时 `p` 绝对不能动！删除一个 key 后，`q` 接手 `p->next` 继续探测，防止连续相同 key 漏网。

```c++
void DeleteAllKeyNodes(LinkList L, ElemType key) {
    LNode *p = L;           // p 充当前驱指针，初始指向头结点
    LNode *q = L->next;     // q 充当工作指针，用来遍历检查每个节点

    while (q != NULL) {
        if (q->data == key) {
            // 【情况 A：命中目标，执行切除】
            p->next = q->next; // 前驱 p 越过 q
            free(q);           // 物理释放
            q = p->next;       // 核心灵魂！q 重新指向新的后继，但 p 保持原地不动！
        }
        else {
            // 【情况 B：未命中目标，双指针安全同步后移】
            p = q;             // p 挪到当前 q 的位置
            q = q->next;       // q 迈步走向下一个节点
        }
    }
}
```

## 经典例题：删除重复节点

在无序链表中，重复的元素可能隔得很远（如 `10 -> 20 -> 30 -> 10`）。彻底去重需要三个指针各司其职："双层嵌套循环 + 三指针暴力扫荡"。

### 核心战术：为什么要用三个指针？

1. **锚点 `p`（基准）**：站在原地的指挥官。如果 p 站在 10 上，它就向后下达命令："后面所有人，谁也是 10，格杀勿论。"
2. **巡视员 `ptr`（探路）**：顺着链表往下挨个查身份证，看是否跟指挥官 p 的值一样。
3. **行刑者 `q`（前驱）**：ptr 的影子。删除操作永远离不开前驱节点，所以 q 必须死死跟在 ptr 后面，一旦 ptr 被核实为重复项，q 立即执行绕过和断链。

### 算法实现

```c++
// 删除带头结点的单链表 L 中所有值重复的节点（保留首次出现的节点）
void DeleteDuplicateNodes(LinkList L) {
    if (L == NULL || L->next == NULL) return; // 空表或只有一个节点的表，直接返回

    LNode *p = L->next; // p 充当"锚点(标尺)"，逐个考察每一个节点
    LNode *q, *ptr;     // ptr 充当"巡视员"向后寻找重复值，q 是 ptr 的前驱

    while (p != NULL) { // 外层循环：p 从头到尾锚定每一个基准节点
        q = p;          // 每次向后巡视前，q 初始指向当前的锚点 p
        ptr = p->next;  // ptr 从 p 的下一个节点开始向后巡视

        while (ptr != NULL) { // 内层循环：ptr 检查 p 后面的所有节点
            if (ptr->data == p->data) {
                // 【发现重复值！暗杀开始】
                q->next = ptr->next; // 前驱 q 绕过 ptr
                free(ptr);           // 物理毁灭重复节点
                ptr = q->next;       // ptr 继续指向新的下一个节点（q 原地不动！）
            }
            else {
                // 【不是重复值，安全路过】
                q = ptr;             // q 跟上 ptr
                ptr = ptr->next;     // ptr 继续往下走
            }
        }
        // 以 p 为基准的重复值已全部清洗干净
        p = p->next; // 锚点 p 往下挪一步，开始下一轮大清洗
    }
}
```

### 关键细节

- **删除后 q 不动、ptr 接替**：与"删所有 key"同理，`ptr = q->next` 保证连续重复也能被连续切除
- **保留首次出现**：外层 p 逐个做基准，内层只删 p 之后的重复项，首次出现的节点天然保留
- **时间复杂度**：$O(n^2)$（双层嵌套循环），空间 $O(1)$

## 操作复杂度汇总

| 操作 | 时间复杂度 | 说明 |
|:---|:---|:---|
| 头插法建表 | $O(n)$ | 逆序建表 |
| 尾插法建表 | $O(n)$ | 顺序建表，结束须置 `r->next = NULL` |
| 按序号查找 | $O(n)$ | 只能顺序存取 |
| 按值查找 | $O(n)$ | 双条件短路 |
| 已知位置插入/删除 | $O(1)$ | 仅改指针 |
| 按位插入/删除 | $O(n)$ | 需先遍历找前驱 |
| 删除所有 key | $O(n)$ | 一趟遍历 |
| 删除重复节点 | $O(n^2)$ | 双层嵌套 + 三指针 |

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 头插法建表 | **逆序建表**，$O(n)$；头结点必须置 `L->next = NULL` |
| 尾插法建表 | **顺序建表**，$O(n)$；结束必须**置尾结点 next=NULL** |
| 钩链顺序 | 永远先 `s->next = p->next;` 再 `p->next = s;`——**先连后面，再连前面**，防止断链 |
| 按序号查找 | 从头结点出发顺藤摸瓜，$i=0$ 返回头结点（找前驱用） |
| 按值查找 | `while (p != NULL && p->data != e)` 双条件短路，直接返回 p |
| 单链表插入 | **先连后面大部队，再让前驱牵自己**（防断链） |
| 单链表删除 | 派哨兵 `q` **锁定目标** → 绕过 → `free(q)` |
| 删除所有 key | 删除后 **p 原地不动**，只让 q 接手 p->next 继续探路 |
| 删除重复结点 | **p/ptr/q 三指针** + 双层嵌套循环，$O(n^2)$；p 锚点基准、ptr 巡视、q 当前驱 |
| 已知位置的插入/删除 | 仅改指针，$O(1)$；按位操作需找前驱，$O(n)$ |
