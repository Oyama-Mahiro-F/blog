顺序表（Sequential List）用顺序存储的方式实现线性表——把**逻辑上相邻**的元素存储在**物理位置上也相邻（地址连续）**的存储单元中。随机存取 $O(1)$，但插入/删除需移动大量元素。

## 结构定义

**静态分配**（数组方式，长度定死）：

```c++
#define MaxSize 10          // 定义最大长度

typedef struct {
    ElemType data[MaxSize]; // 用静态的"数组"存放数据元素
    int length;             // 顺序表的当前长度
} SqList;                   // 结构体的类型别名
```

**动态分配**（指针方式，可扩容）：

```c++
#define InitSize 10         // 默认的最大长度

typedef struct {
    ElemType *data;         // 指示动态分配数组的指针
    int MaxSize;            // 顺序表的最大容量
    int length;             // 顺序表的当前长度
} SeqList;                  // 结构体的类型别名
```

## 初始化

**静态分配**：数组空间已在结构体内部，只需初始化 length。

```c++
void InitList_Sq(SqList *L) {
    L->length = 0;
}
```

**动态分配**：用 malloc 申请连续存储空间。

```c++
void InitList_Seq(SeqList *L) {
    // 1. 用 malloc 申请一片连续的存储空间
    L->data = (ElemType *)malloc(InitSize * sizeof(ElemType));

    // 2. 健壮性检查：内存分配失败时 malloc 返回 NULL
    if (L->data == NULL) {
        return;
    }

    // 3. 初始化当前长度为 0，表示空表
    L->length = 0;

    // 4. 初始化最大容量为 InitSize
    L->MaxSize = InitSize;
}
```

## 插入操作

在第 $i$ 个位置插入新元素 $e$（$i$ 的范围是 1 到 length+1）。**必须从后往前搬**元素：

```c++
bool ListInsert_Seq(SeqList *L, int i, ElemType e) {
    // 1. 边界防雷：判断 i 的范围是否有效
    if (i < 1 || i > L->length + 1) {
        return false; // 插入位置不合法
    }

    // 2. 容量防雷：当前存储空间已满，不能插入
    if (L->length >= L->MaxSize) {
        return false;
    }

    // 3. 核心搬家操作：把第 i 个元素及之后的元素全部后移一位
    // 极其关键：必须从后往前搬！
    for (int j = L->length; j >= i; j--) {
        L->data[j] = L->data[j - 1];
    }

    // 4. 腾出空位，放入新元素
    L->data[i - 1] = e; // 数组下标从 0 开始，第 i 个位置的下标是 i-1

    // 5. 长度加 1
    L->length++;

    return true; // 插入成功
}
```

## 删除操作

删除第 $i$ 个位置的元素。**必须从前往后搬**：

```c++
bool ListDelete_Seq(SeqList *L, int i) {
    if (L->length == 0) {
        return false;
    }
    // 1. 边界防雷：判断 i 的范围是否有效
    if (i < 1 || i > L->length) {
        return false; // 删除位置不合法
    }

    // 2. 核心搬家操作：把第 i 个位置之后的元素全部前移一位
    // 极其关键：必须从前往后搬！
    for (int j = i; j < L->length; j++) {
        L->data[j - 1] = L->data[j];
    }

    // 3. 长度减 1（物理上原数据还在内存里，但逻辑上已不在表内）
    L->length--;

    return true; // 删除成功
}
```

## 按值查找

```c++
int LocateElem_Sq(SqList L, ElemType e) {
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] == e) {
            return i + 1; // 找到了，返回位序（数组下标 + 1）
        }
    }
    return 0; // 遍历完都没找到，返回 0 表示失败
}
```

## 查找定位删除

查找第一个值为 key 的元素并删除它（先查后删的组合操作）：

```c++
bool LocateAndDelete_Seq(SeqList *L, ElemType key) {
    int target_index = -1; // 记录目标元素的数组下标

    // 1. 遍历查找
    for (int i = 0; i < L->length; i++) {
        if (L->data[i] == key) {
            target_index = i; // 找到了！记录下标
            break;            // 找到第一个就停止查找
        }
    }

    // 2. 判断是否找到
    if (target_index == -1) {
        return false; // 没找到，删除失败
    }

    // 3. 核心搬家操作：将 target_index 后面的所有元素统一前移一位
    for (int j = target_index + 1; j < L->length; j++) {
        L->data[j - 1] = L->data[j];
    }

    // 4. 长度减 1
    L->length--;

    return true; // 删除成功
}
```

## 时间复杂度分析

| 操作 | 时间复杂度 | 原因 |
|:---|:---:|:---|
| **按位查找** | $O(1)$ | 连续存放，直接计算地址 |
| **按值查找** | $O(n)$ | 需逐个遍历比较 |
| **插入 / 删除** | $O(n)$ | 需移动元素（平均移动 $n/2$ 次） |

## 记忆要点

- 位序从 **1** 开始（数组下标从 0 开始）
- 插入**从后往前**搬，删除**从前往后**搬——方向不能错
- 静态分配长度定死不可变；动态分配 malloc 新空间可扩容
- 存储密度 = 1，随机存取 $O(1)$，适合查找密集型场景
