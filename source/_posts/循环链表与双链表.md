循环链表将原本指向 `NULL` 的尾巴**重新连回头结点**；双链表在每个节点多塞一个指针 `prior`，用**空间换时间**把"找前驱"从 $O(n)$ 降到 $O(1)$。

## 循环单链表：首尾相连的衔尾蛇

- **普通单链表**判表尾：`p->next == NULL`
- **循环单链表**判表尾：**`p->next == L`**（下一步是否绕回起点）

**尾指针（rear）策略**：不设头指针、只设尾指针 `rear` 时，找尾节点 $O(1)$（直接是 rear），找头结点 $O(1)$（`rear->next`）。

### 实例：合并两个循环单链表

两个用尾指针 `Ta` 和 `Tb` 表示的带头结点循环单链表，首尾相接拼成一个大环。

**口诀**：存 A 头，A 尾接 B 头（实质数据），斩 B 头，B 尾接 A 头。

```c++
LinkList Merge_Circular(LNode *Ta, LNode *Tb) {
    LNode *p = Ta->next;         // 1. 派 p 暂存 A 的头结点，防走丢

    Ta->next = Tb->next->next;   // 2. A 的尾巴连上 B 的第一个有效节点（跳过 B 的头结点）

    free(Tb->next);              // 3. 过河拆桥：B 的头结点没用了，物理超度

    Tb->next = p;                // 4. B 的尾巴连回 A 的头结点，形成终极大闭环

    return Tb;                   // 5. 返回全新的大尾巴
}
```

## 循环双链表：极其优雅的"四通八达"

普通双链表在头尾插入/删除时总要写 `if (p->next != NULL)` 防雷。**循环双链表直接消灭了 NULL**：头结点的 `prior` 指向尾巴，尾巴的 `next` 指向头，没有死角。

```c++
// 初始化循环双链表
void InitDLinkList(DLinkList *L) {
    *L = (DNode *)malloc(sizeof(DNode));
    (*L)->prior = *L; // 头的前驱是自己
    (*L)->next = *L;  // 头的后继也是自己
}

// 判断是否为空：自己指自己
bool Empty(DLinkList L) {
    return L->next == L;
}
```

**无脑插入**（在节点 p 之后插入 s，无需边界判断）：

```c++
s->next = p->next;     // 1. s 的右臂拉住后面的兄弟
p->next->prior = s;    // 2. 后面的兄弟伸出左臂拉住 s（循环链表绝对不会报空指针错误！）
s->prior = p;          // 3. s 的左臂拉住大哥 p
p->next = s;           // 4. 大哥 p 的右臂拉住小弟 s
```

## 双链表（非循环）的插入：著名的"四步连线法"

**目标**：在节点 p 的**后面**插入新节点 s。
**口诀**：**"先连右边（后继），再连左边（前驱）"**——绝对不能先动 `p->next`，否则大部队失联！

```c++
typedef struct DNode {
    ElemType data;              // 数据域
    struct DNode *prior;        // 前驱指针（向左看）
    struct DNode *next;         // 后继指针（向右看）
} DNode, *DLinkList;

bool InsertNextDNode(DNode *p, DNode *s) {
    if (p == NULL || s == NULL)
        return false;               // 非法参数拦截

    // 1. s 的右臂拉住后面的兄弟
    s->next = p->next;

    // 2. 致命防雷点：后面的兄弟伸出左臂拉住 s
    // 如果 p 是最后一个节点，p->next 就是 NULL，空指针没有 prior，强行访问会崩溃！
    if (p->next != NULL) {
        p->next->prior = s;
    }

    // 3. s 的左臂拉住大哥 p
    s->prior = p;

    // 4. 大哥 p 的右臂放开原小弟，拉住新小弟 s
    p->next = s;

    return true;
}
```

## 双链表的删除

删除节点 p 的后继节点 q，只需 2 步断链，但同样要防空指针：

```c++
bool DeleteNextDNode(DNode *p) {
    if (p == NULL || p->next == NULL)
        return false;           // p 不存在，或 p 后面没东西可删

    DNode *q = p->next; // 派临时指针 q 锁定要被杀掉的目标

    // 1. 大哥 p 的右臂直接越过 q，拉住 q 后面的兄弟
    p->next = q->next;

    // 2. 致命防雷点：q 后面的兄弟伸出左臂，越过 q，拉住大哥 p
    if (q->next != NULL) {
        q->next->prior = p;
    }

    // 3. 物理毁灭 q
    free(q);

    return true;
}
```

> **核心总结**：双链表的"边界地雷"就是 `if (p->next != NULL)`——最后一个节点的 next 指向 NULL，修改 NULL 的 prior 会段错误。这是双链表大题最容易丢分的细节。
