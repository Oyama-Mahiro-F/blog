每趟从头到尾依次比较相邻元素，若逆序则交换——每趟把最大值"冒"到末尾。若某趟无交换，则已有序，提前结束。

## 排序过程示例

```
初始:  49  38  65  97  76  13  27

第1趟: 38↙49  65  76↙97  13↙97  27↙97   → 38  49  65  76  13  27  [97]
第2趟: 38  49  65  13↙76  27↙76 [76  97]  → 38  49  65  13  27  [76  97]
...
```

（"↙" 表示交换方向）

## 算法实现

```c++
void BubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {           // 逆序则交换
                int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
                swapped = 1;
            }
        }
        if (!swapped) break;                 // 无交换 → 已有序
    }
}
```

## 性能分析

| 情况 | 时间 | 说明 |
|:---|:---|:---|
| 最好（正序） | $O(n)$ | 一趟无交换即结束 |
| 最坏（逆序） | $O(n^2)$ | |
| 平均 | $O(n^2)$ | |
| 空间 | $O(1)$ | |
| 稳定性 | **稳定** | `>` 不交换相等元素 |

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 冒泡排序 | 相邻逆序交换，某趟**无交换即提前结束**；最好 $O(n)$；**稳定** |
| 每趟能否定最终位置 | 能（交换类排序，每趟确定一个最大值位置） |
| 取前 k 个最小 | 冒泡/简单选择/堆皆可，**堆排序性能最好**（$n \gg k$ 时） |
