栈（Stack）是**只允许在一端（栈顶）进行插入和删除**的线性表，遵循 **LIFO（后进先出）**。两种存储实现各有讲究：

| 实现 | 存储 | 判满 | 入栈/出栈 |
|:---|:---|:---|:---|
| 顺序栈 | 连续数组 | `top == MAXSIZE`（静态）/ 自动扩容（动态） | $O(1)$，扩容瞬间 $O(n)$ |
| 链栈 | 单链表 | 不存在（`malloc` 失败才满） | 严格 $O(1)$（头插/头删） |

> **贯穿两种实现的铁律**：栈顶必须锚定在**数组末端 / 链表头部**——否则入栈找尾、出栈找前驱都会退化成 $O(n)$。

## 顺序栈（静态与动态）

顺序栈利用**一段物理地址连续的存储空间**（数组）存储栈内元素，分**静态**和**动态**两种，核心区别在于底层数组容量是否可以在运行期间改变。

### 静态顺序栈

容量在编译时就固定，通常用宏定义指定数组大小，是考试中最常见、最基础的形式。

```c++
#define MAXSIZE 50      // 定义栈中元素的最大个数

typedef struct {
    int data[MAXSIZE];  // 存放栈中元素的静态数组
    int top;            // 栈顶指针
} SqStack;
```

> `top` 通常初始化为 `-1`（指向栈顶元素），也可初始化为 `0`（指向栈顶元素的下一个空闲位置）。

**核心操作**（以 `top = 0` 方案为例，top 指向下一个空位）：

```c++
bool InitStack(SqStack &S) {
    S.top = 0;          // top 指向下标 0，表示空栈
    return true;
}

bool Push(SqStack &S, int x) {
    if (S.top == MAXSIZE)   // ① 进栈先判满
        return false;
    S.data[S.top] = x;      // ② 将 x 放入当前 top 所指的空位
    S.top++;                // ③ 栈顶指针后移，指向下一个空位
    return true;
}

bool Pop(SqStack &S, int &x) {
    if (S.top == 0)         // ① 出栈先判空
        return false;
    S.top--;                // ② 栈顶指针前移，指向当前有效的栈顶元素
    x = S.data[S.top];      // ③ 取出元素
    return true;
}
```

| 项目 | 内容 |
|:---|:---|
| 初始值 | `S.top = 0` |
| 判空 | `S.top == 0` |
| 判满 | `S.top == MAXSIZE` |
| 入栈核心 | `S.data[S.top] = x; S.top++`（先存再移） |
| 出栈核心 | `S.top--; x = S.data[S.top]`（先移再取） |

**致命缺点**：MAXSIZE 太小易**上溢（Stack Overflow）**，太大浪费空间。

### 动态顺序栈

栈满时自动在堆区申请更大的连续内存，将老数据搬迁过去，实现"扩容"。

```c++
#define INIT_SIZE 10    // 初始分配的容量
#define INCREMENT 5     // 每次扩容增加的增量

typedef struct {
    int *data;          // 指向动态分配数组的基址指针
    int top;            // 栈顶指针（这里用作索引）
    int maxSize;        // 栈当前的最大容量
} DynSqStack;
```

**核心操作**：

```c++
bool InitStack(DynSqStack &S) {
    S.data = (int *)malloc(INIT_SIZE * sizeof(int)); // ① 堆区分配连续空间
    if (!S.data)
        return false;                                 // ② 检查分配是否成功
    S.top = 0;                                        // ③ 空栈：栈顶索引置 0
    S.maxSize = INIT_SIZE;
    return true;
}

bool Push(DynSqStack &S, int x) {
    if (S.top >= S.maxSize) {                         // ① 进栈先判满
        // ② 追加存储空间
        int *newdata = (int *)realloc(S.data,
            (S.maxSize + INCREMENT) * sizeof(int));
        if (!newdata)
            return false;                             // ③ 检查是否分配成功
        S.data = newdata;                             // ④ 更新基址指针和总容量
        S.maxSize += INCREMENT;
    }
    S.data[S.top] = x;                                // ⑤ 元素入栈
    S.top++;
    return true;
}

bool Pop(DynSqStack &S, int &x) {
    if (S.top == 0)         // ① 出栈先判空
        return false;
    S.top--;                // ② 栈顶前移，取出元素
    x = S.data[S.top];
    return true;
}

void DestroyStack(DynSqStack &S) {
    free(S.data);           // 释放堆区数组
    S.data = NULL;
    S.top = 0;
    S.maxSize = 0;
}
```

> 注意：`realloc` 可能寻找全新空间并复制原数据，因此必须更新 `S.data` 指针；`S.top` 是索引，数据搬移后索引关系不变。

### 栈顶 top 的四种初始化方式对比（考研必背）

| 特性 | 从下往上 `top=0` | 从下往上 `top=-1` | 从上往下 `top=n` | 从上往下 `top=n-1` |
|:---|:---:|:---:|:---:|:---:|
| **top 含义** | 下一空位 | 当前栈顶 | 当前栈顶 | 下一空位 |
| **初始值** | `0` | `-1` | `n` | `n-1` |
| **判空** | `top == 0` | `top == -1` | `top == n` | `top == n-1` |
| **判满** | `top == MAXSIZE` | `top == MAXSIZE-1` | `top == 0` | `top == -1` |
| **入栈** | `S[top++] = x` | `S[++top] = x` | `S[--top] = x` | `S[top--] = x` |
| **出栈** | `x = S[--top]` | `x = S[top--]` | `x = S[top++]` | `x = S[++top]` |
| **读栈顶** | `S[top - 1]` | `S[top]` | `S[top]` | `S[top + 1]` |
| **元素个数** | `top` | `top + 1` | `n - top` | `n - 1 - top` |

> **考研提醒**：严蔚敏教材默认 `top = 0`，但很多习题用 `top = -1`。**审题时先确认题目给的 top 初始值，再推导对应代码！**

### 静态 vs 动态对比

| 维度 | 静态顺序栈 | 动态顺序栈 |
|:---|:---|:---|
| 内存位置 | 系统栈区或全局/静态数据区 | 系统堆区 (Heap) |
| 容量限制 | 编译时固定，不可变 | 运行时可动态扩容 (realloc) |
| 上溢风险 | 高 | 极低（仅受物理内存限制） |
| 时间复杂度 | 所有操作严格 $O(1)$ | 绝大部分 $O(1)$，扩容瞬间 $O(n)$ |

## 链栈

链栈（Linked Stack）是用**链表**实现的栈，本质上是一个**只允许在表头进行插入和删除的单链表**。只要内存够就一直能入栈，彻底告别"栈满溢出"。

> **核心设计原则**：栈顶指针必须锚定在链表头部——入栈用头插法、出栈用头删法，均为 $O(1)$。若栈顶在链表尾部，每次入栈找尾结点 + 出栈找前驱都会退化为 $O(n)$。

### 不带头结点链栈（严蔚敏教材默认，408 最常考）

`S`（即 `top`）直接指向第一个数据结点。

```c++
typedef struct LinkNode {
    int data;               // 数据域
    struct LinkNode *next;  // 指针域，指向栈中更底部的元素
} LinkNode, *LiStack;       // LiStack ≡ LinkNode*（栈顶指针类型）
```

**关键理解**：链栈是倒过来的链表——`next` 指向栈中**下方**的元素。入栈 = 头插法，出栈 = 头删法。

```c++
bool InitStack(LiStack &S) {
    S = NULL;           // 栈顶指针置空，空栈
    return true;
}

bool Push(LiStack &S, int x) {
    LinkNode *p = (LinkNode *)malloc(sizeof(LinkNode));
    if (p == NULL)
        return false;               // 内存耗尽（极罕见）

    p->data = x;
    p->next = S;                    // 新结点指向当前栈顶
    S = p;                          // 栈顶指针移到新结点
    return true;
}

bool Pop(LiStack &S, int &x) {
    if (S == NULL)                  // ① 先判空
        return false;

    LinkNode *p = S;                // ② 头删法四步
    x = p->data;                    //    暂存栈顶结点、取出数据
    S = S->next;                    //    栈顶下移（p->next 为 NULL 时 S=NULL）
    free(p);                        //    释放原栈顶
    return true;
}

bool GetTop(LiStack S, int &x) {
    if (S == NULL)
        return false;               // 栈空
    x = S->data;                    // 直接读 top 所指结点的数据
    return true;
}

void DestroyStack(LiStack &S) {
    while (S != NULL) {
        LinkNode *p = S;            // 逐个释放栈顶结点
        S = S->next;
        free(p);
    }
}
```

| 项目 | 内容 |
|:---|:---|
| 判空 | `S == NULL` |
| 判满 | 不存在（链栈不会满，`malloc` 失败才返回 false） |
| 入栈核心 | `p->next = S; S = p`（头插法），严格 $O(1)$ |
| 出栈核心 | `p = S; S = S->next; free(p)`（头删法），严格 $O(1)$ |
| 出栈最后元素 | `S = p->next` 自然置 NULL，**无需特殊处理** |

### 带头结点链栈

`S`（top）永远指向头结点，真正的栈顶数据在 `S->next`。入栈/出栈逻辑**完全统一**，无需区分空栈边界。

```c++
bool InitStack(LiStack &S) {
    S = (LinkNode *)malloc(sizeof(LinkNode));   // 创建头结点
    if (S == NULL)
        return false;
    S->next = NULL;
    return true;
}

bool Push(LiStack &S, int x) {
    LinkNode *p = (LinkNode *)malloc(sizeof(LinkNode));
    if (p == NULL)
        return false;

    p->data = x;
    p->next = S->next;          // 新结点指向当前栈顶（可能是 NULL）
    S->next = p;                // 头结点链到新结点
    return true;
}

bool Pop(LiStack &S, int &x) {
    if (S->next == NULL)        // 判空
        return false;

    LinkNode *p = S->next;      // 锁定栈顶数据结点
    x = p->data;                // 取出数据
    S->next = p->next;          // 头结点跳过 p
    free(p);                    // 释放
    return true;
}
```

| 项目 | 内容 |
|:---|:---|
| 判空 | `S->next == NULL` |
| 入栈核心 | `p->next = S->next; S->next = p`（操作对象是 `S->next` 而不是 `S` 本身） |
| 出栈核心 | `p = S->next; S->next = p->next; free(p)` |
| 代价 | 多一个头结点的 malloc/free 开销 |

### 带头 vs 不带头对比

| 维度 | 不带头结点 | 带头结点 |
|:---|:---|:---|
| 初始值 | `S = NULL` | `S = malloc(…); S->next = NULL` |
| 判空 | `S == NULL` | `S->next == NULL` |
| 入栈 | `p->next = S; S = p` | `p->next = S->next; S->next = p` |
| 出栈 | `p = S; S = S->next; free(p)` | `p = S->next; S->next = p->next; free(p)` |
| 内存 | 省一个头结点 | 多一个头结点 |
| **考研倾向** | **★ 严蔚敏教材默认，最常考** | 考试较少出现 |

## 顺序栈 vs 链栈对比

| 维度 | 顺序栈 | 链栈 |
|:---|:---|:---|
| 存储方式 | 连续数组 | 离散结点（单链表） |
| 容量 | 有限（静态）/ 可扩（动态） | 无限（仅受物理内存限制） |
| 判满 | `top == MAXSIZE` 等 | 不存在（malloc 失败才满） |
| 入栈 | $O(1)$，偶尔 $O(n)$（扩容时） | 严格 $O(1)$（头插法） |
| 出栈 | $O(1)$ | 严格 $O(1)$（头删法） |
| 适用场景 | 元素个数可预估 | 元素个数未知、波动极大 |

## 高频考点速记

| 考点 | 记忆 |
|:---|:---|
| 栈的特性 | **LIFO 后进先出**，只在栈顶 `top` 一端插入删除 |
| 静态顺序栈 | `top=0`：判空 `top==0`、判满 `top==MAXSIZE`、先存再移 |
| 动态顺序栈 | 用 `realloc` 扩容，**必须更新 `S.data` 指针** |
| top 四种初始化 | 从下往上 `top=0/-1`、从上往下 `top=n/n-1`；**审题先看初始值** |
| 入/出栈口诀 | `top=0`：`S[top++]=x` / `x=S[--top]`；`top=-1`：`S[++top]=x` / `x=S[top--]` |
| 链栈设计原则 | 栈顶必须设在**链表头部**，入栈头插法、出栈头删法，均 $O(1)$ |
| 不带头结点链栈 | 判空 `S==NULL`；★ 严蔚敏教材默认，最常考 |
| 带头结点链栈 | 判空 `S->next==NULL`；操作对象始终是 `S->next` |
| 链栈优势 | 不会满；出栈最后元素 `S=p->next` 自然置 NULL，**无需特殊处理** |
